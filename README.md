# 界鉴

界鉴核对 Web 应用的权限要求与实际行为。先确认谁能对什么资源执行什么动作，再使用真实账号和业务材料检查，最后按规则阅读结果、定位问题并复验修改。

## 开始使用

Windows 下运行仓库根目录 `start.cmd`。首次启动准备工具、运行环境、浏览器和前端，之后按指纹复用有效环境。终端 `Ctrl+C` 或界面“退出界鉴”停止本地服务，已保存的业务记录保留。

- 首次体验：[完成首次检查](docs/产品/开始使用.md)。
- 检查自己的程序：[接入应用](docs/产品/接入应用.md)。
- 理解判断：[权限、事实与结论](docs/产品/检查与复验.md#如何理解结论)。
- 开发维护：[开发](docs/工程/开发.md)、[测试](docs/工程/测试.md)。

[文档目录](docs/README.md)按任务提供操作、解释和工程参考。当前生产目标只有 Web；源码和 Agent 建议须经审阅，不能自动激活权限或决定安全结论。检查只针对已获授权的范围。

## 持续检查与维护

发现问题后，从对应权限规则查看问题历史，将一次源码修改关联到实际涉及的多条规则，再沿原问题复验，分别确认漏洞是否解决、正常功能是否保留。Agent 可通过受控连接取得本轮要求与证据，修复说明和代码提交不直接改变检查结论。

右上角运行状态提供组件概览和诊断入口；[本地维护](docs/产品/本地维护.md)说明示例管理、存储清理及中断结果查询。[Windows 便携版](docs/产品/便携版使用.md)使用自带组件运行，可通过明确的本地更新接续原工作区。历史报告按检查时的范围保留，不随当前规则或源码变化重写。
