# 官方示例

界鉴只有一个官方示例：[数字展馆](web/digital_gallery)。从工作台“启动示例”进入，启动和测试使用同一份业务源码。

演练顺序：确认评审可否下载展示版 → 批准权限 → 实际登录并创建虚构资料 → 核对测试材料与证明来源 → 检查 → 修改代码并复验 → 查看同一检查历史。

示例包含公开预览、展示版下载和内部完整包领取。五个源码预设展示正常起点、错误交付、开放后撤回、正确修复及后续预览修改。结论由真实检查生成。文件由运行中的业务操作产生，运行数据和证据只写入 `var/`。

开发、验证与退出边界见[修改官方示例](../docs/能力/应用接入/修改官方示例.md)。
