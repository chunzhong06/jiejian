# 报告与格式投影协议

> 状态：CURRENT。本文解释报告语义真源和确定性格式投影。

## 目的与消费者

报告服务、GUI、CLI、CI 和交付系统消费已发布事实。报告用于呈现 Run、Evidence、Finding、Baseline、Gate、限制和版本，不重新执行验证或修改安全结论。

## 先理解：一份语义，多种投影

`report.json` 保存已经发布并校验的报告语义；HTML、SARIF 与 JUnit 只是由同一输入确定性生成的交付格式。GUI 的 ResultPresentation 和 CLI 的 Human/Machine 输出也读取同一批已发布事实，但服务于即时查看，不替代不可变 Report publication。

因此“修正文案”不能直接改 report.json 中的安全事实，“修格式”也不能重新运行 Verification。投影失败可以重试，原 Run Verdict、Evidence、Finding 与 GateResult 保持不变。

## 协议边界

- 独立 ReportStore publication 中的 `report.json` 是唯一报告语义真源；根文档由 `report_type` 严格区分 `BaseRunReport` 与 `GateRunReport`，不使用可空字段拼成兼容模型。
- `BaseRunReport` 独立呈现 Run/runtime、Artifact 三态、versions、limitations 和有界 diagnosis；`GateRunReport` 引用并复制已验证的 Base 事实，再增加明确的 GateResult。
- diagnosis 只保存授权连续性三态、唯一主断裂、精度、后续 amplifier、固定七项业务故事、已确认下游影响和 Evidence 引用；可选 repair verification 只投影同考题复验三态及其权威引用。二者都不包含完整 Trace，不允许投影器或模型重算位置、精度、影响集合、修复合同或 Verdict。
- 当精度为 `VIOLATION_ONLY` 且 Trace 不能支持具体类型时，diagnosis 的 `breakpoint_type` 为 `null`；投影必须显示当前无法继续定位，不能猜测一个类型填入。
- package manifest 绑定 report、run、报告种类、Base 引用、可选 GateResult、canonical report hash 和固定四格式文件列表。
- HTML、SARIF、JUnit 是由同一语义输入生成的确定性投影。
- 报告只能引用已校验 publication 和不可变 Evidence。

## 生命周期与数据流

```text
Run publication
  → ResultFinalizer → 已物化 Finding/Occurrence
  → ResultPresentation diagnosis
  → 基础 report.json v5
  → 可选 Baseline/Gate → 独立 Gate report.json
  → package manifest/hash
  → HTML/SARIF/JUnit 投影
  → GUI/CLI/CI 读取
```

## 失败与安全语义

缺失 Evidence、manifest、hash 或运行关联时报告无效，不能形成安全结论；基础报告不要求 Gate。报告派生或投影失败记录为可重试派生错误，不得修改 Run Verdict、Finding、Evidence 或 GateResult。Artifact 摘要只使用 `NOT_REQUESTED`、`COMPLETE`、`INCONCLUSIVE`：未请求是中性事实，不形成 limitation；已请求但未可靠完成才形成 INCONCLUSIVE。

## 版本规则与 Schema 真源

Base/Gate Report 当前根 `schema_version` 为字符串 5；report package manifest 是独立根，仍为字符串 1。Report v5 在既有授权连续性、primary/amplifier 和固定七项故事之外，加入可选的权威修复引用与独立复验三态并纳入 canonical；旧 Report 不兼容读取。package manifest 继续绑定当前 report canonical hash，不因被引用根升级而机械改版。字段、hash、canonical、判别联合和严格解析以：

- `product/protocols/report.py`
- `product/protocols/schemas/reports/`

为准。旧开发 Report 和 wire format 不兼容读取。
