## 当前工程边界

Storage 的垂直聚合以字符串 ForeignKey 表达数据库关系，不靠 peer Row import 注册映射；`orm_registry.py` 是需要完整 metadata 时的唯一固定登记清单。`storage/__init__.py` 只提供稳定 Record、Repository、UoW 和数据库 helper，不公开 SQLAlchemy Row。
