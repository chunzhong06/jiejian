# 连接开发工具

开发工具允许外部 Agent 通过本地 MCP 使用明确授予的能力。开始前需要本地服务可用、已选择项目，以及可配置 MCP 的客户端。

## 建立连接与授权

1. 点击左下角“设置”，选择“开发工具”，选择客户端并配置连接。连接设置与当前应用授权分区显示。
2. 在客户端配置连接，再回到界鉴核对状态。
3. 查看应用、动作、来源和期限，分别授予读取、准备或执行能力。
4. 先核对当前上下文，再执行被允许的工作。

连接成功只说明传输可达，不代表已经获准执行。不要将密钥复制到普通数据库、源码、日志、截图或报告。

## 使用建议与交付

规则、材料和业务解释建议进入同一人工审阅流程。Agent 不能批准正式权限、改变来源授权或决定安全结论。解释已有结果时引用实际记录，并保留证据范围。

修改交付注明真实范围、关联规则和准确原题。登记、加载与复验各有回执；一个环节成功不代表后续已经完成。请求结果未知时查询原操作，不用另一份交付覆盖不确定性。

## 围绕一个目标持续协作

从左侧“应用与来源”下方选择“Agent 协作”，交代要完成的目标。可以先选“整理权限要求”“补齐检查准备”或“调查权限问题”，再调整目标；选择示例会填写目标并匹配任务类型，可以在提交前调整；建立任务后再确认启动。协作任务保留当前应用、已有工作及准确产物；已有任务时，同一入口直接显示“进行中”“待你确认”或“待接续”等状态，点击返回原任务。窄窗口先打开导航，入口仍保留名称与状态；离开页面或重启服务后，可以从原任务继续。

在接口流程中点击“请 Agent 补全”，会先显示本次交接的草稿范围；结果判断设置也可交接当前选择。可以补充到已有任务或另建独立目标。请求结构和已选对象会带入，参数原值、凭据与文件留在当前浏览器。离开协作页后可在“产物与上下文”中返回原草稿或交接位置继续；刷新整个网页或关闭窗口会丢失尚未保存的本机草稿。

Agent 保存流程候选后，从“当前工作”的待办中选择该产物，再打开“比较并审阅流程”，核对请求、账号、测试数据、结果查询和恢复安排，再带入编辑器。可以沿用同名参数的本机填写值，结构改变的参数需继续核对；最后“确认用于检查”才正式采用。结果证明继续经过读取范围、预检查与采用。

在任务内使用“补充目标与说明”调整要求，已有工作会保留；需要回答问题时，可以选择建议后补充，也可直接输入。顶部“全部协作任务”可查看进行中及已结束任务，查看和切换都不会调用模型。

Agent 先读取已有权限、账号和材料，再整理缺少的配置。需要你澄清业务要求时，任务显示一个具体问题；需要登录或审阅正式权限时，进入对应的现有界面。普通文字回答不能批准权限或代替秘密输入。其他可准备内容不要求你重复填写技术字段。

任务顶部简述目标和状态。“当前工作”左侧列出需要你处理的事项，选择后在右侧回答、确认或打开审阅；一次只展开一项，切换不会丢失未提交回答。没有待办时，主区显示正在执行的工作、继续入口或对应检查报告。“产物与上下文”查看准确产物、交接范围与返回位置，“处理记录”查看操作回执和后台进展；暂停、结束与停止位于“任务操作”。取得请求回执仅表示业务用例已经接收；后台完成、检查结论及原题复验分别由实际记录确认。

暂停保留进展并停止 Agent 后续工作；停止任务还会向其所属后台执行请求取消。停止请求与资源清理完成分别显示，不停止同项目其他人的执行。遇到回执未知时核对原操作，不换编号重发。

使用已连接开发工具时，复制任务只准备了接续信息，尚未发送或启动 Agent。本机 Codex 执行入口会在启动前说明模型额度与源码修改范围；是否已安装、能否连接、模型是否完成和业务是否完成各自判断。只读协作可以查看已有报告，不附带材料准备或源码修改权限。工具调用被拒绝或失败时，任务保留提示及已有结果，不能用模型已返回替代业务完成。

任务类型为“调查权限问题”时，完成检查并形成报告即达到本次目标，发现问题也可以完成检查。“检查并修复”要求原问题与正常功能取得完整复验依据。整理规则、补齐准备和解读报告分别核对对应产物，不要求全部都运行一次检查。

启动本机 Agent 时，先确认本次是否允许修改当前应用源码；默认不允许修改，当前只读授权不提供修改选项。模型额度和可能费用、回合与授权窗口始终可见。“执行方式与权限边界”收纳持续推进设置及详细职责，持续推进默认开启，需要人的决定时等待确认后接续。持续模式最多 8 个模型回合，关闭持续推进后只执行 1 个模型回合；两者的授权窗口均为 30 分钟，等待确认与后台执行也计入窗口。当前工作旁显示已使用回合；等待你的决定或后台执行期间不调用模型。达到上限、权限变化、越界请求或没有新进展时停止，已经完成的材料、修改与报告保留。工具参数已在本轮纠正且业务确已接收时，继续等待真实结果；结果未知则先核对原回执。需要再推进时明确继续原任务；离开页面不会重新计费启动，服务重启也不会自动恢复模型调用。

## 撤回与排查

暂停或撤权后停止后续受授权操作，已有事实保留供查阅。连接失败时依次检查本地服务、客户端地址、连接状态和能力范围；执行被拒绝时查看具体授权与前置条件，不通过扩大凭据范围绕过拒绝。

## 从报告进入修复协作

报告和规则问题可以生成固定上下文的请求。`jiejian_result_show`返回该轮结果及各修复目标的核验，`jiejian_evidence_show`读取指定用例引用的记录，`jiejian_repair_show`提供原题要求、连续处理历史及复发情况。结果入口始终定位到指定报告，不以“最近一次”替换。

Agent 应先核对事实，再定位实现；修改后以一个稳定操作键登记实际文件变化和多个rule_targets，未知回执先查询原操作。登记、代码加载、材料核对与原题复验分别完成，不用提交说明、人为关闭或版本名称替代修复验收。本流程复用现有MCP授权等级，不新增离线报告或自动发送通道。
