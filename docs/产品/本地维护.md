# 本地维护

按影响选择入口：右上角齿轮进入设置页，页内分类为开发工具、本地存储和运行维护；运行维护中核对界鉴服务的组件状态；左上角应用切换菜单进入官方示例管理。窄窗口保留完整可访问名称。

## 读取运行状态

打开右上角状态入口，查看版本、执行服务和检查浏览器。标题旁刷新图标只重读状态，不重启、不清理。读取失败按原位置重试，不能从页面可打开推断执行服务可用。

点击左下角“设置”，选择“运行与维护”打开本机工作面。“运行诊断”按需核对组件，并显示核对时间；日常状态刷新不反复检查整个发行包。重新准备界面资源后，下次打开诊断会重新核对。

点击“查看诊断摘要”阅读具体信息，摘要内提供“复制摘要”和“下载摘要”。摘要只包含版本、平台、核对时间、运行方式和组件可用性，不包含账号、凭据、个人路径、业务请求或原始日志；产品不自动上传。复制失败时保留摘要及下载入口，不把未完成的复制显示为成功。

“版本与更新”负责选择本地完整发行目录，具体流程见[便携版使用](便携版使用.md)。本地存储从同一工具菜单进入，不在诊断页重复列出缓存清单。

## 管理官方示例

| 操作 | 影响 | 完成后核对 |
| --- | --- | --- |
| 进入或继续 | 使用同一项目和历史 | 当前版本与下一处缺口 |
| 重启运行环境 | 保留源码、规则、报告，重建运行会话 | 登录与受影响材料 |
| 停止示例 | 停止运行环境，保留记录 | 实际停止回执 |
| 重新开始示例 | 建立独立项目，原项目仍可查阅 | 新项目来源、权限与准备 |

“进入”直接可见，其他操作在“管理示例”。确认重要操作前读清影响；正在处理或结果未知时查询原操作，不重复启动新实例。

## 清理本地存储

1. 打开“本地存储”，扫描形成短期计划。
2. 核对类别、条目、数量和空间，按需要调整选择。
3. 确认所选后执行，查看实际处理与跳过结果。

默认选择符合条件、可重建的候选。应用、规则、材料和报告保留；未知归属、活跃引用和不满足条件的文件不靠目录名称判断可删。删除前复核路径、归属、引用与文件变化，发生变化或重新使用的条目跳过。计划过期时重新预览，同一执行只查询原回执。

清理开始与每项已确认结果会保存在本机。进程中断后，存储页面仍能找到上次计划，显示已确认删除、跳过、失败和未确认数量。文件现在不存在不能证明由该操作删除。先查询明细，再选择“核对现状并重新扫描”；这只确认已经阅读中断结果并扫描当前事实，不继续旧删除，也不将未知项改成成功。

## 退出

界面“退出界鉴”说明当前任务和本地服务的停止影响。终端 `Ctrl+C` 直接进入退出过程。保存记录保留，服务和任务仍需完成释放；关闭网页不能代替停止服务，未知进程也不通过强杀解决。

便携启动器在服务及其所属进程退出、工作区锁释放后记录最终结果。“运行诊断”显示最近一次已确认的退出及其时间。强制终止启动器可能来不及写入回执，因此该记录不代表之后从未发生异常退出。网页只确认退出请求已接收，断连不代表收尾完成。
