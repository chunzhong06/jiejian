# 本地维护

按影响选择入口：右上角查看服务，示例页管理示例生命周期，侧栏“本地存储”清理运行生成物。

## 读取运行状态

打开右上角状态入口，查看版本、执行服务和检查浏览器。标题旁刷新图标只重读状态，不重启、不清理。读取失败按原位置重试，不能从页面可打开推断执行服务可用。

## 管理官方示例

| 操作 | 影响 | 完成后核对 |
| --- | --- | --- |
| 进入或继续 | 使用同一项目和历史 | 当前版本与下一处缺口 |
| 重启运行环境 | 保留源码、规则、报告，重建运行会话 | 登录与受影响材料 |
| 停止示例 | 停止运行环境，保留记录 | 实际停止回执 |
| 重新开始示例 | 建立独立项目，原项目仍可查阅 | 新项目来源、权限与准备 |

“进入”直接可见，其他操作在“管理示例”。确认重要操作前读清影响；正在处理或结果未知时查询原操作，不重复启动新实例。

## 清理本地存储

1. 打开“本地存储”，扫描形成短期计划。
2. 核对类别、条目、数量和空间，按需要调整选择。
3. 确认所选后执行，查看实际处理与跳过结果。

默认选择符合条件、可重建的候选。应用、规则、材料和报告保留；未知归属、活跃引用和不满足条件的文件不靠目录名称判断可删。删除前复核路径、归属、引用与文件变化，发生变化或重新使用的条目跳过。计划过期时重新预览，同一执行只查询原回执。

## 退出

界面“退出界鉴”说明当前任务和本地服务的停止影响。终端 `Ctrl+C` 直接进入退出过程。保存记录保留，服务和任务仍需完成释放；关闭网页不能代替停止服务，未知进程也不通过强杀解决。
