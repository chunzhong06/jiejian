# 入口与导航

> 状态：CURRENT。只记录当前 Web 界面的入口归属。数据列表中的每条记录不重复计数；本表不代表已逐个完成运行态验收。

## 分类口径

入口以用户要完成的事情分类，不以按钮、抽屉或组件名称分类。相同目的的概览快捷入口、结果页入口和侧栏入口可以并存，但必须进入同一工作面并携带相同事实引用。

| 层级 | 用途 | 当前数量或形式 |
| --- | --- | --- |
| 一级模块 | 稳定切换完整工作领域 | 4：概览、权限要求、修改与验证、检查记录 |
| 功能路由 | 可以导航到的工作页面 | 9 条有效路径；包括上述 4 条和 5 条辅助路径 |
| 模块子页 | 同一领域中的平级内容 | 权限要求 3 类；修改详情 4 类，连接为次级配置 |
| 对象详情和任务步骤 | 某个动作、原题、Run、材料或提案 | 由具体记录产生，不以数据条数累计导航数量 |
| 抽屉 | 保留原页面上下文 | 1 类：AI 辅助设置 |
| 模态框 | 短确认或设置 | 8 处声明式 Modal 宿主，另有 2 处账号 Modal.confirm；同一宿主可承载多个动作 |
| 就地确认 | 对当前操作确认影响 | 3 类可达确认：公共重启动作、放弃候选编辑、撤下材料引用；旧任务组件不在默认工作面挂载 |
| 原生折叠区 | 说明、细节及少量内嵌任务 | 按下表分类；补充路径和官方演练按需展开，源码声明不等于可达入口总数 |
| 组件折叠区 | 技术信息或备用输入 | 4 处 Collapse 声明 |
| 全局下拉菜单 | 应用选择和工具设置 | 2 处 Dropdown；主题包含一层子菜单 |

这些统计不是可以相加的“入口总数”。例如同一结果对象同时含详情页签和技术折叠区，折叠区里还可能含有页面入口。搜索、分页、刷新、筛选、保存、复制和表单选项是操作控件，除非进入独立工作面，否则不另算导航。

## 主模块和有效路径

| 一级归属 | 当前路径或子入口 | 内容与下一步 | 当前呈现 |
| --- | --- | --- | --- |
| 概览 | `/workspace` | 唯一下一步、权限/材料/最近结果简表 | 完整页面；主任务来自服务端 |
| 概览 | `/application` | 接入应用、确认地址、授权源码分析、审阅权限组和业务动作 | 独立工作面；候选选择后进入确认总览 |
| 概览 | `/tests` | 检查预览、材料准备、执行进度和当前结果 | 完整页面，按任务显示对应步骤 |
| 概览 | `/environment` | 应用信息、实例状态、官方环境操作、旧项目历史、移除应用 | 独立页面 |
| 权限要求 | `/permissions` → 权限规则 | 按业务动作阅读和编辑允许/禁止要求 | 默认规则清单；详情后进入动作工作面 |
| 权限要求 | `/permissions` → 业务动作 | 动作含义、资源、业务结果、代码关联 | 模块内平级入口 |
| 权限要求 | `/permissions` → 业务角色 | 角色含义、引用和代码关联 | 模块内平级入口 |
| 修改与验证 | `/changes` | 最近修改、真实变化、精确检查、待处理问题 | 一块重点状态与修改列表；登记本地修改为次级入口 |
| 修改与验证 | `/changes?change_id=…` | 修改内容、检查结果、沿用要求、源码对应 | 单次详情；相对上次修改/起始快照比较 |
| 修改与验证 | `/changes?repair_reference=…` | 原问题、正常对照、修复依据与复验事实 | 查看/复制依据；已有精确 Run 直接查看 |
| 次级配置 | `/tools` | 客户端连接、凭据管理、各应用允许范围 | 顶部状态或修改页入口进入；可返回修改记录 |
| 检查记录 | `/history` | 历次检查、所选 Run、用例、证据和对应源码 | 列表进入精确记录；代码变化已归 修改与验证 |
| 全局辅助 | `/settings/system` | 运行状态、组件状态、磁盘与维护操作 | 左下角系统状态进入 |

`/settings/models` 只打开已有 AI 辅助抽屉，不增加一个设置页面。历史地址 `/identities`、`/flows`、`/preparation`、`/validation`、`/results`、`/verification` 没有独立当前工作面，只显示不可用提示，不计入有效路径。

旧 `view=handoff/deliveries/acceptance` 地址保留兼容；不恢复新建/接收/结束开发任务工作面。`view=register` 直达一次登记表单。

## 页面内任务与对象入口

| 所属领域 | 当前可进入的内容 | 入口形式 |
| --- | --- | --- |
| 概览 | 服务端当前任务、检查与材料、检查历史、修改与验证、应用与环境 | 主按钮和次级快捷入口 |
| 应用接入 | 文件夹选择、确认应用地址、源码分析 | 顺序工作步骤 |
| 候选审阅 | 权限组 / 业务动作、选择、改名、确认总览、返回修改 | 类别切换与两步流程 |
| 权限要求 | 新增/编辑规则、动作和角色，核对代码关联 | 工具栏与对象行操作 |
| 权限要求 | 草稿审阅、沿用项、批准、放弃提案 | 独立审阅步骤 |
| 检查准备 | 账号、动作演示、测试资源、结果证明、恢复方式 | 5 组材料展开及条目入口 |
| 材料编辑 | 已有候选 / 新建录制、比较、更新影响、预览、确认 | 独立材料工作面 |
| 账号管理 | 添加账号、登录浏览器、核对登录、重置登录、删除账号 | 表单和记录操作 |
| 录制 | 开始演示、停止、审阅、绑定到准备要求 | 顺序工作步骤 |
| 结果证明 | 可用证明能力、来源匹配与限制 | 准备工作面的明示入口 |
| 补充材料 | 导入、修改说明、全部修订、撤下引用、摘要 | 材料工作面的附属功能 |
| 检查执行 | 预览、开始、进度、取消、已发布结果 | 同一工作面按状态切换 |
| 结果与证据 | 整轮总览、单项事实与证明、执行过程、证据记录 | 结果表进入单项工作面；页内切换，保留 Run/Case 深链 |
| 结果与证据 | 本轮范围、冻结对象与精确记录引用 | 页签栏右侧入口与范围弹窗 |
| 结果与证据 | 本轮源码与当前源码对应、相关代码变化 | 对应结果的详情入口 |
| 修改与验证 | 查看/复制修复依据、原始证据 | 原题详情工作面 |
| 修改与验证 | 修改记录、Agent 说明、真实文件变化、源码对应 | 修改记录列表和详情 |
| 修改与验证 | 关联原题、复验原题、复验记录、核对现有材料 | 上下文明确的操作 |
| 修改与验证 | 手动登记变化 | 明确按钮打开表单 |
| Agent 连接 | Codex / DSH / ZCode、添加配置、验证连接、授权范围 | 三步连接引导；教程选择与真实身份分开 |
| Agent 连接 | 管理连接、暂停/恢复、凭据更新/删除、逐应用允许范围 | 页面管理区与最后一次确认 |
| 环境管理 | 启动示例、重置、停止、可选观察条件 | 当前环境工作面及确认框 |
| 修改与验证 | 同步起点、预设异步优化、独立检查、原题修复 | 开发演练工作面 |
| 环境管理 | 环境操作记录 → 对应归档项目检查历史 | 折叠区内明示记录链接 |
| 系统维护 | 维护预览、确认清理、跳过/失败详情 | 页面加短确认框 |
| 全局通知 | 前往处理页面、关闭提示 | 与结构化错误绑定的动作 |

## 抽屉、弹窗、下拉及其他展开区

| 当前入口 | 类型 | 当前内容 |
| --- | --- | --- |
| 本轮范围 | Modal | 本轮冻结范围与精确记录引用 |
| AI 辅助 | Drawer | 默认模型连接、供应商、密钥输入与模型选择 |
| 移除当前应用 | Modal | 当前项目移除影响 |
| 退出界鉴 | Modal | 安全退出与现场处理说明 |
| 启动 / 重置 / 停止 | 共用 Modal | 对官方实例的实际影响 |
| 应用预设异步优化 / 预设修复 | 开发流程 Modal | 实际代码变更与历史保留 |
| 维护清理预览 | Modal | 本次选定的日志、缓存等清理范围 |
| 管理连接 | 页面管理区 | 暂停、恢复、凭据更新与删除 |
| 更新 / 删除连接凭据 | 共用 Modal | 现有客户端和授权的影响 |
| 这次允许 AI 工具做到哪一步 | Modal | 单项目的允许范围 |
| 重置登录 / 删除账号 | 2 处 Modal.confirm | 对账号材料的影响 |
| 公共重启、放弃候选编辑、撤下材料引用 | 3 类可达 Popconfirm | 就地说明操作影响 |
| 目录选择器不可用？ | Collapse | 备用目录手工输入 |
| 查看跳过与失败原因 | Collapse | 维护处理结果 |
| 查看日志分类占用 | Collapse | 各类日志占用 |
| 诊断信息 | Collapse | 错误码与追踪号 |
| 应用切换 | Dropdown | 已有应用与接入新应用 |
| 更多 | Dropdown | AI 辅助、主题子菜单、安全退出 |
| 主题 | Dropdown 子菜单 | 跟随系统、亮色、暗色 |
| Agent 连接状态 | 顶部状态按钮 | 进入连接与授权 |
| 系统状态 | 左下角按钮 | 进入系统详情 |
| 辅助观察与过程记录 | 证据区明确按钮展开 | 必要证明常显，辅助观察按来源和阶段列出 |
| 修复依据 | 原题详情只读正文和复制按钮 | 复制后返回原客户端；不默认发送 |
| 查看源码对应 | 结果或修改详情按钮展开 | 历史源码与当前源码的关系 |
| 材料分组、影响对照、材料修订列表 | 页面内局部展开/切换 | 对象条目、更新后影响及历史修订 |
