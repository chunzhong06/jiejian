# 报告与格式投影协议

> 状态：CURRENT。本文解释报告语义真源和确定性格式投影。

## 目的与消费者

报告服务、GUI、CLI、CI 和交付系统消费已发布事实。报告用于呈现 Run、Evidence、Finding、Baseline、Gate、限制和版本，不重新执行验证或修改安全结论。

## 协议边界

- 独立 ReportStore publication 中的 `report.json` 是唯一报告语义真源，包含 report/run/project、报告种类、可选 gate、runtime、artifact 状态、versions 和 limitations。
- package manifest 绑定 report、run、报告种类、可选 gate、report hash 和文件列表。
- HTML、SARIF、JUnit 是由同一语义输入生成的确定性投影。
- 报告只能引用已校验 publication 和不可变 Evidence。

## 生命周期与数据流

```text
Run publication
  → ResultFinalizer → 已物化 Finding/Occurrence
  → 基础 report.json
  → 可选 Baseline/Gate → 独立 Gate report.json
  → package manifest/hash
  → HTML/SARIF/JUnit 投影
  → GUI/CLI/CI 读取
```

## 失败与安全语义

缺失 Evidence、manifest、hash 或运行关联时报告无效，不能形成安全结论；基础报告不要求 Gate。报告派生或投影失败记录为可重试派生错误，不得修改 Run Verdict、Finding、Evidence 或 GateResult；INCONCLUSIVE 和 INVALID 必须保留其原始语义。未请求 Artifact Scan 是 `NOT_REQUESTED` 中性事实，不形成 limitation。

## 版本规则与 Schema 真源

Report 和 report package manifest 当前主要为 2。字段、hash、canonical 和严格解析以：

- `product/protocols/report.py`
- `product/protocols/schemas/reports/`

为准。旧开发 Report 和 wire format 不兼容读取。
