# 报告与格式投影协议

> 状态：CURRENT。本文解释报告语义真源和确定性格式投影。

## 目的与消费者

报告服务、GUI、CLI、CI 和交付系统消费已发布事实。报告用于呈现 Run、Evidence、Finding、Baseline、Gate、限制和版本，不重新执行验证或修改安全结论。

## 协议边界

- `report.json` 是语义真源，包含 report/run/project/gate、runtime、artifacts、versions 和 limitations。
- package manifest 绑定 report、run、gate、report hash 和文件列表。
- HTML、SARIF、JUnit 是由同一语义输入生成的确定性投影。
- 报告只能引用已校验 publication 和不可变 Evidence。

## 生命周期与数据流

```text
已发布 Evidence/Finding/Baseline/Gate
  → report.json
  → package manifest/hash
  → HTML/SARIF/JUnit 投影
  → GUI/CLI/CI 读取
```

## 失败与安全语义

缺失 Evidence、manifest、hash、Gate 或运行关联时报告无效，不能形成安全结论。投影失败不得修改 Verdict、Finding、Evidence 或 GateResult；INCONCLUSIVE 和 INVALID 必须保留其原始语义。

## 版本规则与 Schema 真源

Report 和 report package manifest 当前主要为 2。字段、hash、canonical 和严格解析以：

- `product/protocols/report.py`
- `product/protocols/schemas/reports/`

为准。旧开发 Report 和 wire format 不兼容读取。
