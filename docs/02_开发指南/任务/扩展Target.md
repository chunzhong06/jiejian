# 扩展 Target

## 什么时候看

只有产品明确决定增加 Web 以外 Target 时使用；当前生产 Target 仍只有 Web。

## 正常从哪改

先读 [系统全景](../../01_系统地图/系统全景.md)、[执行与观察](../../01_系统地图/执行与观察.md) 和相关协议，再形成独立架构、协议和验证决策。

## 不能破坏

不得在 Web V1 入口预建空 Target、绕过 Worker/Runner、复制 Verification 或新增未裁决公共 Schema。

## 直接验证

至少需要跨模块设计、协议、ApplicationCore 和代表性运行闭环；仅修改文档不能宣称 Target 已实现。
