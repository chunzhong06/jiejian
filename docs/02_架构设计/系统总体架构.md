# 系统总体架构

> 状态：CURRENT。当前适用范围：本机模块化单体、Web 产品入口、权限安全检查和结果交付。

## 职责

说明模块化单体的组合根、入口、控制面、持久任务、隔离执行和当前 Web 目标边界，提供其他 Architecture 的总览。

## 非职责

- 不定义 Runner、Observer、Report 或公共 Schema 的完整字段。
- 不复制 ADR 历史或路线图。
- 不把 CLI_APPLICATION、MCP_AGENT 或未来适配器描述为当前能力。
- 不替代代码、测试、migration 和协议 Schema。

## 真源

当前结构真源是 `product/backend`、`product/protocols`、`product/frontend`、`scripts`、相关测试和现行 migration。

## 目的

真实表达“入口如何进入共享应用、应用如何进入受控执行、结果如何返回”，避免入口、领域和执行职责混淆。

## 组件与边界

- GUI、CLI 和 API 共享完整的 `ApplicationContainer` 与 `ApplicationCore` 能力门面；Worker 使用独立、完整的 `WorkerContainer`，不通过继承或部分初始化共享组合根。
- `backend/core` 保存领域规则和安全结论；`workflows` 编排应用动作；`infra` 提供 Storage、队列、事务和发布；`api` 只做 transport；`cli` 只做命令适配。
- Worker 消费持久 Job，维护租约、fencing、取消、重试、发布和恢复。
- 受控 Runner 执行主动目标流量，并把受限结果交回 Worker；这里的隔离只指解释器、环境、进程树、取消和恢复边界，不代表未来 CLI Target 所需的完整 OS 沙箱。
- `TargetRuntimeRegistry` 按当前 Target Kind 创建 runtime；生产只注册 Web Target Runtime，通用 Case Orchestrator 与 Verification 不依赖 HTTP 协议。
- `RuntimePaths` 是 `var/data`、`runtime`、`cache`、`logs`、`temp` 和 `test` 的唯一物理路径真源。
- Run publication 与 Verdict 先独立完成，`ResultFinalizer` 再幂等物化 Finding/Occurrence 和基础报告；Gate 是可选后续派生。
- `product/protocols` 是跨进程机器协议真源；前端不直接调用目标。

## 关键数据流

```text
用户/CI
  → GUI、CLI 或 loopback API
  → ApplicationCore
  → Contract/Profile 校验与冻结执行请求
  → 持久 Job → Worker → 隔离 Runner
  → TargetRuntimeRegistry → Web Target Runtime
  → Evidence → 唯一 Verification → Run publication
  → ResultFinalizer → Finding/Occurrence → 基础报告
  → 可选 Baseline/Gate/Gate 报告
  → API、CLI、GUI 和 CI 读取已发布结果
```

安全意图到结果的完整链路见[安全意图与验证架构](安全意图与验证架构.md)。

## 关键不变量

- API 和 GUI 不直接发高风险目标请求。
- Worker 不重新读取可变 Profile、Flow 或 Contract；执行使用已冻结快照。
- 领域纯逻辑不依赖 FastAPI、SQLAlchemy、Playwright 或具体 LLM SDK。
- 生命周期状态、Verification Verdict 和 GateResult 分离。
- 已发布 Evidence 不可变，结果读取只消费已校验事实。

## 失败语义

入口输入、Contract/Profile 漂移、目标范围、预算、协议、租约、完整性或发布校验失败时，系统拒绝进入下一边界并返回脱敏、可识别错误。未知 TargetType、过期 fencing token、未知数据库结构和无法验证的工件均 fail closed。

## 安全约束

执行只允许用户明确授权的 Web 范围；重定向、私网访问、请求数、响应字节、并发、超时、秘密、日志和清理均受边界预算约束。LLM 不能决定安全结论。

## 兼容与版本

当前生产协议只表达 Web Target，不保存 `CLI_APPLICATION`、`MCP_AGENT` 等未实现枚举或空模型。未来 Target 通过新的不兼容 Schema 加入 Registry。旧开发数据库、Profile、Run、Evidence、Artifact、Report 和 wire format 不提供兼容读取；Schema/protocol 版本只表示机器格式。
