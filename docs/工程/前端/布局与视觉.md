# 布局与视觉

界鉴围绕持续维护的应用、权限要求、测试场景和检查事实组织工作。主内容应先回答“当前对象是什么、需要看什么、可以做什么”。本文维护通用视觉与审查判据，具体组织归[工作面模式](工作面模式.md)，控件行为和节奏归[交互与动效](交互与动效.md)，实现所有权归[实现](实现.md)。

## 基础统一与布局重建

基础设计的目标是统一，布局与信息组织的目标是重建。保留雾蓝身份、字体、字号层级、字重、圆角、控件结构、壳层尺寸和已认可动效；亮暗配色采用用户审阅通过的整窗背景与完整配色方案，避免页面各自定义。页面内容、任务分区、主次、阅读顺序和内部入口按真实任务重新组织。局部布局授权不自动扩大为基础风格替换。

## 框架与层级

侧栏是应用导航，顶栏是位置与全局工具，正文直接展开当前任务。沿用用户采纳的工作台框架和壳层尺寸，正文不再整体套入内缩圆角容器。背景渐变贯穿整个窗口，侧栏也能看出自然明暗变化；顶栏下方不另设横向色带或分界线。侧栏与正文之间使用上下留空的细分隔，不连接窗口顶端和底部。

侧栏沿用既有入口：工作台、权限与覆盖、测试、问题；分隔后的应用与来源管理资料，Agent 协作在其下方独立同级。Agent 使用明确文字和对话图标，当前任务状态属于该入口，不做独立宣传卡。应用切换菜单集中选择、新建和官方示例。设置固定在侧栏左下角，以齿轮和“设置”文字共同呈现，对齐其他导航的图标及文字轴，保留可访问名称和键盘焦点，直接进入独立设置页。顶栏保留上下文、刷新、主题及最右侧退出；设置分类在页内选择。

既有框架使用 224px 侧栏、68px 桌面顶栏及原阅读宽度。布局重建不另行缩改这些基础尺寸。它们服务于本产品的密度，不是通用设计定律；窄窗按内容重排。固定导航的图标与名称分列，名称使用一致的文字中心线；两字中文适当增加字距。此规则不用于正文、动态名称或全部按钮。

标题、对象、状态、辅助说明分配不同视觉重量。页面只有一个主标题；业务对象标题次之，分组标题再次。辅助栏不重复主标题或完整规则。页签属于当前位置，不形成卡片中的第二套主导航。普通页签不播放整页转场。

标题的 HTML 层级与视觉角色独立。可维护集合使用统一的 20px/1.5/600 组合，紧凑分组使用 14px/1.6/600，辅助分类使用 12px/1.6/600；语义上从属于业务操作的“业务结果”仍使用集合外观。页面不因 h2/h3 标签不同而另定同类字号，也不将所有 h3 机械放大。字体组合由共享标题预设负责，业务样式只安排空间、位置和适用颜色。

## 表面与颜色

圆角半径与转角曲线分别维护。共享形状层在浏览器支持时对产品控件、表面及 Portal 浮层采用 `superellipse(1.5)`，作为直边平滑进入转角的 Web 近似；8/12/16px 等现有半径和尺寸保持原值，颜色由共享语义角色维护。悬停遮罩与宿主使用相同曲线，单选圆点、编号圆与活动点保持圆形，局部连续索引仍为直角选择带。不支持时自然回退普通圆角，不增加 SVG 裁剪或运行时重绘。等距内外轮廓按真实内缩协调，不能将任意子控件机械改成同心形状。

浅色使用柔和蓝灰画布，深色使用中深蓝灰画布；二者沿用已采纳小样的底色和整窗渐变。浅色普通表面降低大片纯白的视觉重量，输入使用近白表面及中性边界，标签比标题更轻；深色保留已采纳的表面层次。颜色由共享语义角色统一调整，业务样式不另建色板。MiSans 字体、字号层级、字重、圆角、控件尺寸和动效基准保持原设计。

画布、内容面、输入面和浮层分别持有背景角色；深色浮层相对内容面提高明度，普通表面减少饱和度。主要动作、链接和选中各有前景角色，选中面的正文和辅助文字使用对应前景；不能只改底色后继续使用原灰字。普通悬停使用中性浅层，持续选中使用清楚的雾蓝及位置标记；选中项悬停使用同色系的明暗变化，保持原位置线。

完整颜色角色由 `tokens.css` 唯一维护：主、次、轻量按钮分别消费动作、普通表面及链接色；悬停与按下分别取对应角色。信息使用雾蓝，成功使用灰绿，警告使用灰金，错误使用灰玫瑰，中性等待使用灰蓝。角色、来源和 Agent 身份不额外分配彩虹色；允许、禁止与实际核验结果继续分开表达。

输入边界与装饰分隔线分别校准。正文、辅助文字、占位、禁用文字有独立角色，禁用控件不用整体透明度同时冲淡文字和底色；禁用按钮、输入、选择器和候选均沿用同一颜色职责。菜单、对话框和提示共用浮层角色，组件库按亮暗算法与同一组语义颜色映射，不另派生一套主题。

连续目录使用表格或相接的行；编辑任务、需要独立确认的范围可以围合。固定工作面默认无悬浮阴影，菜单和对话框保留真实层级。不能将每段文字、每条说明都包成相同权重的框。已有留白或表面差异足以表达分组时，减少重复线条。

连续目录、索引与普通配置表单沿用画布，不默认铺满辅助蓝底。选中、输入、语义通知和独立证据面保留各自表面；移除冗余底色不改变主题令牌。目录外层与内部表格只由一处承担边界，页签下分界也只有一个所有者，避免外框套表格、页签下双线。空态和读取失败不再叠加无意义外卡。

选中使用持续的浅蓝表面与位置标记；深色主题也使用相对明亮的蓝色。悬停仅反馈指针所在对象，不能替代或遮盖选中。键盘焦点独立可辨，禁用与未选中不同。普通辅助底色不能冒充选中底色，状态色不能只靠颜色表达。

左侧局部索引以检查准备的材料目录为样式基准，使用无独立实底的连续行、浅蓝整行选择和左侧位置线。行高可随内容增长，图标、名称、短状态和方向各有轨道；不按页面重新发明圆角、背景、悬停或选择动画。该规则限定同类局部入口，不将全局侧栏、页签、表单选择和多选框混成一种控件。

## 选中与状态的颜色职责

导航选中、键盘焦点和业务状态分别表达，不在一条短导航中叠加多个强色。全局协作入口的状态作为次要文字：未选中使用辅助文字色，选中沿用选中前景；状态名称保留，不用黄色强调普通待回复。局部连续索引上的短状态文字同样继承选中前景，避免红、绿、黄文字直接铺在浅蓝选中底上；确需保留的结果图标或独立状态徽标继续使用自身形状与成对语义表面。

普通说明和正常待准备默认中性，正常进行与等待业务回复使用信息强调，取得对应结果使用成功色；需防止误操作、未知回执、读取异常和准备条件失效才使用警告，实际失败与错误使用错误色。任务进展不等同权限结论，规则中的允许、禁止和预期结果使用中性文字与明确符号；角色类别和步骤记录的授权决定也不使用成功或失败色。红绿结果色留给实际执行状态与核验结果。不能为了减少彩色而隐藏未知、安全边界或真实失败。

语义文字与所属背景成对使用，普通小字按至少4.5:1核对；关键图形和焦点另按适用要求检查。两套主题分别核对，包含真实渐变、悬停、选中和禁用背景。第三方组件的错误、警告、成功、信息色及危险菜单反馈由公共适配接入同一组令牌，不沿用另一套默认色。新的页面布局继续引用已采纳的颜色角色，不随页面调整底色。

## 空间、阅读与对齐

内容决定宽度和高度。短表单使用适合阅读的字段宽度，目录与证据比较使用可用宽度；相关信息之间不能因容器铺满而被拉到远端。内容结束后的页面留白可以保留，禁止用装饰、虚构状态或最小高度填满。左右区域按阅读任务分配，默认顶部对齐，各自自然结束。

同组距离小于分区距离。局部标题到首项通常 12–16px，标签与值约 6px，名称与短状态 8–12px，独立分区约 20–28px。按真实长文字和窗口校准，避免父级 gap、标题 margin 和内边距叠加。

已有条目与“添加动作、添加步骤”等追加操作属于不同分组，使用共享 `IndexActions` 保留约 24px 的组间留白，追加操作图标和条目图标沿同一轴线排列。索引行保留足够的垂直内边距，编号、名称和方向之间各自留出空间，长名称自然增高。该规则同步到场景、接口流程、材料、结果和协作的同类索引；数据表、徽标和标签内的紧密关系继续按内容校准，不能把全部小间距机械改成分区间距。

有边界的内容在四边保留完整内边距；桌面工作面通常采用24px，窄窗按内容降至16–20px。目录列与相邻详情分别保留阅读内边距，方法、名称与路径使用同一列轨道，按 DELETE、OPTIONS 等最长方法校准。同层导航的选择带左右采用相同内缩，不能一侧贴边、一侧留空。

悬停或选中后才出现的底色也属于有边界的表面。整块统计与整行入口保留完整四边内边距，不能继承纯文字按钮的零内边距；用网格排列时同时核对内容轨道是否被共享按钮的居中规则收窄。图标按钮以固定热区居中，表格入口按单元格已有内边距核对，不机械叠加第二份留白。

名称、图标和状态共用整行对齐：徽标按中心，纯文字数量按共同基线。标题不携带单侧段落间距，不用固定偏移补偿旧布局。表头与正文共用列定义和内边距；文字列对齐起点、短状态列对齐中心、数值与操作列对齐右边界。长文字允许换行，路径和编号不撑破容器。

状态先归属对象。单对象的短状态紧接名称，可比较目录保留共享状态列；说明留在名称下面。主操作在任务收口，短行内操作就近。不能把全部状态推到最右，也不能将所有内容堆在左侧。窄属性单元优先标签在上、值在下，避免再嵌固定宽键值列。

主推进按钮位于所属任务区域右下角；直接说明和下一步放在同一操作组，不能把说明留在整行远端。整批进度可以独立置于左侧。报告状态图标与标题本行对齐，辅助标题和元数据沿标题文字起点排列。

## 通用审查规则

截图反馈应先还原为任务和关系，再检查同根因的全部消费者。每条规则只有一个事实所有者，不为一次截图或实施批次另写一套规范。

| 检查对象 | 判据 |
| --- | --- |
| 重复入口 | 同对象、同目的地、同一上下文保留一处正文动作。全局导航、准确对象深链接和回程入口各有职责，不按 URL 相同机械删除。空状态承担创建动作时，标题不重复提供同义动作。 |
| 说明与术语 | 使用对象和动作解释当前后果。源码关联、部署版本、地址连通、身份有效、材料就绪、执行结束和权限结论分别表达。避免没有实际任务的“当前业务动作”及装饰流程图。 |
| 核心能力 | Agent 等高价值入口保留名称和真实状态，图标与悬停提示不能独自说明能力。实例和示例归应用切换及明确管理工作面。 |
| 控件一致性 | 同类按钮、选择器、状态、页签、菜单与浮层复用共享实现。业务层只改尺寸、密度和排列，不重写选中色或争夺优先级。 |
| 内外边界 | 文字、选中表面、图标和箭头均有内边距；通知与表格、表单和卡片之间保留独立间距。检查全部四边，不只看是否出现整页横向滚动。 |
| 空白与平衡 | 先调整信息分组、目录和详情比例，再决定宽度；不靠统一缩窄、左右拉开或添加装饰遮盖缺少内容关系的问题。 |
| 标题与嵌套 | 主标题、局部分类和当前对象各承担一个层级。两个独立任务使用并列工作区，避免多层侧栏、卡片、页签套叠。 |
| 对象与创建入口 | 标题命名本区域的对象，创建入口与该对象同组；总任务标题不承接其中一个子集合的新增操作。例如“业务操作—添加操作”“业务结果—添加结果”。子对象保留所属对象的上下文，多条记录下不能串改其他对象。目录追加与空态创建按状态互斥。 |
| 初始、空与失败 | 初始状态说明可以开始的真实任务；筛选空态可恢复。读取失败保留标题、对象、原因及重试，不能让页面退化为孤立横幅，也不能显示默认成功。 |
| 动效 | 选择标记连续移动，局部内容有接续，展开锚点稳定；保留已认可节奏和减少动效支持。等待用户决定不持续旋转，动画不延迟事实或拦截操作。 |
| 证据 | 静态扫描、组件行为、真实浏览器和用户观感分别记录。全路由截图不等于全部业务分支验证，构建通过不等于视觉采纳。 |

审阅覆盖两主题、正常与空/失败、长名称、各类状态、键盘焦点以及代表窄窗口。完整页面用于判断整体层级，局部截图用于核对边界；不得只修用户圈出的几个像素。交付用户审阅时只选本次修改的重点工作面和关键状态，避免重复提供大量全量截图；检查范围与截图数量分别记录。
