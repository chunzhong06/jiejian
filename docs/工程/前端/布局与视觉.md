# 布局与视觉

界面首先帮助使用者找到当前任务、理解状态并采取下一步动作。侧栏提供稳定入口，顶栏保留应用上下文和全局状态，工作面组织当前对象；区域关系不能只靠卡片边框解释。

## 整体结构与设计取舍

当前工作台围绕完整任务建立连续工作面。主内容、相关状态和下一步操作共享边界，辅助条件退后一级；不同层级通过表面、对齐和信息密度区分。这样既能减少同等权重的卡片堆叠，也能避免将短内容和操作拆到宽容器两端。

| 区域 | 当前安排 | 解决的问题与边界 |
| --- | --- | --- |
| 侧栏 | 应用选择、主要业务流程、应用连接和官方示例，退出位于底部 | 保留明确的任务名称，低频全局工具不挤占流程 |
| 顶栏 | 可跳转的应用上下文、当前位置、开发工具、存储、主题及服务状态 | 工具入口保留名称提示和应用归属，不将陌生业务入口全部图标化 |
| 当前任务 | 标题、编辑或阅读内容、状态与主操作共用工作面 | 先建立信息联系，再决定列宽；不靠整体缩窄或全部左移掩盖空白 |
| 辅助阅读 | 检查条件、适用规则、草稿预览与保留范围退后一级 | 必要信息仍可查，不与主任务争夺相同视觉权重 |

宽屏可以把互补内容并列，但短字段不为占满宽度而强行分列。内容少时工作面自然结束，页面下方留白可以保留；对象之间出现的大段空白、状态与操作脱离所属对象，则应重新分组。窄窗口按任务顺序重排，不依赖固定最小高度维持版式。

## 画布与表面

保留浅色和雾蓝深色两套主题。浅色使用蓝灰画布、退后的导航底色、白色工作面和下沉的辅助区；深色保留雾蓝基调，以明暗区分相同职责。渐变只在画布顶部提供轻微过渡，不贯穿整页承担内容分组。颜色经语义令牌引用，业务页不另建调色盘。选中底色独立于普通辅助底色，并配合文字和定位标记；默认、悬停、选中、聚焦和禁用分别可辨，不能只在深色主题检查反馈。

完整任务或可比较对象可以使用卡片；连续同类信息优先行、表格和分隔线。主区域、辅助区和浮层使用不同表面强度，避免每段文字都套同等权重的框。阴影表达悬浮关系，不替代信息分组。

固定工作面默认不使用悬浮阴影。任务标题、主操作、内容和收口共享一个框架；嵌入材料与上下文用表面、分隔和对齐表达关系。菜单、浮层和对话框保留真实悬浮层级。公共规则改变后，仍须检查各页面是否保留自己的信息重点。

## 密度与阅读单元

名称、状态、说明和操作围绕同一对象组织。短内容不因窗口宽而拆到两端；也不把所有内容推到左边留下无意义空白。先决定信息之间的关系，再分配列和宽度。

| 任务 | 组织方式 | 阅读重点 |
| --- | --- | --- |
| 权限审阅 | 可比较的规则表与明确批准收口 | 谁能否对何种资源做什么 |
| 权限编写 | 连续编辑区、草稿预览与提交收口 | 先定义角色、操作与结果，再检查访问要求 |
| 材料准备 | 相邻的材料索引和当前详情 | 当前动作缺什么、从哪里补 |
| 账号准备 | 按真实身份成组，当前登录任务接在所属账号附近 | 同一账号用于哪些操作，当前需要登录还是恢复 |
| 检查报告 | 规则结果列表与依据阅读面 | 是否满足要求，再按需查证据 |
| 操作经过 | 连续步骤、状态和就近的记录入口 | 在哪一步形成事实 |
| 应用连接 | 源码与业务、按方式展开的应用运行、相邻检查条件 | 先区分配置目标与启动实例，再明确采用 |
| 开发工具 | 客户端索引、连接与授权共用工作面 | 选哪个工具，当前配置到哪里，下一步是什么 |
| 官方示例 | 当前实例及进入操作为主，管理菜单和归档记录为辅 | 继续、重启环境与重新开始各自影响什么 |
| 本地维护 | 当前影响、可选范围与执行回执 | 将处理什么、实际处理了什么 |
| 任务恢复 | 原任务、失败原因与可继续操作成组 | 查询已有结果还是由用户明确重新发起 |

材料准备把当前业务操作放入工作面标题，多项操作才显示切换；材料索引、当前材料和适用规则相邻。空间足够时具体材料与规则并列，空间不足时按阅读顺序堆叠；账户的身份、用途、状态和操作保持在同一单元中。

权限编写使用连续的编辑区和草稿预览，预览退后一级，提交与未完成事项就近。账号准备按真实账号成组，使用范围与登录操作在同一单元；当前登录任务接在清单内，宽屏将说明与步骤、操作并列，窄屏按实际顺序排列。登录中断后，将原因与恢复操作放在同一区域，避免只剩一个孤立在最右侧的按钮。任务入口同时显示动作和当前状态，等待用户输入不使用持续旋转图标，失败与进行中不能混用反馈。

应用接入按源码与业务、应用运行组织，检查条件退为相邻的紧凑清单。“连接已有应用”和“由界鉴启动”作为同一运行区域的两种编辑方式，一次只显示对应字段。选择项用标题、短用途和选中态表达关系；地址及提交、入口与端口及预览分别成组，主操作在所属区域右侧。实例启动后用实际地址、入口和管理操作替换启动表单，不重复铺开两套配置。当前检查目标与实例运行状态分别呈现，切换方式不会自动启动、停止或采用地址。条件与实际设置不重复提供同页查看入口，业务证明保留其准备入口。连接新应用时，任务说明与目录输入相邻，不将一个短表单拉成空白大卡片。异步状态只来自实际回执，布局调整不自动执行或重新提交任务。

开发工具将客户端选择、当前连接与应用授权放在连续工作面内。工具索引容纳完整名称，不将产品名称拆成独立两行；当前工具的状态与配置说明在左，配置操作在右，窄窗口再按内容宽度换行。官方示例围绕当前实例组织进入、管理与工作区链接，归档记录和实现切换退后一级。存储清理将候选项目与保留范围并列，数量、大小和选择对应同一类文件；没有数据时给出所属任务的下一步，不用介绍文字填满空间。共享的工作面标题、图标和路径样式由公共层加载；示例归档样式由示例页加载。直接进入或刷新页面不依赖先访问其他页面取得样式。

报告概览、逐项结果和依据共用连续工作面。结果多时使用列表和详情，只有一两项时将结果横排在依据上方，避免少量记录占据整条空列。宽依据面将实际结果、核对对象和证明记录按职责分区；操作步骤与本步记录相邻，不将短字段横拉到页面两端。

嵌套内容先共享阅读起点，再决定是否需要框。展开技术字段只使用必要宽度，长段正文维持可读行长。留白用于分组和节奏，不能用最小高度把本来属于一组的信息分散。

## 操作位置

页面主操作位于标题或任务收口；行操作跟随所属对象；对话框提交和取消组成底部动作组。下一步卡片可以左侧说明、右侧主操作，短对象内部操作则应就近。位置取决于任务结构，不规定所有按钮统一靠左或靠右。

常用操作直接可见，次要管理操作进入菜单。侧栏承载应用流程、应用连接和官方示例；开发工具与本地存储放在右上角，与主题切换组成全局工具组。图标入口提供名称提示、可访问名称和当前页状态，工具链接保留所选应用。窄窗口将服务状态缩为状态点，按钮仍保留完整可访问名称。刷新使用紧凑图标，退出保留侧栏底部入口。整行跳转覆盖完整可见范围，装饰不遮挡点击。

## 排版与几何

当前字号使用 12、14、20、28px，分别承载元信息、正文、分组和页标题。优先用字重、颜色和间距表达关系，不继续增加字号，最小文字不低于 12px。

控件、表面和浮层圆角分别为 8、12、16px。嵌套时结合真实内边距核对内外轮廓，避免机械相同圆角。图标按视觉中心对齐；多行文字旁的状态对齐首行，不能以容器居中掩盖错位。

布局验证先看同类页面是否共享规则，再检查两套主题、长文本、空状态和窄窗口。没有相应变化时不要求重拍全部页面。具体颜色、圆角和阴影以 `shared/styles/tokens.css` 为当前实现，动态行为见[交互与动效](交互与动效.md)。
