# 布局与视觉

界面首先帮助使用者找到当前任务、理解状态并采取下一步动作。侧栏提供稳定入口，顶栏保留应用上下文和全局状态，工作面组织当前对象；区域关系不能只靠卡片边框解释。

## 整体结构与设计取舍

当前工作台围绕完整任务建立连续工作面。主内容、相关状态和下一步操作共享边界，辅助条件退后一级；不同层级通过表面、对齐和信息密度区分。这样既能减少同等权重的卡片堆叠，也能避免将短内容和操作拆到宽容器两端。

| 区域 | 当前安排 | 解决的问题与边界 |
| --- | --- | --- |
| 侧栏 | 应用选择、主要业务流程、应用连接和官方示例，退出位于底部 | 保留明确的任务名称，低频全局工具不挤占流程 |
| 顶栏 | 可跳转的应用上下文、当前位置、开发工具、存储、主题及服务状态 | 工具入口保留名称提示和应用归属，不将陌生业务入口全部图标化 |
| 当前任务 | 标题、编辑或阅读内容、状态与主操作共用工作面 | 先建立信息联系，再决定列宽；不靠整体缩窄或全部左移掩盖空白 |
| 辅助阅读 | 检查条件、适用规则、草稿预览与保留范围退后一级 | 必要信息仍可查，不与主任务争夺相同视觉权重 |

宽屏可以把互补内容并列，但短字段不为占满宽度而强行分列。内容少时工作面自然结束，页面下方留白可以保留；对象之间出现的大段空白、状态与操作脱离所属对象，则应重新分组。窄窗口按任务顺序重排，不依赖固定最小高度维持版式。

## 画布与表面

保留浅色和雾蓝深色两套主题。浅色使用蓝灰画布、退后的导航底色、白色工作面和下沉的辅助区；深色保留雾蓝基调，以明暗区分相同职责。渐变只在画布顶部提供轻微过渡，不贯穿整页承担内容分组。颜色经语义令牌引用，业务页不另建调色盘。选中底色独立于普通辅助底色，并配合文字和定位标记；默认、悬停、选中、聚焦和禁用分别可辨，不能只在深色主题检查反馈。

完整任务或可比较对象可以使用卡片；连续同类信息优先行、表格和分隔线。主区域、辅助区和浮层使用不同表面强度，避免每段文字都套同等权重的框。阴影表达悬浮关系，不替代信息分组。

固定工作面默认不使用悬浮阴影。任务标题、主操作、内容和收口共享一个框架；嵌入材料与上下文用表面、分隔和对齐表达关系。菜单、浮层和对话框保留真实悬浮层级。公共规则改变后，仍须检查各页面是否保留自己的信息重点。

## 密度与阅读单元

同一阅读单元内的距离小于不同单元之间的距离。标题、紧接的说明与内容保持连续；不要把父容器的 `gap`、标题外边距和子区内边距叠加成无意的大段空白。局部标题与首项内容通常相隔 12 至 16px，属性标签与值相隔 6px，对象名称与短状态相隔 8 至 12px；独立分区再使用 20 至 24px 等较大的间距。数值用于当前密度校准，不替代长文字与实际窗口检查。

窄弹层和多列摘要使用标签在上、值在下的属性组，同组共享文字起点。不要在一个已经很窄的属性单元里继续套固定宽标签列；较长名称、路径和结果值应自然换行。宽工作面中的行式键值表仍保留统一的值起点。

状态首先属于具体对象。单个对象的状态紧随名称；少量独立结果可以并列成单元，名称与状态在单元内相邻；反复比较的材料索引和数据表保留共享状态列。动作属于任务收口时可以靠右，不能据此把只读短状态也推到容器尽头。已完成修复依次呈现结果、复验范围与修改、报告操作，避免较长的辅助栏撑高短结果区。

表头和正文必须共用列定义及水平内边距，不能分别用两套宽度模拟表格。文本列沿同一文字起点，短状态列沿同一中心轴，数值与操作列沿同一右边界。状态标签包含自身留白时，按文字与整体视觉轴核对，不把标签外框的左边缘当作文字对齐。检查长内容换行、不同状态长度、水平滚动及窄窗口，不能只核对第一行。

材料索引使用固定图标列、可伸缩名称列、独立的右侧状态列和方向列。状态不嵌在名称下方；为窄列简化显示词时，详情仍保留完整原因。权限规则使用逐条规则表，访问要求、适用条件、检查情况和最近检查共享列。一条规则有独立条件与结果时必须独占一行，不把同角色的多条条件规则竖直塞进同一格，造成其他角色列的大段空白。

同类问题按下列规则检查整个前端，修复落在共用组件或所属布局，避免只给一张截图增加局部补丁。

| 通用规则 | 适用方式与边界 |
| --- | --- |
| 同类控件只有一个实现入口 | 选择、输入、按钮、状态和浮层复用公共规则，页面只改变内容与排列；不同交互语义不强制合并 |
| 表面包住内容 | 文字、图标、选中态与箭头均有内边距，不能贴边；表格分隔线和进度轨道按自身职责保留 |
| 同一对象共享阅读行 | 清单名称、状态使用稳定列，说明接在名称下方；不把短状态再叠成独立段落 |
| 推进操作属于任务收口 | 宽屏说明与操作分工，提交与继续在所属区域右侧；短行内操作就近，窄屏允许自然换行 |
| 空白由信息关系决定 | 优先调整对象分组、列与操作归属，不靠把全部内容左移、缩窄容器或补解释文字填空 |
| 反馈不改变阅读位置 | 展开、选中和等待保留控件边界、当前对象与焦点；当前状态和历史记录分开表达 |

接入进度使用名称、状态和简短说明组成的清单。状态与名称同排，说明位于名称下方，区域收口提供继续操作；已有运行记录或来源配置不使用“已确认”的成功标记。权限草稿的未生效状态属于预览标题，开发工具的应用授权属于所选范围，不能因为它们处在侧栏就将全部内容竖直堆在左侧。

首次编写还没有输入时，未完成项以可展开清单收纳，保留具体缺口到编辑区的入口。辅助清单不撑高整块空白表单；当前编辑与下一步仍直接可见。证明管理已在任务收口内，不重复增加局部分隔线。页面覆盖按钮密度时保留文字两侧留白，不能把水平内边距清零来伪装成正文对齐。

名称、状态、说明和操作围绕同一对象组织。短内容不因窗口宽而拆到两端；也不把所有内容推到左边留下无意义空白。先决定信息之间的关系，再分配列和宽度。

| 任务 | 组织方式 | 阅读重点 |
| --- | --- | --- |
| 权限审阅 | 一条规则一行的比较表与明确批准收口 | 谁能否对何种资源做什么 |
| 权限编写 | 连续编辑区、草稿预览与提交收口 | 先定义角色、操作与结果，再检查访问要求 |
| 材料准备 | 相邻的材料索引和当前详情 | 当前动作缺什么、从哪里补 |
| 账号准备 | 按真实身份成组，当前登录任务接在所属账号附近 | 同一账号用于哪些操作，当前需要登录还是恢复 |
| 检查报告 | 规则结果列表与依据阅读面 | 是否满足要求，再按需查证据 |
| 操作经过 | 连续步骤、状态和就近的记录入口 | 在哪一步形成事实 |
| 应用连接 | 源码与业务、按方式展开的应用运行、相邻检查条件 | 先区分配置目标与启动实例，再明确采用 |
| 开发工具 | 客户端索引、连接与授权共用工作面 | 选哪个工具，当前配置到哪里，下一步是什么 |
| 官方示例 | 当前实例及进入操作为主，管理菜单和归档记录为辅 | 继续、重启环境与重新开始各自影响什么 |
| 本地维护 | 当前影响、可选范围与执行回执 | 将处理什么、实际处理了什么 |
| 任务恢复 | 原任务、失败原因与可继续操作成组 | 查询已有结果还是由用户明确重新发起 |

材料准备把当前业务操作放入工作面标题，多项操作才显示切换；材料索引、当前材料和适用规则相邻。空间足够时具体材料与规则并列，空间不足时按阅读顺序堆叠；账户的身份、用途、状态和操作保持在同一单元中。

权限编写使用连续的编辑区和草稿预览，预览退后一级，提交与未完成事项就近。账号准备按真实账号成组，使用范围与登录操作在同一单元；当前登录任务接在清单内，宽屏将说明与步骤、操作并列，窄屏按实际顺序排列。登录中断后，将原因与恢复操作放在同一区域，避免只剩一个孤立在最右侧的按钮。任务入口同时显示动作和当前状态，等待用户输入不使用持续旋转图标，失败与进行中不能混用反馈。

应用接入按源码与业务、应用运行组织，检查条件退为相邻的紧凑清单。“连接已有应用”和“由界鉴启动”作为同一运行区域的两种编辑方式，一次只显示对应字段。选择项用标题、短用途和选中态表达关系；地址及提交、入口与端口及预览分别成组，主操作在所属区域右侧。实例启动后用实际地址、入口和管理操作替换启动表单，不重复铺开两套配置。当前检查目标与实例运行状态分别呈现，切换方式不会自动启动、停止或采用地址。条件与实际设置不重复提供同页查看入口，业务证明保留其准备入口。连接新应用时，任务说明与目录输入相邻，不将一个短表单拉成空白大卡片。异步状态只来自实际回执，布局调整不自动执行或重新提交任务。

开发工具将客户端选择、当前连接与应用授权放在连续工作面内。工具索引容纳完整名称，不将产品名称拆成独立两行；当前工具的状态与配置说明在左，配置操作在右，窄窗口再按内容宽度换行。官方示例围绕当前实例组织进入、管理与工作区链接，归档记录和实现切换退后一级。存储清理将候选项目与保留范围并列，数量、大小和选择对应同一类文件；没有数据时给出所属任务的下一步，不用介绍文字填满空间。共享的工作面标题、图标和路径样式由公共层加载；示例归档样式由示例页加载。直接进入或刷新页面不依赖先访问其他页面取得样式。

报告按独立概览、纵向结果列表和有边界的依据阅读面分区。少量结果沿用相同列表，不横排成大页签。打开依据后，结果列表保留规则、资源和一句实际结果；右侧集中显示所选项，账号与资源组成紧凑属性组。正常功能与原问题对照共用检查事实，详细记录按需展开。窄屏进入单一阅读面，并能返回本轮结果。

单条证据先展示记录名称、证明类别和记录中的值，再说明采集方式与记录关联。简短属性组成紧凑网格，业务前后值保留各自含义；长说明按阅读宽度自然换行。规则背景及已发布判断、适用范围及封存原文分别展开，避免每条过程记录重复一整轮检查说明。类别只标明业务证明或辅助记录，不用成排勾号暗示记录本身已经证明权限安全。展开入口位置稳定，继续使用公共展开动效；宽屏的两个说明组并列，窄屏依阅读顺序排列。

复验行的当前结果、查看依据和历史展开入口各自保留固定阅读起点。展开只增加下方内容，不改变触发器的宽度、外边距、内边距或所在列；历史属性的底色属于展开内容，不能包住触发器后再重新排版。

版本更新共用一个工作面：当前版本与工作区位于顶栏，下方只展示当前操作阶段。未选择目录时显示表单，预览时显示目标与影响，交接时显示真实进度，完成时显示成果接续和返回应用。路径及交接位置按需展开，选择下一份发行退为次要操作；完成回执不与空白更新表单同时占据主区。

规则详情保留稳定的对象标题和阅读宽度，页签紧接当前工作面。检查结果、修复与修改、检查历史一次只呈现一项，登记表单只属于修复工作面，不插在三个视图共用的上方。从具体问题进入登记时定位到对应表单；切换其他页签后回到其内容，重新打开登记仍保留说明草稿。长内容滚动时保留局部页签，普通切换不抢走键盘焦点。

检查范围按业务操作逐项排列，每项将账号和核对结果、缺口及处理入口并列分工。相同操作中指向同一准备入口的缺口可以合组，必须保留不同原因和原始结果定位；不同操作不合并成一条笼统提示。可执行时显示实际检查场景，缺材料时显示准确原因和具体补充动作。窄工作面按先对象、后准备的顺序排列，不将短信息拉成整行空白卡片。

嵌套内容先共享阅读起点，再决定是否需要框。展开技术字段只使用必要宽度，长段正文维持可读行长。留白用于分组和节奏，不能用最小高度把本来属于一组的信息分散。

## 操作位置

页面主操作位于标题或任务收口；行操作跟随所属对象；对话框提交和取消组成底部动作组。下一步卡片可以左侧说明、右侧主操作，短对象内部操作则应就近。位置取决于任务结构，不规定所有按钮统一靠左或靠右。

常用操作直接可见，次要管理操作进入菜单。侧栏承载应用流程、应用连接和官方示例；开发工具与本地存储放在右上角，与主题切换组成全局工具组。图标入口提供名称提示、可访问名称和当前页状态，工具链接保留所选应用。窄窗口将服务状态缩为状态点，按钮仍保留完整可访问名称。刷新使用紧凑图标，退出保留侧栏底部入口。整行跳转覆盖完整可见范围，装饰不遮挡点击。

跨页面的应用协作入口位于固定顶栏，和页面自身的标题操作分开。没有任务时显示“开始协作”，已有任务时显示“继续协作”，进入准确任务并保留所属应用；目标和状态可从提示与任务页查阅。窄窗口缩为带可访问名称的图标，不再在正文上方单独占一行。页面标题只保留当前对象的管理与推进操作，不因协作任务存在而改变位置。

## 排版与几何

当前字号使用 12、14、20、28px，分别承载元信息、正文、分组和页标题。优先用字重、颜色和间距表达关系，不继续增加字号，最小文字不低于 12px。

控件、表面和浮层圆角分别为 8、12、16px。嵌套时结合真实内边距核对内外轮廓，避免机械相同圆角。图标按视觉中心对齐；多行文字旁的状态对齐首行，不能以容器居中掩盖错位。

布局验证先看同类页面是否共享规则，再检查两套主题、长文本、空状态和窄窗口。没有相应变化时不要求重拍全部页面。具体颜色、圆角和阴影以 `shared/styles/tokens.css` 为当前实现，动态行为见[交互与动效](交互与动效.md)。

## 展开时保持画布位置

根滚动区域预留稳定的竖向滚动条空间。折叠内容超过一屏时，居中的工作面、标题和操作不会因为新出现的滚动条横向移动。展开触发器不改变宽度或外层布局，内容在下方自然扩展；保留现有过渡、键盘操作与减少动态效果设置。

应用连接采用设置与接入进度的主次分区，运行配置和启动确认各有独立内容面。状态不因展开表单自动变成横向平铺；配置很长时先分组、逐步呈现，不靠把所有字段铺满宽度解决空白。账号采用列表与当前账号详情，登录、等待、保存结果出现在同一工作区；管理操作按需展开。复杂接口设置按起点、账号与数据、操作与恢复、确认使用分步完成，返回上一步保留草稿。

检查预览使用操作摘要与场景表：账号、权限要求、数据所有者和测试数据共享列，避免短摘要与长场景清单等高并列。结果证明完成后不再叠加多块成功提示，保留对象状态、准备过程和可查证的读取内容。

## 信息关系与操作层级

首先让使用者识别当前对象、需要处理的事和下一步，再决定分栏。单个目标、短结论和状态组成相邻的阅读单元；记录较多时使用紧凑、可比较的列。不能把“右侧操作”扩展成所有状态都推到最右，也不能把“内容靠近”扩展成整页全部堆左。

复杂表格中的一行必须表示同一项事实。权限表将谁可以或不可以做什么、资源范围作为主信息，租户与数据状态作为适用条件，检查结果独立成列；同角色有多个条件时分别成行。搜索、筛选、详情入口保留准确规则引用，简化展示不简化权限含义。

协作任务共用连续工作面：目标与状态相邻，当前需要的启动、继续、确认或结果阅读突出显示。完成后的结果取代待办；没有处理记录时不画空记录区。关联资料收在“本任务资料”，不与当前动作等权平铺；暂停、结束、停止等管理命令进入“任务操作”，更换执行方式和工具连接按需展开。主报告已有阅读入口时，不在资料中重复同一入口；原问题报告仍独立保留。

全站按“当前推进、对象内操作、辅助资料、管理命令”检查入口层级。同一状态下只突出当前任务的推进动作，独立对象和需要明确选择的业务决定可以有各自操作。表单的取消、返回、提交，以及列表各行的详情入口不因总数多就强行合并。

重复消息按原因组织：同一原因集中说明，相关对象和准确处理入口在展开内容中保留。可执行性、权限授权、未知回执及历史证据继续由原业务用例决定，界面分组不能隐藏独立问题或放宽检查范围。
