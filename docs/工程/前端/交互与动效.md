# 交互、反馈与动效

用户应先确认操作被接受，再看状态发生了什么变化。动效表达方向、层级和连续性，不能遮掩接口等待、延后可读内容或替代错误处理。

## 按任务选择呈现

| 情形 | 呈现 | 必须保留 |
| --- | --- | --- |
| 图标的简短含义 | 延迟短提示 | 独立可访问名称，不遮主要动作 |
| 非阻断运行详情 | 附着入口的轻量浮层 | 明确来源与关闭方式 |
| 连续阅读依据 | 保留上下文的详情面 | 当前选中对象与返回位置 |
| 接受重要状态变更 | 对话框 | 实际影响、明确动作和取消 |
| 多步骤审阅或准备 | 页面工作面 | 当前对象、进度与缺口 |

菜单、浮层和模态不混用。Escape 可关闭相应层级，关闭后焦点回到发起位置。对话框内浮层归属该对话框；关闭图标获得初始焦点时不立即弹提示遮挡内容。

## 控件状态

主、次、轻量、危险和图标按钮表达动作层级。透明边框可以保留尺寸；同组有框与无框的差异应来自明确层级，不随组件来源偶然变化。名称、字体族、点击范围、忙碌和禁用规则保持一致。

默认、悬停、选中、键盘聚焦与按下分别表达。悬停零延迟命中，进入 50ms、离开 40ms；状态遮罩单独变化，按下立即反馈。背景变化不能只修改很小的文字区域，也不能因整页透明度尚未完成而延迟出现。

普通动作共用主、次、轻量和危险四种按钮变体；页面只按密度调整尺寸与排列，不另造颜色、边框或圆角。卡片选择、页签和导航使用各自的选中语义。鼠标操作以底色反馈，键盘导航保留可见焦点；浮层关闭后恢复焦点，随后移动鼠标时不残留键盘焦点框。分隔线独立于按钮，不参与悬停底色。

展开箭头随真实展开状态旋转，当前时长 160ms；页签指示器 120ms。方向变化可以打断，装饰不拦截指针。

## 页面连续性

| 对象 | 当前参数 | 使用边界 |
| --- | --- | --- |
| 页面工作面 | 旧面退出 100ms，新面交接 220ms | 框架稳定，工作面小幅位移 |
| 加载内容 | 必要时揭示 100ms | 只处理首次事实到达，不重播后台刷新 |
| 非原生页面回退 | 可取消入场 180ms | 不等待退场后才发请求 |
| 页内替换 | 160ms | 不触发整页快照 |
| 菜单与轻量浮层 | 淡入 160ms，淡出 100ms | 定位容器保持实际尺寸，不叠加缩放 |
| 阅读面板与对话框 | 进入 200ms，退出 100ms | 表达层级，不延迟输入 |

快速导航立即接受新目标，跳过旧过渡并丢弃陈旧读取，不能排队播放每次切换。主题同步切换配色，使用可取消的 100ms 轻淡入，保留整页点击能力。减少动效时移除动画与位移，导航、焦点和状态保持可用。

这些参数描述当前配置，不是流畅程度的保证。出现停顿时，先区分指针命中、CSS 状态、主线程长任务、模块加载、数据请求和动画叠加，再决定修复位置；不能仅靠继续缩短时间处理所有问题。

## 异步和文案

初次读取采用真实标题和结构占位，不生成假计数、通过状态或按钮。后台刷新保留已有内容；写入忙碌态防重复操作，回执未知查询原动作。

正文说明对象、要求和实际结果。技术名词、代码、摘要和节点位置按需展开；证据不足只列必要缺口和影响，适用范围集中表达。避免冗余辅助标签、重复解释及中点分隔，让布局与状态承担组织工作。

改动哪一类交互就验证哪一类：控件检查指针和键盘；导航检查快速正反向切换；过渡检查普通与减少动效；写入检查成功、拒绝和未知回执。真实动态观察与自动化分别说明，不能由静态截图推断丝滑程度。
