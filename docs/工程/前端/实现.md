# 前端实现与数据寿命

前端拥有展示、导航和当前交互状态，服务拥有运行事实与安全判断。页面不根据颜色、执行成功或本地计数重新推断 verdict。

## 模块所有权

| 层 | 职责 | 边界 |
| --- | --- | --- |
| `app` | 路由、项目选择、主题、全局错误和导航框架 | 不堆入页面业务表单 |
| `pages` | 完整任务、局部详情与页面样式 | 跨页面逻辑按真实所有者提取 |
| `entities` | 应用、规则、准备、检查和修改的 API 与契约 | 不依赖具体页面 |
| `shared` | 传输、读取取消、通用控件、导航基础和语义令牌 | 不导入业务实体或页面 |

组件从声明模块导入，避免公共 barrel 把无关业务一起加载。局部 CSS 随路由加载，只有真实共用的规则才提升到公共层；样式与事件不跨层偷偷接管业务状态。

行为测试留在所属模块旁，页面专属冻结样例也留在页面测试附近。`tooling` 集中维护 Vite 配置、Vitest 环境初始化与编辑器解析插件；包命令通过明确的配置路径接入，tsconfig 保留在前端根供编辑器自动发现。`tooling/vitest.setup.ts` 只由 Vitest 加载，负责 DOM 清理与缺失浏览器 API 的替身。开发工作区同步测试输入，类型检查覆盖初始化文件，产品入口不导入这些测试设施。

pnpm 工作区明确只包含前端根包；编辑器解析器是开发工具输入，单独安装到受控编辑器依赖视图。包清单、锁文件、工作区范围与插件输入共同决定依赖身份，范围变化必须重新准备依赖，不能只同步文件后沿用旧安装记录。

## 代码加载与业务读取

路由模块使用独立加载器，缓存已解析组件并通知当前订阅者。模块就绪即可挂载，业务数据再显示所属占位，避免代码和数据共用 Suspense 回退周期而额外等待。离开页面解除订阅，迟到模块不能覆盖当前任务。

侧栏可预取模块，但不提前挂载页面或触发业务写入。面包屑父级为真实链接，当前项标记当前位置；页签等局部选择不重播整页过渡。

`useApplication` 管应用上下文，完整工作区用于概览和修改工作面。准备页直接读取 preparation 与必要批次状态，名称、缺口和推荐操作来自自身投影，避免为了一个名称等完整历史。

## 请求所有权

HTTP 传输合并同代并发只读请求，写入使旧读取失效；写请求不盲重试。`useRead` 用 key 区分对象，离开时取消请求并丢弃迟到响应。已有数据刷新不清空工作面，首次读取提供结构占位，错误在所属位置处理。

读取缓存只服务显示。预览、提交与执行门禁继续核对当前服务事实，不能使用前端缓存充当批准或冻结输入。

## 过渡所有权

支持 View Transitions 时只捕获 `jj-workspace`，在快照更新回调内提交路由。新导航跳过旧过渡，旧完成回调不能清除新状态。主题使用独立根快照，页面局部变化不参与根交接。

不支持时直接导航，由 PageSurface 提供可取消入场；减少动效时直接呈现。首次内容揭示与导航分开，不重播后台读取，不对整个应用重复淡入。具体参数见[交互与动效](交互与动效.md)。

## 字体选择

根与 Portal 共用 `--font-ui`。MiSans 使用独立字体别名与预加载，首次挂载前最多等待 80ms：及时可用则采用，否则本次文档固定后备字体。迟到字体不再次激活，后开的菜单继承同一选择。

代价是首次选择增加至多 80ms 等待，慢速首次文档可能使用后备字体；下一次文档可受益于缓存。字体资源尚未压缩，`font-display: optional` 不是唯一防闪换措施。

## 验证边界

普通类型检查保护契约连接；确定性组件测试保护焦点、取消和状态；真实浏览器补足渲染、字体和原生过渡。字体变化需延迟请求并观察字形宽度，截图前等待 `document.fonts.ready` 不能证明没有闪换。

只改说明无需执行全量界面验收；改变读取、导航或真实字体行为时，再选择对应测试与动态观察。结构、主题和业务结论分别核对，避免将某一层通过扩展成全产品通过。
