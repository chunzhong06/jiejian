# 前端实现与数据寿命

前端拥有展示、导航和当前交互状态，服务拥有运行事实与安全判断。页面不根据颜色、执行成功或本地计数重新推断 verdict。

`ObjectHeading` 拥有对象名称、短状态、装饰图标与说明的组合。图标列按标题层级的首行行高对齐，文字列保持标题、换行状态与说明的共同起点；调用方只提供事实和标题层级。`Heading` 的装饰标题图标同样按首行行盒居中。对象头、步骤与反馈不再以页面专用标题边距或图标偏移补偿对齐；内容表仍由行列轨道管理状态。

`SectionHeading` 的 `level` 负责语义大纲，`appearance` 负责 collection、group、caption 三类视觉组合；普通标题需要紧凑角色时使用同一组 `jj-title-*` 预设。字号、行高、字重只由共享基础样式拥有，业务选择器不得重新定义；保留页面标题和普通 HTML 标题的默认回退。

## 持续工作入口

侧栏主任务为工作台、权限与覆盖、测试、问题；应用与来源位于资料区，Agent 协作在其下方独立同级。应用切换菜单统一选择、新建及官方示例；设置图标和文字位于侧栏底部；顶栏保留上下文、刷新、主题及最右侧退出。界面模式与视觉分别由[工作面模式](工作面模式.md)和[布局与视觉](布局与视觉.md)维护，本页记录技术所有权。

`pageRefresh` 只登记当前挂载的读取回调，`useRead` 在同一读取生命周期中接收刷新结果、保持数据并拦截失效响应。全局刷新不重挂页面、不重放写入；连续点击共享在途刷新。运行诊断可提供独立的缓存更新 reader，存储扫描等非 `useRead` 所有者通过 `usePageRefresh` 接入并保留原忙碌门禁；错误通知不再持有各自的重读动作。

AppShell 持有稳定的协作实例，桌面与移动导航仅迁移触发器的 Portal 挂载点；目标面板独立挂载到正文。关闭移动导航不重置草稿及未知回执编号。协作读取失败只查询原任务，不当成不存在而创建；目标示例仅改输入，建立任务不自动启动模型。

应用资料按分类加载，环境与源码草稿归稳定父级。来源草稿保留开始编辑的修订，人工关联独立于来源修订；来源更新使用所选请求的真实 source_id。切换应用显式重建对象状态，应用创建成功清除创建视图，不改原应用资料。导入原文只留当前内存，公开恢复输入仅保留净化候选、来源与预期修订；未知保存先读原操作。

规则和场景目录复用 shared 的连续表格与详情框架；问题和请求索引拥有局部布局。测试复用 entities/preparation/ui/OperationFlowEditor，页面间不互相导入。原 /preparation、/reports 及精确规则、问题、来源、试运行深链接持续可读。问题和报告只展示已发布事实，材料是否就绪由 preparation 投影给出。

`Notice` 默认中性且限制为公共语义类型，已有风险提示明确声明 caution，不能依赖默认值表示风险。协作生命周期的颜色映射由协作实体统一拥有，正常等待不映射为警告；Verdict、身份与准备状态仍由各自所有者表达。`IndexSelection`拥有选中行的文字前景，局部状态不直接在选中背景上覆盖另一种文字色。UIProvider同步第三方组件的语义令牌，危险菜单的悬停保持对应浅底和文字色。

整窗背景由共享 `--window-background` 配方维护。应用壳、固定侧栏和顶栏均以同一视口尺寸及固定坐标绘制，固定栏因此可遮挡滚动内容，同时保持渐变连续；正文和主容器不再额外铺底。侧栏分隔的上下留白由壳层伪元素负责。普通表面、输入和浮层使用各自的不透明角色，浮层不透出后方的状态色。`UIProvider`同步主动作的悬停/按下、信息与结果色、占位及禁用色，第三方组件不重新选择一套颜色。

## 模块所有权

`DirectoryField` 只维护本机目录的文本输入、选择入口和布局，所属页面通过回调使用现有目录选择服务。API 适配统一将取消映射为保留原值、不可用映射为可解释错误；组件不能保存项目、读取目录或启动应用。补充源码仍提交当前应用标识及预期修订，继续由服务端维护来源与授权边界。

选择器由 `shared/ui/Choice.tsx` 拥有语义、选项和键盘行为，共用样式与 UIProvider 统一触发器、菜单和主题。业务页通过 `Field` 关联标签，提供值和回调；操作起点、账号、请求、恢复、登录方式及结果字段均复用这一入口。菜单定位归最近对话框或页面根，定位本体不缩放，继续使用公共展开和悬停动效。文本输入、文件上传和单选组各自保留真实语义，不以外观统一替代它们。

浮层宽度同时受视口和实际容器约束。对话框内的下拉菜单在打开、退场和窗口缩放时都保留容器内边距；不能只用视口宽度限制缓存尺寸，让已关闭但仍在退场的浮层撑大对话框滚动范围。选项文字允许换行，继续保留展开、退出动效和键盘操作。

| 层 | 职责 | 边界 |
| --- | --- | --- |
| `app` | 路由、项目选择、主题、全局错误和导航框架 | 不堆入页面业务表单 |
| `pages` | 完整任务、局部详情与页面样式 | 跨页面逻辑按真实所有者提取 |
| `entities` | 应用、规则、准备、检查和修改的 API 与契约 | 不依赖具体页面 |
| `shared` | 传输、读取取消、通用控件、导航基础和语义令牌 | 不导入业务实体或页面 |

组件从声明模块导入，避免公共 barrel 把无关业务一起加载。局部 CSS 随路由加载，只有真实共用的规则才提升到公共层；样式与事件不跨层偷偷接管业务状态。

重构后的工作面使用与职责对应的样式类，不能为复用外观继续挂载带有旧排版语义的容器类。请求详情、请求索引和证明来源索引分别拥有局部样式；除直接打开外，还需检查从其他页面返回后的结果，避免路由加载顺序改变标题间距、状态对齐或索引结构。

行为测试留在所属模块旁，页面专属冻结样例也留在页面测试附近。`tooling` 集中维护 Vite 配置、Vitest 环境初始化与编辑器解析插件；包命令通过明确的配置路径接入，tsconfig 保留在前端根供编辑器自动发现。`tooling/vitest.setup.ts` 只由 Vitest 加载，负责 DOM 清理与缺失浏览器 API 的替身。开发工作区同步测试输入，类型检查覆盖初始化文件，产品入口不导入这些测试设施。

pnpm 工作区明确只包含前端根包；编辑器解析器是开发工具输入，单独安装到受控编辑器依赖视图。包清单、锁文件、工作区范围与插件输入共同决定依赖身份，范围变化必须重新准备依赖，不能只同步文件后沿用旧安装记录。

## 公共控件与阅读位置

文字角色、44px普通规格、36px紧凑规格与圆角由共享令牌拥有，`UIProvider`从同一来源为第三方选择器提供尺寸。页面只选择用途与排列，不能把操作文字改成12px辅助信息，或在选中时更改字号与字重。统计、时间使用等宽数字，路径继续保留等宽字体。

`Button`的忙碌指示覆盖原图文占位，不以另一套内容挤动操作组；完成标记由调用方的真实成功回执驱动。`Field`合并已有说明、提示与错误的可访问关联；失效选择保留原值，不自动选中其他对象。`PasswordInput`只在当前字段组临时显示，离开后遮蔽；`Switch`使用外部确认值，忙碌时拒绝再次变更，失败处理仍由业务用例负责。两者复用现有秘密和授权流程，不建立新的持久化状态。

菜单定位容器只控制可见性与命中，方向变化作用于内部表面。选择标记保留当前位置和速度，普通内容交接只在对象身份改变时发生；轮询或输入更新不重播整页。颜色变化平稳收束，不使用空间弹簧的过冲。

短命令菜单使用同一条居中行：前置图标、普通标签或链接、尾部标记共同对齐，不由行内图标基线决定位置。当前选择底色与指针悬停层分开，指针离开后不保留旧活动项的悬停填充；键盘当前候选继续有可见反馈。检查伪元素颜色前须确认其实际生成，不能把未绘制的计算样式当成屏幕颜色。

`CommandMenu`统一管理短命令菜单的展开、聚焦与退场，第三方库保留定位、菜单语义和方向键选择。打开时有限等待实际菜单挂载，聚焦当前项；关闭或禁用取消未完成的聚焦。退场沿用既有时长并禁用命中，由自身结束后卸载，不同时依赖第三方延迟聚焦和CSS结束事件。快速取消与反向展开仍须在真实浏览器核对，避免关闭后抢焦点或残留浮层；减少动效时立即结束。

复选框与单选框的基础样式单独继承标签行高，不沿用文本输入固定行高；标签按首行行框计算方框位置。公共标签规则应明确覆盖输入基础重置，页面只负责选择项的分组与排列，避免各处用固定偏移互相抵消。具体语义见[多行选择与审阅](交互与动效.md#多行选择与审阅)。

报告关闭依据时恢复最后选中项的焦点，滚动起点仍保留首次打开时的位置。选择对象与首次打开阅读面的定位分别持有，不能让后续切换仍返回第一个对象。

## 代码加载与业务读取

路由模块使用独立加载器，缓存已解析组件并通知当前订阅者。模块就绪即可挂载，业务数据再显示所属占位，避免代码和数据共用 Suspense 回退周期而额外等待。离开页面解除订阅，迟到模块不能覆盖当前任务。

侧栏可预取模块，但不提前挂载页面或触发业务写入。面包屑父级为真实链接，当前项标记当前位置；页签等局部选择不重播整页过渡。

`useApplication` 管应用上下文，完整工作区用于概览和修改工作面。准备页直接读取 preparation 与必要批次状态，名称、缺口和推荐操作来自自身投影，避免为了一个名称等完整历史。

## 路由与编辑状态所有权

路由名称、分类、项目范围、旧路径别名及预载目标由 `shared/lib/routes.ts` 静态登记。导航与设置分类消费登记项；`app/Router.tsx` 只维护具名懒加载器和业务查询参数分派。设置按实际分类预载，旧深链接继续可读；不为元信息统一引入新路由框架。

`useCommand` 只复用组件实例内的互斥、提交状态与失效响应隔离。明确拒绝如何分类、未知回执如何查询、是否重新提交，仍由调用用例拥有；两个组件不共享同一个命令状态。流程编辑草稿使用 `FlowEditorDraft` 和 reducer，完整解码后一次载入来源、身份、资源、步骤及恢复；保存回执与界面选择分别管理。

编辑草稿只留本次文档内存，必须声明所属应用。完成采用或保存后明确删除；应用归档清除其草稿，普通应用切换仍允许接续。sessionStorage 恢复输入只保留非秘密净化数据，声明形状检查的消费者在读取时拒绝坏数据；泛型类型本身不构成校验。

依据 [React 状态结构](https://react.dev/learn/choosing-the-state-structure)、[reducer](https://react.dev/reference/react/useReducer)及[自定义 Hook](https://react.dev/learn/reusing-logic-with-custom-hooks)收敛所有权，保持现有主题、字体、控件和动效。

## 请求所有权

HTTP 传输合并同代并发只读请求，写入使旧读取失效；写请求不盲重试。`useRead` 用 key 区分对象，离开时取消请求并丢弃迟到响应。已有数据刷新不清空工作面，首次读取提供结构占位，错误在所属位置处理。

同键读取的订阅者各自持有取消信号；一个页面离开只释放自己的订阅，最后一个订阅者离开才取消底层网络请求。带自定义请求选项的读取独立执行，避免把同路径但不同语义的请求合并。共享的是在途读取，不是永久数据缓存。

官方示例状态仅由示例页及概览中的真实示例对象读取；无关业务页不按固定间隔重复查询。日常系统状态使用轻量 summary，环境与静态资源完整核对使用有时间的诊断快照。构建清单或入口变化使快照失效，显式重新核对也会刷新。该快照只服务展示，不是安全门禁。

读取缓存只服务显示。预览、提交与执行门禁继续核对当前服务事实，不能使用前端缓存充当批准或冻结输入。

## 应用运行的状态与操作

`product/frontend/src/pages/connections/Connect.tsx` 负责当前项目、源码与业务和检查条件；`product/frontend/src/pages/connections/RuntimeConnection.tsx` 在同一区域负责运行方式、编辑草稿及启动回执。组件按 project_id 重新建立，项目切换不会沿用另一应用的输入。

| 状态 | 所有者与寿命 | 操作含义 |
| --- | --- | --- |
| 连接或启动方式、未提交的地址和入口端口 | 页面内编辑状态，方式切换时保留 | 只切换字段，不写入服务事实 |
| 启动预览及执行勾选 | 当前输入对应的局部确认 | 入口或端口变化使预览失效，启动前必须明确授权 |
| 尚未确认的启动标识 | 浏览器会话保留定位信息，服务端拥有操作回执 | 刷新查询原操作，明确恢复时复用原标识 |
| 运行实例、源码对应和终态 | 服务端运行事实 | 成功后显示实例；失败或取消后移除旧确认 |
| 当前检查地址 | 源码理解记录中的已确认地址 | 手工提交或采用实例地址均走同一确认接口 |

没有普通应用启动能力时不读取运行实例，也不露出启动方式。存在未确认启动时锁定方式切换，避免正在核对的任务被另一个表单遮蔽；终态到达后刷新实例事实和应用事实，不按本地猜测补成功。

“使用此应用”只改变访问目标，启动和停止仍由原运行 API、持久 Job 与 Worker 负责。界面重组没有另建后端协议或数据库结构，也没有把实际运行等同于安全结论。精确进程、实例和回执契约见[应用与运行](../能力/应用与运行.md#源码整理与运行连接分开)。

## 过渡所有权

支持 View Transitions 时只捕获 `jj-workspace`，在快照更新回调内提交路由。新导航跳过旧过渡，旧完成回调不能清除新状态。主题同步提交配色，再使用可取消的短淡入，不捕获整页快照，避免暂时暂停导航和业务控件的命中。页面局部变化不参与根交接。

不支持时直接导航，由 PageSurface 提供可取消入场；减少动效时直接呈现。首次内容揭示与导航分开，不重播后台读取，不对整个应用重复淡入。具体参数见[交互与动效](交互与动效.md)。

## 字体选择

根与 Portal 共用 `--font-ui`。MiSans 使用独立字体别名、高优先级预加载和中英文样本文字核验，首次挂载前最多等待 800ms：及时可用则采用，否则本次文档固定后备字体。迟到字体不再次激活，后开的菜单继承同一选择。

代价是首次选择增加至多 800ms 等待，慢速首次文档可能使用后备字体；下一次文档可受益于缓存。字体保持官方可变 TTF，构建时生成保持原字节的 gzip 静态表示，`font-display: optional` 不是唯一防闪换措施。

当前官方 WOFF2 为静态字重，尚未替换完整可变 TTF。图标改用包的独立入口；读取恢复监听、工作区修订提示及生产身份输入的规则见[性能与读取](../性能与读取.md#前端资源和刷新)。

## 分类模块与读取归属

模块加载机制由 `product/frontend/src/shared/lib/routePage.tsx` 统一负责；模块就绪即挂载，数据读取仍归实际工作面。应用资料的环境、接口来源、业务整理与源码运行按分类加载，环境与源码输入草稿由稳定父级持有。设置齿轮只预载默认分类，其他分类在指针或焦点进入对应入口时预载。

测试目录读取业务动作与场景上下文，并独立读取 preparation 投影区分实际录制准备与接口流程；不能根据流程数量推断材料缺口。编辑器独立读取上下文和账号，父级只在路由明确要求时恢复试运行或指定来源。数据写入后的刷新、修订核对和陈旧响应隔离继续保留。横向分类的状态样式、指示器和过渡由共享控件样式维护，页面样式只设置位置、间距与密度，不用提高局部选择器优先级争夺选中色。

协作入口常驻读取轻量任务摘要，委派表单及其选择控件在明确打开时加载。当前草稿与未知请求由稳定入口或文档内存持有，不因表单模块分块而重新建立任务。

## 验证边界

全量审查先从当前路由、入口与公共组件调用关系列出覆盖范围，再按同一根因检查消费者及页面例外。源码审查、真实运行和用户审阅分别记录；未运行的状态不能计入实跑覆盖，也不因遍历路由就宣称所有业务分支都已验证。

布局重点核对对象与状态的归属、标题到首项的距离、表头与正文轨道、表面内边距及主操作位置；交互重点核对键盘与指针、当前对象接续、空与失败后的恢复、展开位置和快速切换。两套主题及代表窄窗口检查共用规则，长文本和多行标签用于暴露固定偏移与宽度假设。共享修复先验证受影响的控件族与代表页面，有差异再扩大范围，不为每个无影响实例复制测试。

普通类型检查保护契约连接；确定性组件测试保护焦点、取消和状态；真实浏览器补足渲染、字体和原生过渡。字体变化需延迟请求并观察字形宽度，截图前等待 `document.fonts.ready` 不能证明没有闪换。

应用运行的直接行为验证覆盖方式切换无写入、草稿保留、无执行权限的地址确认、明确授权启动、成功后的显式采用、原请求查询，以及失败和取消后的确认清理。真实独立应用另核对预览、启动、采用新地址、刷新恢复、返回实例管理与停止；错误和取消的组件用例不冒充这些异常都经过了真实进程注入。

布局以两套主题的完整页面和代表窄窗口检查；静态图能核对层次、对齐与操作距离，不能证明动效流畅或全部窗口都无溢出。菜单尺寸连续采样与开闭观察用于排查缩放干扰；没有捕获原始缩小瞬间时，只能记录修复依据和实际观察，不能宣称完整复现。

只改说明无需执行全量界面验收；改变读取、导航或真实字体行为时，再选择对应测试与动态观察。结构、主题和业务结论分别核对，避免将某一层通过扩展成全产品通过。

## 工作流上下文与恢复

场景确认页的 `FlowTrialPanel` 拥有试运行预览、步骤事实与原修订历史。编辑字段变动使旧预览失效；确认执行先保存一次非秘密操作编号，网络回执未知时只刷新原历史，不能再次点击执行。明确的输入拒绝可重新核对。历史读取及继续编辑不改变当前已采用场景；试运行进度通知共享活动读取者，终态不自动采用或触发正式检查。

保存后采用主辅工作面：试运行占主要阅读区，场景核对与采用在辅助摘要中收口；未保存时只显示核对内容。本次试运行与历史记录由公共页签切换，历史选择与反馈详情相邻。首次恢复可定位既有记录，后台刷新不切换使用者正在阅读的页签；执行确认、未知回执和活动任务期间暂停采用。流程根下的最新草稿与仍被采用的旧修订同时保留，从旧记录继续编辑使用当前最大修订之后的新修订，不覆盖旧执行或材料绑定。

准备页的账号行通过 `account_slot` 定位当前需求，账号页将跨操作复用的需求归并到实际账号。显式目标优先于自动选择；目标失效时提示重新选择，不悄悄进入其他账号。关闭账号任务时清除该定位参数并回到原材料。

结果证明没有 SQLite 候选时，补读已有本地运行状态与配置，区分未启动、源码未对应、未配置及尚未取得读取记录；读取失败保留重试，不推断配置丢失。跳转应用运行设置时携带原准备页面的返回位置；支持普通应用运行时直接展示已有启动配置，修正后可回到原操作与证明来源。进入设置不自动提交地址或启动进程。该读取只服务引导，不执行目标请求，也不替代证明预检查。

应用内链接及保留应用上下文的工具、存储入口携带 project_id。面包屑、侧栏和业务操作共享归属规则；切换应用时显式指定新应用，浏览器前进、后退和复制链接均使用地址中的归属。工具与存储仍是全局能力，应用编号只保留授权对象与返回上下文，不改变后端授权。无归属的旧报告链接先读取检查的所属应用，归档记录进入只读历史页。

检查预览按业务操作展示测试账号、待核对结果与具体缺口，不将不同操作的相同缺口合并成一条提示。缺口入口保留 action_id、适用规则、修改与 return_to；补材料后可以回到同一次阅读任务。筛选无结果与没有历史记录使用不同空状态。

账号创建使用稳定操作标识，登录页面恢复已有准备进程。录制建立前保存非秘密请求及原标识，离开后查询原录制；普通请求重放复用既有任务和凭据会话。已结束或已取消的检查停止轮询，失败阶段及错误编号从服务端受控诊断事实读取，执行失败不展示权限结论。

侧栏只呈现当前应用进行中的检查、批量材料准备和待继续的账号操作。任务在服务端执行，离开页面不会取消；取消操作放在任务所在页面。读取失败保留已有内容并提供重读入口，不将失败呈现为首次使用。

代码登记分为实际文件预览与确认登记。源码指纹变化使预览失效。明确的输入或状态拒绝解除当前提交等待，保留说明供重新核对；传输失败保留原标识，只查询或显式恢复同一个请求。

规则详情由地址中的 section 选择唯一内容面，并建立页签到面板的语义关联。登记入口先切换到修复工作面，再定位表单；登记开关不能跨页签占位。普通页签沿用即时选中指示与局部内容过渡，焦点留给当前输入方式。源码修改页的阅读宽度规则不再通过登记组件反向改变权限页宽度。

运行与维护作为保留应用上下文的全局工作面，运行诊断与版本更新各自拥有一个并列工作区；旧view=update深链定位版本区，不再嵌套第二层页签。组件状态按两列比较，操作在工作面标题或确认收口；路径按需展开，更新完成文案依据原回执阶段，不能保留尚未执行的警告语气。原生最终退出回执显示最近确认时间，不以旧回执推断之后没有异常退出。

界鉴服务状态、诊断与刷新统一属于运行维护内容；设置框架不再单独轮询另一份服务摘要。维护操作直接在设置页完成，避免另设同义入口。更新工作面按回执阶段切换主体，已完成状态默认返回应用，另选发行显式打开新表单。复验行的历史触发器始终占据同一位置，内层内容承接折叠动效。

设置框架由App层组合三个独立页面，页面之间不互相导入。统一一级标题与横向分类导航，嵌入内容直接呈现任务标题，不再重复类别标题；分类写入`/settings?section=tools|storage|system`，原`/tools`、`/storage`、`/system`及`/settings/models`继续解析到对应分类，项目归属与运行维护的`view`参数保留。分类切换保持外层页面身份，底部选中指示线连续移动，内容复用局部进入动效；减少动态效果时直接更新。导航尺寸变化重新测量指示器，不对定位容器缩放。


## 准备任务的工作面

账号列表选择与服务端登录任务分开持有。详情显示所选账号，登录、等待保存与完成反馈留在同一位置；切换账号不启动新登录，恢复任务仍查询原准备标识。管理项不改变已有凭据和授权边界。

操作设置按四个内容面维护同一份非秘密草稿。已有流程以根身份和修订共同定位，避免同一根的不同版本共享选择值。保存后才能确认使用，继续编辑解除旧保存的可确认状态；正式采用仍由服务端事务更新材料绑定。

持续协作的当前工作、已用回合和目标产物分别消费执行记录与业务核验，不从模型返回状态推断完成。等待期间不显示新的启动入口；停止接续后才提供继续操作，原业务仍按回执展示。启动确认分开说明持续接续、计费窗口与源码修改范围，界面切换沿用公共动效。

保存检查范围使用公共选择器，不另造弹窗或配置页。普通预览提供紧凑的保存与沿用操作，原题复验继续按自身固定范围执行。保存结果未知时，将原请求及非秘密选择快照保留在会话存储，显式核对同一请求；成功后清除。服务端仍拥有准确规则身份、失效判断和幂等结果，浏览器缓存不决定有效性。

结果证明的默认工作面显示当前步骤和主要动作。完整核对项目及读取技术引用按需展开；授权、可用性核对和正式使用仍是不同操作。检查预览用操作摘要和账号场景表对照权限、数据所有者和测试数据，缺口在对应操作内处理。

工具连接以共享Choice选择客户端，切换后清除该客户端的配置位置选择，再读取对应连接状态；状态、配置操作和维护仍归同一客户端。应用授权在相邻工作区读取当前应用范围，切换客户端不改应用授权。工具选择不写入配置，连接与授权继续经过原确认流程。

连接管理只保留一个展开入口，包含受控接入地址、当前客户端的恢复操作及全部配对管理。未配置时不提供无对象的配置恢复。客户端切换清除旧客户端提示；重复的写入回执与当前状态说明只展示一次。应用授权以实际grant呈现，READ默认选择不代表已授权；范围草稿与实际授权分开，提交继续经过确认。

公共页签、设置分类、分段选择与材料索引通过`useSelectionIndicator`读取目标元素的布局位置；布局坐标不从正在插值的标记反推。ResizeObserver覆盖容器及候选项，字体或窗口尺寸变化后更新边界。选择标记用 Web Animations 采样临界阻尼曲线，反向时从上一段的当前时间计算位置及速度，取消旧段后接续；不逐帧更新 React、不引入动画库或常驻 RAF。既有240ms令牌作为主要变化节奏，最后120ms自然收尾；没有动画 API 时立即定位，减少动效切换时取消在途动画。分段选择保留方向键、Home/End、按下状态和单一Tab焦点；阅读内容的短淡入可接续中断时的透明度，不以重挂载方式丢弃草稿。

CSS 时间经 `motionMilliseconds` 转为原生动画与计时器需要的毫秒，同时接受源码的 `ms` 与构建压缩后的 `s`；控件测试覆盖两种单位，真实浏览器使用生产产物核对实际动画。不能直接以 `parseFloat` 读取时间令牌，否则生产压缩可能使节奏缩短千倍。

`shared/ui/Tabs.tsx` 与同目录 `Tabs.css` 共同拥有页签的完整默认外观和行为，组件直接导入自身样式；调用处无需补齐 flex、按钮内边距、字号或分隔线。`Tabs` 用于内容面，`LinkTabs` 用于设置等路由分类，分别保留 tab/tabpanel 与链接/当前位置语义，复用同一选择指示器和视觉实现。默认常规密度，参数位置、试运行记录和证据阅读使用明确的紧凑密度；只有外部工具栏已经拥有分隔线时使用 `divider={false}`。页面样式只安排外层放置，不定义页签子项的外观。架构检查约束公共页签选择器的样式所有权，真实浏览器比较跨页面的计算样式、指示器、焦点和窄窗行为。

`IndexSelection`统一拥有局部索引的选中表面和位置线，索引项使用`jj-index-item`；业务模块只维护行内列、内容与必要密度。组件读取现有的`aria-current`或`aria-pressed`，不改变选择、路由或可操作门禁。无可见选中项时清除旧标记；过滤后不得留下悬空选择底。动画继续使用既有令牌，减少动效由公共策略处理。

应用工作面的操作错误按应用与页签保存，迟到结果保留在原归属；业务线索编辑在自己的工具栏下显示失败并保留草稿。通知和内容使用所属容器的gap，避免公共通知叠加固定外边距。工具接入与授权仍保留各自原始状态、确认和恢复边界。

环境编辑草稿仍由应用工作面持有，切换资料页签不丢弃；添加或编辑仅改变本地显示，保存、采用、地址确认分别调用原用例。目录读取当前采用的准确修订；该修订不在最新配置列表时仍单独呈现。业务动作卡片只读取已持久化的效果标签、流程目标步骤、修订与步骤数，不生成占位进展或新的权限判断。

跨工作面回程由共享导航解析和构造；工作台只接受包含准确任务编号的协作回程，不能据此开放任意地址。对象链接带入发起页及其查询状态，目录层级由路由元信息维护。问题页先从完整集合定位显式引用，再同步可见筛选；失效引用显示缺失状态。

`useDirectoryState` 只按应用和目录保存搜索、筛选、选择及展开偏好；滚动和返回焦点在当前文档内存中交接，待数据与目录挂载后恢复。表单及秘密不进入该目录存储。接口流程与证明配置继续使用原编辑器内存草稿；证明的运行引导在回程中携带配置模式、操作和来源身份，应用分类切换不删除回程。

前端复核同时检查内容分配、状态颜色和元素边界。页面无横向溢出、按钮未裁切和标题对齐不能证明信息层级或空态合理；至少回看正常、空内容、编辑和失败的代表状态，并记录通知与实际相邻表面的距离。静态消费者检查、真实浏览器采样和人工图像审阅分别记录，未出现的分支不宣称已经运行。

应用连接概览将环境读取与源码摘要各自交给原读取所有者，源码摘要核对项目归属；完整授权与运行配置仍由连接工作面负责。检查方案与业务场景目录只读取当前选中对象的准确修订，校验对象和修订后呈现实际内容，不调用准备、保存或执行来填充摘要。目录偏好与返回焦点复用 `useDirectoryState`，详情复用 `Inspector`、内容切换和共享表格选择面。方案的运行限制及保存历史旧分类链接映射到内容内对应区域，草稿仍由原方案编辑器持有。

`app/CheckWorkspace` 组合本次检查与原材料、流程和应用工作面，`WorkflowContext` 只持有导航位置，不复制领域数据或保存回执。URL 外层保留规则、选区、修改、场景、方案及绑定；`work_item` 表达当前子事项。只允许已知内部工作面，拒绝跨应用嵌入。嵌套补账号的回程返回原编辑器，顶部返回入口回到本次检查；重新核对继续使用原预览服务。

方案准备与原题修复组件归 `entities/check/ui`，由方案页、检查预览和问题页复用。页面仍按路由懒加载，组合工作面不能将所有页面静态打入首页。`ActionLink` 只将当前工作面内的普通内部左键导航交给组合层，保留调用方取消、修饰键、新标签与下载行为。

本次范围与未知提交分别保留。已有未确认请求不能覆盖显式规则或选区；查询回执后按原请求的冻结范围阅读。发现应用已有运行时，只把本页作为返回位置，不把本页的规则、修改或选区附到该运行上。账号及证明工作面读取组合层的当前子路由，外层 URL 不替代内层配置模式和来源定位。


## 共同模式的实现所有权

`WorkflowSteps`、`Progress`、`ObjectHeading`、`Status`、`DisclosureMarker` 与 `ComparePair` 管理共同模式的内部表达；`patterns.css` 拥有其字号角色、标记、状态、密度与实际容器响应。业务提供对象、事实、门禁和动作，不按页面重新绘制内部状态。`jj-object-line`供不需要完整对象头的行内组合使用；集合标题继续使用`SectionHeading`。

事实组使用`jj-facts`。标签值并列为默认，`is-stacked`在组内上下排列，`data-layout=columns`将多组事实按容器宽度并列；后两种共用同一标签值语法。页面只安排外部位置及留白，不维护私有标签列宽、字号或嵌入密度。内容表统一使用`jj-content-table`，常规与紧凑密度由公共样式拥有；`ObjectTable`另外拥有持续单选面。比较数据使用`jj-comparison-data`，变更标记不自行表示安全好坏。

纯跳转迁移到`ActionLink`时，原`go`整页导航使用`navigationScope=page`，已有上下文链接保持默认工作流责任；两者复用相同外观。带禁用、忙碌或附带本地状态变更的按钮不机械转换成链接。

独立与嵌入工作面可改变外围位置、宽度、留白及外框归属，不能用跨模块后代选择器改变共同模式的标记大小、字级、图标、选中面和当前态。新增用途应由原模式定义完整状态，不再逐页增添任意外观开关。加载骨架沿用平面阅读或目录的轮廓，避免等待时临时产生另一层卡片。

名称与其状态必须在同一阅读组内。对象标题使用`ObjectHeading`，不需要标题层级的任务条目使用`ObjectIdentity`；外部两端对齐只能安排整个阅读组与操作或时间，不能把名称和状态作为两个伸展列。内容表的独立状态列与窄目录的扫描列继续保留各自用途。
