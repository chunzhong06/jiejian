# 前端实现与数据寿命

前端拥有展示、导航和当前交互状态，服务拥有运行事实与安全判断。页面不根据颜色、执行成功或本地计数重新推断 verdict。

## 模块所有权

| 层 | 职责 | 边界 |
| --- | --- | --- |
| `app` | 路由、项目选择、主题、全局错误和导航框架 | 不堆入页面业务表单 |
| `pages` | 完整任务、局部详情与页面样式 | 跨页面逻辑按真实所有者提取 |
| `entities` | 应用、规则、准备、检查和修改的 API 与契约 | 不依赖具体页面 |
| `shared` | 传输、读取取消、通用控件、导航基础和语义令牌 | 不导入业务实体或页面 |

组件从声明模块导入，避免公共 barrel 把无关业务一起加载。局部 CSS 随路由加载，只有真实共用的规则才提升到公共层；样式与事件不跨层偷偷接管业务状态。

行为测试留在所属模块旁，页面专属冻结样例也留在页面测试附近。`tooling` 集中维护 Vite 配置、Vitest 环境初始化与编辑器解析插件；包命令通过明确的配置路径接入，tsconfig 保留在前端根供编辑器自动发现。`tooling/vitest.setup.ts` 只由 Vitest 加载，负责 DOM 清理与缺失浏览器 API 的替身。开发工作区同步测试输入，类型检查覆盖初始化文件，产品入口不导入这些测试设施。

pnpm 工作区明确只包含前端根包；编辑器解析器是开发工具输入，单独安装到受控编辑器依赖视图。包清单、锁文件、工作区范围与插件输入共同决定依赖身份，范围变化必须重新准备依赖，不能只同步文件后沿用旧安装记录。

## 代码加载与业务读取

路由模块使用独立加载器，缓存已解析组件并通知当前订阅者。模块就绪即可挂载，业务数据再显示所属占位，避免代码和数据共用 Suspense 回退周期而额外等待。离开页面解除订阅，迟到模块不能覆盖当前任务。

侧栏可预取模块，但不提前挂载页面或触发业务写入。面包屑父级为真实链接，当前项标记当前位置；页签等局部选择不重播整页过渡。

`useApplication` 管应用上下文，完整工作区用于概览和修改工作面。准备页直接读取 preparation 与必要批次状态，名称、缺口和推荐操作来自自身投影，避免为了一个名称等完整历史。

## 请求所有权

HTTP 传输合并同代并发只读请求，写入使旧读取失效；写请求不盲重试。`useRead` 用 key 区分对象，离开时取消请求并丢弃迟到响应。已有数据刷新不清空工作面，首次读取提供结构占位，错误在所属位置处理。

读取缓存只服务显示。预览、提交与执行门禁继续核对当前服务事实，不能使用前端缓存充当批准或冻结输入。

## 应用运行的状态与操作

`product/frontend/src/pages/connections/Connect.tsx` 负责当前项目、源码与业务和检查条件；`product/frontend/src/pages/connections/RuntimeConnection.tsx` 在同一区域负责运行方式、编辑草稿及启动回执。组件按 project_id 重新建立，项目切换不会沿用另一应用的输入。

| 状态 | 所有者与寿命 | 操作含义 |
| --- | --- | --- |
| 连接或启动方式、未提交的地址和入口端口 | 页面内编辑状态，方式切换时保留 | 只切换字段，不写入服务事实 |
| 启动预览及执行勾选 | 当前输入对应的局部确认 | 入口或端口变化使预览失效，启动前必须明确授权 |
| 尚未确认的启动标识 | 浏览器会话保留定位信息，服务端拥有操作回执 | 刷新查询原操作，明确恢复时复用原标识 |
| 运行实例、源码对应和终态 | 服务端运行事实 | 成功后显示实例；失败或取消后移除旧确认 |
| 当前检查地址 | 源码理解记录中的已确认地址 | 手工提交或采用实例地址均走同一确认接口 |

没有普通应用启动能力时不读取运行实例，也不露出启动方式。存在未确认启动时锁定方式切换，避免正在核对的任务被另一个表单遮蔽；终态到达后刷新实例事实和应用事实，不按本地猜测补成功。

“使用此应用”只改变访问目标，启动和停止仍由原运行 API、持久 Job 与 Worker 负责。界面重组没有另建后端协议或数据库结构，也没有把实际运行等同于安全结论。精确进程、实例和回执契约见[应用与运行](../能力/应用与运行.md#源码整理与运行连接分开)。

## 过渡所有权

支持 View Transitions 时只捕获 `jj-workspace`，在快照更新回调内提交路由。新导航跳过旧过渡，旧完成回调不能清除新状态。主题同步提交配色，再使用可取消的短淡入，不捕获整页快照，避免暂时暂停导航和业务控件的命中。页面局部变化不参与根交接。

不支持时直接导航，由 PageSurface 提供可取消入场；减少动效时直接呈现。首次内容揭示与导航分开，不重播后台读取，不对整个应用重复淡入。具体参数见[交互与动效](交互与动效.md)。

## 字体选择

根与 Portal 共用 `--font-ui`。MiSans 使用独立字体别名与预加载，首次挂载前最多等待 80ms：及时可用则采用，否则本次文档固定后备字体。迟到字体不再次激活，后开的菜单继承同一选择。

代价是首次选择增加至多 80ms 等待，慢速首次文档可能使用后备字体；下一次文档可受益于缓存。字体资源尚未压缩，`font-display: optional` 不是唯一防闪换措施。

## 验证边界

普通类型检查保护契约连接；确定性组件测试保护焦点、取消和状态；真实浏览器补足渲染、字体和原生过渡。字体变化需延迟请求并观察字形宽度，截图前等待 `document.fonts.ready` 不能证明没有闪换。

应用运行的直接行为验证覆盖方式切换无写入、草稿保留、无执行权限的地址确认、明确授权启动、成功后的显式采用、原请求查询，以及失败和取消后的确认清理。真实独立应用另核对预览、启动、采用新地址、刷新恢复、返回实例管理与停止；错误和取消的组件用例不冒充这些异常都经过了真实进程注入。

布局以两套主题的完整页面和代表窄窗口检查；静态图能核对层次、对齐与操作距离，不能证明动效流畅或全部窗口都无溢出。菜单尺寸连续采样与开闭观察用于排查缩放干扰；没有捕获原始缩小瞬间时，只能记录修复依据和实际观察，不能宣称完整复现。

只改说明无需执行全量界面验收；改变读取、导航或真实字体行为时，再选择对应测试与动态观察。结构、主题和业务结论分别核对，避免将某一层通过扩展成全产品通过。

## 工作流上下文与恢复

应用内链接及保留应用上下文的工具、存储入口携带 project_id。面包屑、侧栏和业务操作共享归属规则；切换应用时显式指定新应用，浏览器前进、后退和复制链接均使用地址中的归属。工具与存储仍是全局能力，应用编号只保留授权对象与返回上下文，不改变后端授权。无归属的旧报告链接先读取检查的所属应用，归档记录进入只读历史页。

检查预览按业务操作展示测试账号、待核对结果与具体缺口，不将不同操作的相同缺口合并成一条提示。缺口入口保留 action_id、适用规则、修改与 return_to；补材料后可以回到同一次阅读任务。筛选无结果与没有历史记录使用不同空状态。

账号创建使用稳定操作标识，登录页面恢复已有准备进程。录制建立前保存非秘密请求及原标识，离开后查询原录制；普通请求重放复用既有任务和凭据会话。已结束或已取消的检查停止轮询，失败阶段及错误编号从服务端受控诊断事实读取，执行失败不展示权限结论。

侧栏只呈现当前应用进行中的检查、批量材料准备和待继续的账号操作。任务在服务端执行，离开页面不会取消；取消操作放在任务所在页面。读取失败保留已有内容并提供重读入口，不将失败呈现为首次使用。

代码登记分为实际文件预览与确认登记。源码指纹变化使预览失效。明确的输入或状态拒绝解除当前提交等待，保留说明供重新核对；传输失败保留原标识，只查询或显式恢复同一个请求。
