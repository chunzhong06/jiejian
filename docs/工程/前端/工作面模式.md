# 工作面模式

集合标题与关联动作复用 `SectionHeading`，由共享层维护基线、间距和窄窗换行，业务只提供对象名称及操作。页面总任务、对象集合、当前对象各有职责：权限编写的操作集合拥有“添加操作”，每项操作内的结果集合拥有“添加结果”；批量资源的创建入口与逐项比较同区，读取范围和判断方式分别管理。空目录只保留空态的首项创建，存在记录后再展示目录追加，不把相同动作同时放在两处。

本文维护界鉴各任务采用的具体组织；通用判据归[布局与视觉](布局与视觉.md)。所有页面使用统一组件、排版和动效，保留已认可的亮暗配色；布局重建不强求不同任务使用相同列数。下面的工作面都必须保留准确对象、草稿、读取失败与返回位置。

内容少时用标题、相关事实和区域末尾动作建立重心；内容多时按照用户当前要完成的工作分配主体。短创建与普通范围确认就地审阅，长授权、执行、复杂配置与深入证据进入聚焦任务。同一任务的阶段依次替换正文，同一对象确需反复切换的阅读视角才保留分类。隐藏原编辑面时继续保留草稿、后台操作与未知回执的所有者；关闭任务只表示返回，不代表成功或取消。


## 工作面选择

| 当前任务 | 组织方式与返回责任 |
| --- | --- |
| 继续已有工作 | 当前任务、近期事实与可接续对象；共用资料按需查看 |
| 比较多个对象 | 带共同表头的内容表；简短字段就地调整，复杂内容单独编辑 |
| 持续选择并阅读 | 连续局部索引与当前详情；收起、窄窗和返回恢复准确位置 |
| 创建或维护对象 | 按依赖分组；新建需要时引导，已有内容可直接进入相应分类 |
| 预览与执行 | 明确范围、缺口和后果；准备后回原范围，人工确认后才执行 |
| 理解证据或变化 | 结论、观察与解释相邻；长解释使用完整阅读宽度，技术记录按需展开 |
| Agent 协作 | 当前目标、需要人决定的事项与产物分开；候选、执行与验证保持区别 |

同类任务共享语法，不将全部页面套成同一种分栏。保留原结构的页面也核对功能归属、入口与回程；界面清单与运行证据留在运行边界，不增设常驻审计文档。

先决定常驻内容，再安排组件。日常目录直接呈现对象、状态和操作；首次使用、空状态及具体缺口才解释如何开始。步骤、阶段标题、正文和按钮不重复表达同一动作。保存状态只提示当前草稿是否已保存；执行、授权、采用、删除的真实后果在对应确认位置说明。来源和技术范围按需展开，实际错误、未知回执和判断条件持续可见。每页按真实任务取舍，保留已经清楚的布局，不用另一套固定结构覆盖全部页面。

## 目录与详情

规则、场景和问题用连续目录支持定位、比较与筛选。标题说明任务；搜索和筛选位于目录工具区；选中后相邻显示当前对象。表格行只保留名称、必要范围、关键状态和时间，完整依据进入阅读区。目录不将每个对象变成独立大卡片。

规则一行对应一条实际要求，保留各自角色、资源范围、状态条件及结果。右侧集中显示所选规则的含义、检查材料和准确结果入口。搜索或筛选改变可见范围后，详情对应可见对象；完整详情仍保留规则、修改与历史深链接。

比较表的单元格只承载简短摘要或单值调整。复杂条件在对应规则下方展开整行编辑区，一次展开一条；不能把多字段表单塞进一个单元格，拉高整行并使其他列空置。收起或切换不提交修改，各对象的草稿继续保留，最终由工作面的确认操作生成待审变更。

测试目录以业务动作组织执行方式、结果要求和实际准备状态。操作录制、接口流程及其草稿分别表达；没有接口流程不等于材料未准备。就绪来自服务的准备投影。右侧展示当前动作的执行、结果、恢复与修订，分别进入材料核对或接口流程；共享账号与证明来源集中在“准备与资料”。准备读取失败显示待核对，不推断没有权限要求。

来源的请求索引与详情相邻。搜索属于请求索引，来源名称按组出现一次，请求行保留方法、名称及路径。详情先阅读业务用途，需要修改时再编辑名称与关联；参数和导入依据退后。草稿保留最初修订，保存仍核对并发。窄窗选择请求后进入单一详情，返回保留搜索与选择。

接口来源优先保障当前请求的阅读与编辑宽度，目录保留持续定位所需的名称、方法和短路径。分栏或单一详情按来源工作面的实际可用宽度切换，嵌入时也沿用同一规则，不通过缩小字段或改变标题角色补宽度。

目录详情展开时，索引只保留名称、状态和区分同名对象所需的最短上下文；资源归属、实际结果和完整说明集中到详情。关闭详情后恢复完整摘要、焦点和阅读位置。没有所选对象时不预留空详情列。

规则与测试目录的相邻详情统一使用 `Inspector`：可通过关闭入口或详情内的 Escape 收起，焦点返回仍被选择的条目，搜索、筛选和选择保持不变；点击条目重新展开。关闭后列表使用完整宽度并恢复摘要，展开时将重复说明留给详情。详情切换沿用可中断的短淡入，不通过重挂目录重新读取或清除草稿；窄窗改为上下阅读，不压成多条窄栏。

当前五处搜索统一使用 `SearchField`，放大镜、范围提示、输入与清除位置由公共组件维护；清除后焦点回到输入，控件宽度不因有无文字改变。来源索引保留嵌入密度，规则、操作、场景保留即时筛选，检查记录保留明确提交查询，公共组件不偷偷切换查询方式或触发后台写入。

目录的相邻详情栏将名称与状态放在同一标题行，事实按标签和值排列。任务操作在详情栏右下角收口，次要操作在前、主要操作在后；阅读导航仍保留自然顺序。窄栏允许标题换行，不能让状态脱离对象，也不以固定大高度撑开说明与操作。

相关表单按实际对象配对，而非把每行强制分成两半。操作定义与其结果、连接位置与业务记录对应可以在宽工作面并列；每组内部保持连续阅读，额外字段随实际类型出现。复用 `FormColumns` 和字段栈管理排列与间距，窄工作面自动转为上下顺序；不附加背景、边框或固定高度。只有说明和低频技术引用可以折叠，操作类型、资源及判断结果所需字段不靠折叠掩藏。

## 工作台与应用资料

内容较少的连接条目不横跨整个工作面。检查地址与本地源码属于同一应用的两种配置，在概览并列；窄窗按地址、源码顺序阅读。应用连接条目按名称与使用状态、地址与部署说明、末尾操作分别组织。连通状态只表达已核验事实；编辑、核验或切换在条目右下收口，不与说明文字一起塞入窄侧列。窄窗保持同一阅读顺序，操作完整换行。

为已有应用补充源码时，先明确当前应用已经建立、正在使用哪个地址，再解释补充源码用于整理线索或本机启动。这里始终补充到当前项目，不能复用新建工作区的接入措辞。首次从源码建立工作区则核对原目录对应的项目，再选择继续或新建。

本机源码目录同时支持系统选择与手工完整路径。选择只填入值，取消保留输入；选择器不可用时说明手工回退。确认保存、源码读取授权和实际运行分别发生。初次接入与补充源码共用目录输入布局；目标应用内部路径、接口地址与受控远端路径不据此增加本机目录选择。

内容表的名称和修订属于同一对象，但使用独立行与明确间距；不能依赖内联 small 自动产生分隔。目录选择、表头、元信息与操作区按各自职责校准，不从一个表格实例推导所有列表的样式。

工作台突出一个当前任务，保留必要原因和区域右下的推进动作。权限、材料和问题用简短事实入口定位，不再用概况段落复述计数。最近检查只保留一个全部记录入口，整行悬浮和键盘焦点表达可点击；比较在完整记录中选择两轮后出现。接续区只展示已有方案和待处理问题，没有对象时不预留空栏或常驻教程。多份方案保留选择与准确修订，再进入本次准备。

空态、缺口和次要模块先说明用途与当前情况，再给下一步及其后果，不能只罗列名称、计数和技术编号。指引就近呈现，不把所有页面变成教程。首次创建与顶部追加入口按状态互斥；筛选无结果保留筛选恢复，已完成状态说明记录去向。

页面语言先交代当前要完成的工作，再解释操作后果。检查方案保存反复核对的要求；接口流程说明一项业务操作如何执行；业务场景组合连续操作与跳步、重复、更换账号等变化，三者不能混称。保存、确认用于检查、开始执行、批准规则和查询上次结果使用各自准确动作；查询未知结果继续核对原请求，不暗示重新执行。批准规则只更新界鉴的检查依据，不修改目标应用的权限配置。

改写前先区分显示文字与程序匹配值。后端发布判断、协议枚举、字段名、路由参数和判断条件中的固定文字属于使用契约，不能按文案统一替换；需要通俗表达时在显示层转换。验证既要检查语言与换行，也要保留结论判断、准确回程、未知结果查询和草稿恢复的回归证据。

恢复按钮按实际行为命名：只读查询可以写“查看上次结果”；查不到记录时会沿用原请求完成写入，则写“继续上次保存、添加或连接”，并说明继续使用原内容和请求。不能因它具备幂等保护，就把仍可能完成写入的动作称为查看。

准备状态、执行进度、检查结论与修复结论分别表达。确定性检查结论统一为“符合规则、不符合规则、证据不足”；尚未执行、尚未发布或材料未齐不冒充检查结论。缺口说明具体对象和处理去向，返回保留准确范围与当前事项。没有核对运行代码时，只陈述观察到的结果，不把行为变化写成源码修复。技术编号和执行细节留在需要查证的位置，不能代替任务说明。

工作台围绕当前工作与最近结果组织：使用当前任务明确关联的操作和角色，解释原因与下一步，主要动作在该任务右下；不另铺方案、资料和统计栏目。近期检查的结果在名称前，时间与类别留在次行，整行进入原报告。当前已停止的示例使用真实停止状态，不由历史记录猜测下一项工作。真实连接异常与读取失败直接提示。

业务结果证明先呈现实际判断方式、资源和读取记录，完整参照接在同组事实下面；缺口说明紧邻核对或采用动作，读取管理作为次操作。接口流程的短事实按标签和值阅读，试运行与记录单独成组，修改及采用在区域末尾。试运行历史先核对执行条件，再阅读逐步请求反馈，不为短摘要保留固定半栏。

协作只有一个待答问题时，以问题作为主标题，原任务目标保留为上下文；多事项仍由目录选择当前项。已保存来源与交接草稿分别标明，准确来源链接紧邻回答，任务管理放入原菜单。选择已知选项不自动展开补充表单，“暂不确定”交回原任务在既有授权内查证。

测试区的检查方案、操作与材料、业务场景、检查记录是长期目的地，共用路由分类导航；使用原生链接与当前位置语义，保留项目归属。具体方案、场景编辑、检查预览、材料准备和证据阅读以准确回程衔接，不在编辑任务上方重复所有分类入口。集合创建属于该集合，提交和采用属于当前任务。

检查方案目录与准确修订的实际范围并列。目录选择后读取该修订的权限要求或业务场景，详情解释检查什么、准备什么与运行上限，再分别进入编辑或本次准备；不能只用目录摘要和一句通用说明撑起详情。收起后恢复完整目录及原项焦点，窄窗一次显示目录或详情。方案编辑保留检查内容、检查准备两个分类；内容与短运行上限并列，保存记录在内容下按需展开。原运行限制、保存记录深链接仍定位到对应区域，原草稿与未知保存请求不变。

应用与来源保留应用连接、接口来源、业务角色与操作三个长期分类。连接概览将检查地址和本地源码并列：地址选择与源码补充在同一上下文，完整源码授权和受控运行从源码区深入。原源码与运行深链接、运行方式参数及发起页回程继续有效。应用连接解释待检查地址及切换后的材料责任；地址目录连续比较名称、地址、部署说明和当前使用事实。保存、切换、核验分别承担不同后果。首次无配置直接编辑；已有配置按需进入修改。短名称、部署说明和请求预算按内容限宽，地址获得足够阅读宽度；相关字段在可用宽度下并列，窄窗完整换行。不会用未核验版本占位或重复卡片填充内容。

创建应用以当前表单为主，本地源码与独立示例是其他开始方式，各自说明后果并在所属区域收口。源码与运行按真实责任组合；连接已有应用和由界鉴启动只显示当前方式需要的内容。切换视图不启动、停止或采用地址，原草稿与未知操作编号继续保留。

尚无保存连接时，当前运行地址作为已有事实单列，新增检查连接具有自己的标题和保存说明。进入本地运行后，运行任务接管主标题、返回与错误，应用连接、接口来源、业务角色与操作三个二级入口仍可见可达；原编辑面与草稿保持挂载。返回与对象标题之间保留分组间距，应用名与主标题使用明确的次级间距。候选连接的“使用此连接”进入影响核对，确认切换仍由原事务负责。

业务角色与业务操作分类核对。它们只需比较和调整少量字段，因此采用带表头的内容表：名称、是否用于检查、来源依据共享列，来源路径和位置相邻。这里不使用局部索引与宽空详情栏；长来源按需展开。类别切换和离开再进入保留同一来源修订的各项草稿；失败保留输入，成功留在当前工作面反馈。保存只确认业务含义，访问规则由独立入口继续维护。添加和保存不同时提供重复提交入口。

## 场景与材料

业务场景目录与当前保存的实验安排并列：正常流程、各项变体及其动作顺序就近阅读，再进入准确修订的编辑或检查范围。选择和浏览只读取，不保存、不运行；读取失败保留所选对象，不拿最新修订或其他场景代替。长场景编辑继续拥有完整任务空间。

场景步骤用一个已准备项选择保持权限、账号与资源的准确绑定，选后分项核对业务操作、操作账号、资源编号、归属和访问要求。资源来源说明随所选来源变化。局部试验集中选择本实验、正常流程至当前步或可用的单独动作，再显式进入预览；整份场景保存独立收口。单独试运行接管正文和操作，返回继续原草稿。

材料工作面以业务操作为上下文，左侧连续导航，右侧编辑或阅读当前材料。选中带与目录相接，图标、名称、状态和方向列稳定，无悬浮卡片。所用权限和相关资料为次要上下文；既有账号、证明和流程可复用，不要求重复填写或重新准备。

局部索引统一沿用检查准备的材料目录：未选中融入画布，选中使用浅蓝整行、左侧3px标记和连续移动，行内保留稳定的图标、名称、状态与方向位置。请求、账号、证明来源、流程阶段、执行步骤、试运行记录、问题与报告索引共用这一实现；业务只负责内容、列定义和必要密度，不另加悬浮圆角卡片或独立底色。比较表格保留表格结构，采用相同的选中表面与左侧标记；全局侧栏和横向页签仍各守原有职责。

接口流程是可维护资产。顶部进度显示起点、账号与数据、执行请求、核对与使用；存在字段比较时增加“结果核对”，数据变更操作显示“结果与恢复”，没有相应配置时直接核对。已经完成的阶段可以返回，必要输入仍控制推进。请求编辑正文只有执行顺序和当前请求两列；请求方式、路径与参数集中编辑，受检请求用明确状态表示，其他步骤可显式设为受检。编辑面只承担账号、资源、请求、结果依据与恢复配置。保存、试运行和用于检查分别收口；试运行替换为聚焦任务，采用前用短审阅说明准确修订和后果，不再常驻左右分栏。历史归当前流程的记录入口。

阶段进度不与正文的步骤索引并列争夺宽度。起点方式和请求参数分别在所属阶段内选择；动态防伪参数由明确命名的配置对话框加入准备步骤，资源提取、字段比较和恢复接口进入后续阶段。请求参数默认定位已有内容或内建资源取值，空参数说明可跳过，不能让使用者误以为必须逐项补齐。执行步骤选择带末端与编辑分界之间保留独立留白，详情也有自己的阅读内边距。场景核对沿用画布，仅保留事实与操作收口，不铺额外整块背景。

试运行预览和执行、保存草稿和正式采用各有独立后果。未知执行只查询原记录，活动期间不采用；旧试运行和仍被采用的修订持续可读。从旧记录继续编辑建立新修订，不覆盖旧事实。试运行结束不产生权限结论。

账号使用列表和相邻详情，真实身份、登录配置与会话有效性分开。账号槽位定位优先于自动选择；不可用对象保留原因，不能悄悄换成另一个主体。证明来源使用配置、读取范围、预检查及采用的渐进工作面。已有数据库对应先读摘要，无剩余候选时不显示空选择器；配置存在不代表实际读取已成功。

证明来源在同一对象内组织判断依据、核对记录和来源管理。判断依据呈现方式、资源归属与完整参照；核对记录直接列出已确认、尚未确认及不支持的事实；读取位置、大小与时间限制、判断方式调整和撤权在当前对象下展开，收起后保留未提交文件。完整配置、读取授权与撤权仍使用原审阅和确认流程。当前推进动作在工作面右下角，普通管理不另建一层返回。

## 检查、证据与修复

复杂业务场景沿用“业务实验页签 → 左侧节点索引 → 右侧当前节点”的工作面。节点从已准备的操作、账号、资源与准确规则选择；批量资源用统一表格比较资源、操作账号、归属与预期后果，选中后编辑一项，不再增加一层导航。完整正常流程与挑战明确区分；保存、预览、执行分别表达不同后果。长路径可以换行，索引与详情保持独立内边距。

同一次批量请求只使用一个业务动作和操作账号。第一项确定该范围，其余项只列相同动作及账号的准确规则；改变第一项后保留其他项原选择并明确指出不匹配，不自动替换账号或批准规则。正式结果沿用同一比较表，展示实验、节点、实际资源、预期效果和实际后果；选中依据后目录收敛为资源与结论，完整内容在相邻详情中阅读。资源编号与实验发生位置同时保留，不能只用重复的动作名称定位批量结果。

包含多项输入的子配置作为完整分组占据父表单的一整行，不把两列分组再塞进父网格的半列，挤成四分之一宽度。基础操作信息简短、结果条件较多时按阅读顺序上下组织，避免两栏高度严重失衡。表格单元格里的关系条件用纵向输入；验证除整体溢出外，也检查关键下拉文字与字段路径是否因局部过窄而截断。结果配置沿用同一画布和分隔，不额外套一张底色卡片。

单个已有资源动作可沿用原试运行器查看请求反馈，明确不运行前序节点、不提供权限结论。整个业务实验或正常流程的选定前缀另存独立准确范围，再进入统一检查预览及确认；变体保留完整正常对照。原草稿、准确修订与未知保存回执持续保留，不因调试覆盖原场景。目录只读取摘要，编辑时再取得准确正文和准备上下文。

服务数据库声明使用共用对话框，按连接位置和业务记录投影分组；密码留在受控输入中，不展示引用值作为可编辑业务字段。安装和移除另行审阅准确对象与 DDL，不复用普通保存按钮。异步文件配置只在选择异步交付后出现，用共享页签组织任务路径、状态、关联和预算；关闭或切换配置时保留未提交草稿。连接投影、复杂关系和异步配置使用共享宽对话框，短确认沿用默认宽度；长内容只在正文滚动，标题和右下确认持续可见。动效层不拥有控件尺寸。

检查预览按业务操作展示范围、账号、结果要求和缺口。同一准备入口可以归并，但保留所有原因、原始对象、规则、修改及回程；不同业务动作不合成笼统提示。提交区域只确认当前真实范围，不将已有授权重复变成勾选任务。

报告先给本轮判断与范围，再提供结果筛选和连续列表。筛选是定位工具，不做第二组结论卡；改变阅读范围不改变报告结论。选中后目录收窄，证据阅读占主要区域。主区直接比较权限要求与实际结果，再给判断记录；账号、资源、条件和请求/恢复核对在相邻上下文。操作路径与证明记录保留各自页签和准确片段定位。窄屏进入单一阅读面，关闭后恢复选中项、焦点和原滚动位置。

归档属性是报告上下文，放在报告元信息中；返回官方示例与返回该应用检查记录共用顶部操作行。归档目录在标题中说明所属应用，不再用独立横幅重复占据正文高度。只读边界仍由归档查询与实际操作能力负责。

单条证明先展示类别与实际值，来源和范围退后；前后状态保留各自含义，不用成排勾号暗示权限安全。技术调用、HTTP 成功、业务提交和安全结论分别表达。路径与发布记录不由前端推断或生成。

问题工作面用目录定位原题，右侧阅读影响、正常对照和复验。比较表保留禁止场景、选定正常场景及保留功能的独立结果，原检查与新检查分别呈现。源码登记、关联修改和复验带准确问题及回程；源码档案属于查阅，不代替问题处理。来源记录与新验证都持续保留。

跨轮结果比较采用全宽内容表，选中结果的说明在原行正下方跨列展开；桌面将前后事实并排，窄窗按参照、本次的阅读顺序上下排列。说明、比较限制与准确报告入口同属该项，避免少量摘要行与右侧长详情绑定高度。切换、收起和报告回程保留准确事项与键盘焦点，继续复用共享表格选中底面和内容动效。其他目录按各自任务保留相邻详情模式，不将此规则泛化为所有表格都展开长正文。

规则详情一次呈现检查结果、修复与修改、检查历史之一；登记表只属于修复任务。历史展开只增加下面的内容，不改变触发器尺寸或所在列。登记草稿和原题引用不能随切换丢失。

单次检查摘要先将结论与状态并排，再按同一基线展示检查范围和时间，阅读依据的操作在摘要右下角。不能把徽标、结论、元信息与主操作全部排成左侧一列，也不通过增加空白高度突出操作。

## Agent 协作

外部工单审阅先说明发送位置与后果，再以完整段落展示将发送的标题和正文；原报告与问题编号收在可展开的检查记录中。按钮写明“创建这张工单”，远端关闭仍不改变本地修复结论。不得把凭据、协议字段或整份参数JSON作为审阅正文。

目标使用紧凑正文，与任务类型和单一状态放在页签之前，不单独围合成大卡片。“当前工作”在左侧连续索引列出待办，右侧一次展开一个问题、执行确认、未知回执核对或产物审阅；索引使用共享选择表面，分类使用短文字，不重复为每项加状态徽标。默认先核对未知操作，其次补充业务含义，用户可以自由选择处理顺序。无待办时，主区显示实际执行、继续入口或检查结果。

“产物与上下文”集中准确产物、交接结构与返回位置，“处理记录”单独查阅操作回执、后台执行和事件，首屏不再重复堆叠目标、待办和时间线。页签和事项切换保留未提交回答；已处理事项消失后选择剩余待办。主操作留在当前详情右下角，暂停、结束与停止归任务操作。尚无产物时准确说明，不画固定阶段进度或虚构已完成事项。

接口流程与证明设置在所属工作面提供当前草稿交接，委派对话框集中展示目标类型、交接对象与接续位置；不在各页复制一套聊天或执行器。任务提供目标补充与自由回答，建议选项只预填回答，统一在右下角提交。任务列表用于查找和切换，目标工作面仍负责处理决定与产物。流程候选使用当前草稿与准确修订的并列表格，带入、保存和采用分别有明确动作；后台读取不自动覆盖本机草稿。既有主题、字体、选中表面与动效继续由公共实现拥有。

操作回执、后台执行结果和发布检查各有含义。工作类别仅汇总真实操作，Agent 的结束消息不等于目标达成，调用成功不等于权限通过。建立目标不启动模型，示例只填入输入。启动前保留源码权限、额度和执行边界；人工批准规则和确定性结论继续由原所有者负责。

## 设置与维护

齿轮进入独立设置页，开发工具、本地存储、运行与维护为一层分类。工具连接与应用授权并列，无第三层客户端导航；具体客户端用选择器。对象与状态就近，接入服务与维护动作组成完整区域，地址和解除配对退到连接管理。

工具连接与应用授权按接近的工作量并列，客户端和连接状态就近，接入状态与开关归在同一服务组；配置和授予操作位于各自区域右下角。设置面板按实际内容分组和限制宽度，不用远端按钮、超长字段或无关说明填充空白。

运行诊断围绕当前组件状态组织，四项采用两条对齐的阅读轨道，名称与状态保持同组；核对时间归标题下方。诊断摘要是单一深入入口，复制和下载归摘要内操作。当前版本与工作区位置收为轻量页脚，进入更新后才展示当前操作阶段，已完成回执不与空白更新表单争夺主区。窄屏依次阅读。存储清理按相同列比较候选数量、大小及选择，并保留实际保留范围。官方示例围绕当前实例组织进入、停止及工作区链接，归档和实现切换退后。

所有异常状态保留页面标题、当前对象、失败原因与可行恢复；嵌入读取失败留在所属区域，不用重复主标题。方案准备读取失败时，保留方案分类、草稿及准确修订回程，提供应用连接和重新读取。空状态将说明与操作组分开，多个操作在组内排列并随宽度换行，不能共占同一网格位置。没有数据不自动视为首次使用，状态未知不自动重放写请求。

规则详情以规则名称、资源范围和检查结果连续阅读。角色、操作和资源已经包含在标题及范围中，不另用长期侧栏重复；相关材料和最近修改在结果后接续。规则目录仍按列表与当前详情选择，不能把目录选择和独立详情页强制套成相同分栏。

权限提案审阅先展示按业务操作分组的概览，同一行连接访问要求、资源、业务结果与变更类别，支持跨规则比较。选中后打开共享详情栏，概览收起重复的结果列；关闭后恢复完整比较及原条目的键盘焦点。详情一次呈现一条规则的主体、资源、条件和受保护结果。业务定义与提案来源使用同层分类，切换后保留所选条目。窄窗由概览进入详情，避免两栏挤压或上下重复。调整及停用保留原版本与批准后的对照，缺失依据明确提示；浏览与选择不产生批准，底部确认仍覆盖全部访问规则及业务定义，未知回执继续查询原批准。

记录页区分首次无数据、筛选无结果及读取失败：首次无数据集中说明产物和开始动作，不展示无作用的筛选栏；筛选无结果保留查询和清除入口；读取失败保留原因，不宣称没有记录。仅在真实内容需要分组时画分隔线，空列表的筛选与空态不叠加整条边界。


任务往返保留当前对象和选择范围：从规则进入检查时使用当前生效规则，并保留必要正常对照；规则已丢失或显式本地范围不存在时，不回退为全量检查。准备材料、补充账号、编辑来源请求、查看运行及重新核对后，返回到对应的范围或草稿。全局目录入口可以开始新任务，针对当前对象的入口不能静默扩大范围；按钮名称与目标任务一致。

关联报告、源码修改和运行配置保留准确发起位置，返回到原规则、问题、协作任务及所在分类。协作产物审阅、后台结果与连接设置采用同一任务回程；返回交接草稿本身不再叠加一层任务回程。指定问题优先于目录筛选，已验证问题自动可见；对象不存在时说明缺失，不以其他问题替代。用户主动取消已验证筛选时退出相应对象选择。

测试下的操作目录称为“操作与材料”，组合实验称为“业务场景”，已形成的检查集合称为“检查记录”。这些页面归属测试，源码修改归属权限与覆盖；协作列表和详情均选中原 Agent 入口。规则与操作目录返回后恢复搜索、筛选、选中项、详情展开、阅读位置和焦点，不通过新增全局入口补偿回程缺口。

结果判断配置需要补充运行时，直接进入“源码与受控运行”，由应用工作面保留返回草稿入口；切换应用资料分类仍保留该回程。返回后重新打开同一判断配置及其本地草稿，配置、保存、采用和执行继续分别确认。

## 检查准备、流程维护与协作审阅

检查预览默认在同一任务中核对准确范围、准备缺口和将执行的操作。调整范围时进入选择工作面，复用原规则选择器；缺口按业务操作归组为一层目录，正文一次解释一项及其全部原因、关联规则和准备入口；执行预览一次核对一项操作的实际场景。补材料回程保留精确范围、所属分类与当前项；已解决的缺口显示变化，不悄悄跳到其他问题。提交仍以重新读取的计划指纹和服务端执行门槛为准，未知回执先核对原操作。

同一准备事项有多个目的地时，入口写明所属权限要求或业务结果，不用“账号1、账号2”等顺序编号区分。局部补材料采用轻量导航，整页推进保留在底部右侧；缺口未解决时直接说明仍需准备，不能笼统承诺无需重新准备。

接口流程分开处理新建与维护。新建保留引导和逐步准备；从准确修订进入的已有流程使用可直接切换的账号、请求、结果与恢复、保存与使用分类。保存、采用和执行明确分开；未保存修改不可冒充已保存修订参与试运行。候选先比较，再带入草稿；采用仍由原配置入口确认。

Agent 审阅围绕产物本身展示准确修订、比较基准、变更内容、影响和后续动作。流程候选在当前事项中读取准确版本并比较，不再次复制编辑器或另造采用逻辑；完整配置与采用仍进入原流程所有者。没有结构化比较合同的其他产物显示真实产物类型、操作回执和原审阅入口，不推测差异、风险或采用状态。待补充的问题、未知回执与候选审阅继续分工。

目录分栏随集合规模调整：只有一个对象时直接展示内容与相关准备，不保留无选择价值的半页目录；多个对象时使用目录与当前实际内容。多项变体逐项阅读，大集合说明按需展开，不把全部长正文堆进右栏。

空工作区欢迎页的应用与示例入口分别在所属卡片底部右侧收口。整块导航入口显式选用对应的集合行表达，不能依赖默认行内链接样式后再用低优先级局部规则补高度；示例三个入口在宽窗均匀排列，保持完整内边距与可见键盘焦点，窄窗空间不足时转为完整行。

## 同一事项中的准备、处理与反馈

一次检查拥有自己的范围与回程。从待准备事项进入账号、操作、测试数据或证明时，原检查范围保留在外层；当前编辑使用完整主区。短选择就地完成，复杂编辑不塞进窄侧栏或多层弹窗。补账号后先回原流程草稿；保存材料取得回执后，再回本次检查重新核对。仅关闭编辑器不显示“已完成”。

已保存方案的“准备这次检查”直接进入本次准备，按准确修订核对材料；确认使用这些材料后才进入执行预览，不自动运行。旧准备深链接继续可用。问题详情将“问题与证据”和“处理与复验”作为同一原题的两项工作，登记、加载、补材料与复验保留该问题。问题目录已经占一栏时，修复正文使用剩余完整宽度，不能再套一条长窄说明栏。

当前检查的下一步取范围内准备投影，范围外更高优先缺项不抢占；没有材料任务时仍保留核对权限要求的入口。对象失效显示缺失状态，不替换成其他对象。协作返回准确检查、修订和编辑位置，草稿由原编辑器继续保管；交接只保存白名单对象引用，不复制原始表单值。

组合后的返回文字必须对应实际目的地，不能沿用独立页面的“返回材料清单”。返回本次检查与返回原编辑器各有用途；没有中间任务时不重复放同义返回入口。

方案材料详情将使用要求与当前材料分组，宽工作面并列，窄工作面按阅读顺序上下排列。标题与状态同排，技术引用按需展开，准备动作在详情区右下收口；不将标题、状态、重复说明和操作分别堆成一条纵列。

问题内嵌修复任务由父页拥有问题标题与页签。流程提示使用较轻层级，当前任务与推进操作集中在正文，复验依据退为辅助内容；分组间距大于标题与说明的间距，内嵌任务不重复增加一层正文内缩。尚无修改时不展示空的文件折叠；修改登记后的流程提示进入条件核对，真实复验仍须满足原运行和材料门禁。

准备中的进展、正常对照选择、业务要求处理与检查中断同样遵守任务分组。进展与状态就近呈现；需要人决定时先说明选择用途，再列出选项，确认操作放在本区末尾。执行中断时将已有进展与失败原因分开，在宽工作面并列，诊断细节按需展开；不得把中断或载入完成表达为业务检查通过。

业务要求的处理方式保持短选择，判断依据与保留的业务要求使用相邻字段组；待确认范围的标题、状态与解释分层，不能在无间距的连续正文中混排。录制取消等次要动作排在当前推进之前；数据选择输入限于合理阅读宽度，操作区在窄工作面完整换行并保持右侧收口。

协作上下文将任务产物与原交接内容相邻组织，连接管理退后。两组在实际可用宽度充足时并列，不按窗口宽度压成两条窄栏；长请求路径正常换行。代码载入按标题与运行状态、后续说明、末尾操作组织，应用配置作为次要入口，载入动作保持最后。查询与恢复原请求仍分别表达，布局不改变未知回执的处理规则。


## 跨工作面的共同表达

长期目录的分类入口与读取内容分别保留。测试目录、检查方案、业务场景、检查记录和应用资料在模块或首次数据读取失败时仍提供准确分类；加载等待使用相同入口。内嵌资料模块仅替换内容，外层继续拥有标题和分类；恢复成功后只呈现实际页面的一组入口。具体编辑、报告与执行任务沿原准确回程继续。

聚焦任务共用返回与标题之间的24px分组间距，所有页面标题的对象名与主标题保持12px间距；正文分组继续由实际对象和内容决定。长期分类入口保持可达，当前任务接管自己的标题、返回、异常与收口，不以隐藏全部分类换取聚焦。

业务含义与检查范围的互斥选项只修改本地选择，确认后再提交原命令。相同恢复去向合并准备入口，但保留全部缺口原因和原执行门禁。暂停协作时，人审产物与继续执行区分主次；报告的检查对象、比较两轮的时间身份和证据所属结果保持就近可读。普通管理在当前对象内展开，完整授权、配置和执行继续使用准确的独立审阅边界。

独立证明记录将当前值与说明作为主阅读区，采集方式、记录关联和检查背景在相邻辅助区核对；原文仍按需展开。按实际容器宽度并列或上下排列，短事实不沿整幅画布连续堆在左侧。已有方案的少量只读范围在当前预览内展开，可编辑范围任务接管自己的主标题和直接返回；独立证据阅读同样只保留当前深度的返回。

顺序阶段应用于新建接口流程、登录准备、证明授权与采用、问题处理与复验；各自状态映射由业务负责，共用内部表达。已有流程的自由维护仍使用分类，不改成强制向导。应用接入情况是独立条件清单，注明用途，不编号为必经步骤；后台检查与批量准备使用真实执行进度，证据路径和处理历史则使用连续记录。

对象头部、事实组、内容表、展开和比较分别复用共同模式。内容表用于比较，连续索引用于持续选择，两者不合并。比较前后方向稳定，说明紧邻事实，容器放不下时顺序纵排；不依靠压缩字号和窄栏堆叠。阶段、状态和对象头进入嵌入工作面后保持内部规则，只有外围布局适配所在任务。

比较阅读同时统一列关系与纵向节奏。总体说明与限制先成组，与逐项依据保持24px分隔；依据内部的规则要求、实际观察及正常对照分别成段，折叠的测试对象再退后。共同比较模式拥有这些间距，不能只迁移并列布局而遗漏原段落留白。

简短准备清单优先保持完整阅读顺序，不按固定两列均分。独立进度摘要可与单列条目在可用宽度内并列，窄工作面上下衔接。正常业务对照等核对项将名称与短状态就近并排，仍使用真实已发布状态，不能推断为修复成立。

对象标题、局部索引、修改摘要与证据详情中的短状态紧接名称右侧，间距和换行由共享名称组维护；元信息和行操作各自归位。内容表需要逐条比较时继续保留表头及独立状态单元格，状态不移入名称列。带装饰图标的对象头使用图标列与文字列：图标居中对齐标题首行，说明和换行后的状态沿文字列阅读。标题不叠加单侧边距，图标不靠垂直偏移补偿。

来源核对、运行诊断、试运行条件和复验范围使用共享状态概览。状态紧接本项名称右侧，保持固定间距和文字基线；条目按实际可用宽度排列，使用留白区分，不逐行添加横线或把状态拉到模块最右侧。长名称和长状态完整换行，窄区按原顺序阅读；单条属性的限宽不进入整组。标题、说明、概览和动作属于同一模块，不把一句解释单独放成半栏。证明方法、资源事实与管理入口形成完整信息组，最新核对结果形成另一组；按可用空间并列或顺序阅读。试运行将账号核验、恢复请求和逐步请求记录分组，步骤名称与请求反馈靠近，HTTP 等过程数据退为次级信息。请求被接受不表示业务恢复或权限通过。材料授权范围与关联规则保持单列连续阅读；事实表、对象目录、成对比较和独立编辑区域继续按其任务组织。

同一工作面不机械叠加多层常驻目录。试运行历史在独立任务中使用记录选择与当前正文；单条记录直接展示，不增加空目录。报告深入操作经过或证明记录时退出完整报告总览、统计与筛选，只保留当前事项的短上下文、证据读者和准确返回业务结果的路径。只有连续浏览真实父子集合时才保留多级分栏；标题、修订、状态与时间在当前阅读层级中各有明确归属，不在相邻的大块选择面里重复强调。

移除嵌套目录后重新分配外层空间，不能继续沿用原目录占宽。接口流程的编辑、试运行与采用拥有不同决定和副作用，分别进入当前任务；不以固定双栏或统一限宽代替职责划分。留白服务于分组，不在记录与相邻任务之间保留无用途的大段空档。


## 按具体任务收敛正文

工作台只承载当前工作与最近检查，名称和检查结果先于时间，用途放第二行；方案、材料和问题的长期管理回到所属目录。应用连接概览顺序呈现当前连接与源码，短编辑使用对话框，不常驻新增表单。账号核对只说明本账号用途和实际身份；证明阅读集中当前缺口、读取范围与下一步，完整历史按需展开，当前未解决项持续可见。

已有接口流程的核对与试运行分别阅读，采用准确的已保存修订。多条试运行记录使用索引和当前正文，单条直接阅读。少量报告结果在原行展开业务依据，要求和观察只说明一次；结果较多或需要持续比较时保留索引。深入操作经过或证明记录使用独立任务，去掉内外重复页签，返回原报告、原事项与原回程。修复任务按真实阶段替换正文，验收依据在同一轴上接续。

Agent 问答不预选建议。已保存来源及其修订来自原来源接口，交接草稿单独标明；没有完全对应的来源时明确提示，允许“暂不确定”交回原任务查证。普通文字回答不批准规则或扩大执行授权。运行诊断将异常组件集中解释并共用摘要入口，可用组件按实际数量排列，摘要工具归同一组收口。

示例启动后直接核对完整预置规则，不再单独询问一个孤立的下载偏好。读取草稿不创建提案；明确批准后，先核对服务端提案与刚展示的完整命令一致，再沿原批准用例执行。内容变化转回完整审阅，结果未知先回读原提案。批准完成后进入示例材料范围预览，仍需明确确认才准备账号、操作与证明。

方案准备缺少检查连接时，主动作进入原应用连接工作面，并保留方案及修订的回程；不能用重复准备材料替代连接配置。材料满足后才确认准确绑定，进入同一方案的预览与运行。接口资料保存回执独立于目录刷新；目录更新失败仍显示已保存的来源修订，并能定位原来源，不引导重复导入。

方案准备在材料前说明连接前提；每项材料将当前事实、本次要求和准确补充入口放在同一阅读组，详细使用要求及对照按需展开。只有一个材料事项时直接阅读，多项继续使用原目录。查看方案内容进入准确方案修订并保留当前准备回程，不用同一预览地址充当范围阅读入口。

检查缺口以业务操作为目录单位，同一操作的账号、执行和证明原因在正文相邻解释；单操作直接阅读。Agent 问题区从原判断方式、准确动作与来源修订提供已有依据，字段存在与业务用途已确认分别说明，缺少依据时明确未知；执行确认同时交代当前任务和实际待执行动作。问题与协作筛选明确已读取集合的范围，当前对象被过滤时保留选择并提示。

材料批次运行时由该批次拥有进度、当前事项和停止操作，手工材料正文在批次结束后接续，不把运行中账号与旧材料状态同时铺开。当前操作的缺口先于全局影响；同角色账号与同一执行准备合并入口，资源和证明仍按准确规则、业务结果分别定位。零可执行场景不建立第二套空目录。

已保存流程把修订用途、账号、资源、执行和恢复事实放在同组；试运行、历史阅读与确认用于检查分别进入对应任务。报告优先展开实际发生变化的项目，共同要求只说一次，观察与解释相邻；通过报告可沿用准确原范围继续预览，Agent 解读保持辅助。协作回答保存、后台执行和产物形成分别反馈，确认执行前常显已知授权对象，完整协议按需展开。
