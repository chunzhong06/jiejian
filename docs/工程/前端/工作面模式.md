# 工作面模式

本文维护界鉴各任务采用的具体组织；通用判据归[布局与视觉](布局与视觉.md)。所有页面沿用已认可的控件、颜色、字体和动效基准并消除差异；布局重建不强求不同任务使用相同列数。下面的工作面都必须保留准确对象、草稿、读取失败与返回位置。

## 目录与详情

规则、场景和问题用连续目录支持定位、比较与筛选。标题说明任务；搜索和筛选位于目录工具区；选中后相邻显示当前对象。表格行只保留名称、必要范围、关键状态和时间，完整依据进入阅读区。目录不将每个对象变成独立大卡片。

规则一行对应一条实际要求，保留各自角色、资源范围、状态条件及结果。右侧集中显示所选规则的含义、检查材料和准确结果入口。搜索或筛选改变可见范围后，详情对应可见对象；完整详情仍保留规则、修改与历史深链接。

测试目录以业务动作组织执行方式、结果要求和实际准备状态。操作录制、接口流程及其草稿分别表达；没有接口流程不等于材料未准备。就绪来自服务的准备投影。右侧展示当前动作的执行、结果、恢复与修订，分别进入材料核对或接口流程；共享账号与证明来源集中在“准备与资料”。准备读取失败显示待核对，不推断没有权限要求。

来源的请求索引与详情相邻。搜索属于请求索引，来源名称按组出现一次，请求行保留方法、名称及路径。详情先阅读业务用途，需要修改时再编辑名称与关联；参数和导入依据退后。草稿保留最初修订，保存仍核对并发。窄窗选择请求后进入单一详情，返回保留搜索与选择。

目录详情展开时，索引只保留名称、状态和区分同名对象所需的最短上下文；资源归属、实际结果和完整说明集中到详情。关闭详情后恢复完整摘要、焦点和阅读位置。没有所选对象时不预留空详情列。

目录的相邻详情栏将名称与状态放在同一标题行，事实按标签和值排列。任务操作在详情栏右下角收口，次要操作在前、主要操作在后；阅读导航仍保留自然顺序。窄栏允许标题换行，不能让状态脱离对象，也不以固定大高度撑开说明与操作。

## 工作台与应用资料

工作台左侧为当前任务、规则/材料/问题摘要与最近检查，右侧为当前环境和应用资料。当前任务只解释实际原因和推进动作，不靠空白大卡片或装饰步骤填充。运行进度只来自真实执行；资料数量可直接链接所属工作面。资料、目标连通性与部署声明不在多个横栏重复。

应用与来源分为环境、接口来源、业务角色与操作、源码与受控运行。分类页不重复同义主标题。环境目录以连续记录比较名称、地址、部署说明和当前使用状态；新增/编辑表单使用固定阅读轨道，保存、切换和地址核验分别承担不同后果。没有保存环境时直接呈现表单，当前地址只作为相关上下文。

创建应用以当前表单为主，本地源码与独立示例是两组自然高度的开始方式，各自说明后果并在组内收口；不把多个孤立标题、提示和按钮堆成一列。

业务角色与业务操作是两组可独立核对的线索，宽窗并列，窄窗依次阅读。名称、处理方式和来源依据各有位置；保存只确认业务含义，访问规则仍单独审阅。表单失败在所属任务附近，不放在整页底部与内容粘连。

源码与业务、应用运行及检查条件按真实责任组合。“连接已有应用”和“由界鉴启动”一次只显示对应字段。实际实例形成后显示其地址与管理操作，不同时平铺空启动表单。切换编辑方式不启动、停止或采用地址；草稿和未知操作编号继续保留。

## 场景与材料

材料工作面以业务操作为上下文，左侧连续导航，右侧编辑或阅读当前材料。选中带与目录相接，图标、名称、状态和方向列稳定，无悬浮卡片。所用权限和相关资料为次要上下文；既有账号、证明和流程可复用，不要求重复填写或重新准备。

局部索引统一沿用检查准备的材料目录：未选中融入画布，选中使用浅蓝整行、左侧3px标记和连续移动，行内保留稳定的图标、名称、状态与方向位置。请求、账号、证明来源、流程阶段、执行步骤、试运行记录、问题与报告索引共用这一实现；业务只负责内容、列定义和必要密度，不另加悬浮圆角卡片或独立底色。比较表格保留表格结构，采用相同的选中表面与左侧标记；全局侧栏和横向页签仍各守原有职责。

接口流程是可维护资产。顶部进度显示起点、账号与数据、执行请求、核对与使用；存在字段比较时增加“结果核对”，数据变更操作显示“结果与恢复”，没有相应配置时直接核对。已经完成的阶段可以返回，必要输入仍控制推进。请求编辑正文只有执行顺序和当前请求两列；请求方式、路径与参数集中编辑，受检请求用明确状态表示，其他步骤可显式设为受检。保存后的试运行为主要工作区，场景摘要与采用在旁边收口；本次执行与历史修订在同一区域切换，实际反馈紧接输入或所选记录。

阶段进度不与正文的步骤索引并列争夺宽度。起点方式和请求参数分别在所属阶段内选择；动态防伪参数由明确命名的配置对话框加入准备步骤，资源提取、字段比较和恢复接口进入后续阶段。请求参数默认定位已有内容或内建资源取值，空参数说明可跳过，不能让使用者误以为必须逐项补齐。执行步骤选择带末端与编辑分界之间保留独立留白，详情也有自己的阅读内边距。场景核对沿用画布，仅保留事实与操作收口，不铺额外整块背景。

试运行预览和执行、保存草稿和正式采用各有独立后果。未知执行只查询原记录，活动期间不采用；旧试运行和仍被采用的修订持续可读。从旧记录继续编辑建立新修订，不覆盖旧事实。试运行结束不产生权限结论。

账号使用列表和相邻详情，真实身份、登录配置与会话有效性分开。账号槽位定位优先于自动选择；不可用对象保留原因，不能悄悄换成另一个主体。证明来源使用配置、读取范围、预检查及采用的渐进工作面。已有数据库对应先读摘要，无剩余候选时不显示空选择器；配置存在不代表实际读取已成功。

证明来源按“结果说明、核对记录、来源与管理”组织同一对象。结果说明呈现判断方式、资源归属与完整参照；核对记录直接列出已确认、尚未确认及不支持的事实；来源与管理承载读取位置、限制、范围查看、判断方式调整和撤权。仅字段映射等低频技术引用保留展开。切换分类保留未提交文件，当前推进动作在工作面右下角；允许读取、开始核对、正式采用及撤权仍各自保留原有确认边界。

## 检查、证据与修复

检查预览按业务操作展示范围、账号、结果要求和缺口。同一准备入口可以归并，但保留所有原因、原始对象、规则、修改及回程；不同业务动作不合成笼统提示。提交区域只确认当前真实范围，不将已有授权重复变成勾选任务。

报告先给本轮判断与范围，再提供结果筛选和连续列表。筛选是定位工具，不做第二组结论卡；改变阅读范围不改变报告结论。选中后目录收窄，证据阅读占主要区域。主区直接比较权限要求与实际结果，再给判断记录；账号、资源、条件和请求/恢复核对在相邻上下文。操作路径与证明记录保留各自页签和准确片段定位。窄屏进入单一阅读面，关闭后恢复选中项、焦点和原滚动位置。

归档属性是报告上下文，放在报告元信息中；返回官方示例与返回该应用检查记录共用顶部操作行。归档目录在标题中说明所属应用，不再用独立横幅重复占据正文高度。只读边界仍由归档查询与实际操作能力负责。

单条证明先展示类别与实际值，来源和范围退后；前后状态保留各自含义，不用成排勾号暗示权限安全。技术调用、HTTP 成功、业务提交和安全结论分别表达。路径与发布记录不由前端推断或生成。

问题工作面用目录定位原题，右侧阅读影响、正常对照和复验。比较表保留禁止场景、选定正常场景及保留功能的独立结果，原检查与新检查分别呈现。源码登记、关联修改和复验带准确问题及回程；源码档案属于查阅，不代替问题处理。来源记录与新验证都持续保留。

规则详情一次呈现检查结果、修复与修改、检查历史之一；登记表只属于修复任务。历史展开只增加下面的内容，不改变触发器尺寸或所在列。登记草稿和原题引用不能随切换丢失。

单次检查摘要先将结论与状态并排，再按同一基线展示检查范围和时间，阅读依据的操作在摘要右下角。不能把徽标、结论、元信息与主操作全部排成左侧一列，也不通过增加空白高度突出操作。

## Agent 协作

目标使用紧凑正文，与任务类型和单一状态放在页签之前，不单独围合成大卡片。“当前工作”在左侧连续索引列出待办，右侧一次展开一个问题、执行确认、未知回执核对或产物审阅；索引使用共享选择表面，分类使用短文字，不重复为每项加状态徽标。默认先核对未知操作，其次补充业务含义，用户可以自由选择处理顺序。无待办时，主区显示实际执行、继续入口或检查结果。

“产物与上下文”集中准确产物、交接结构与返回位置，“处理记录”单独查阅操作回执、后台执行和事件，首屏不再重复堆叠目标、待办和时间线。页签和事项切换保留未提交回答；已处理事项消失后选择剩余待办。主操作留在当前详情右下角，暂停、结束与停止归任务操作。尚无产物时准确说明，不画固定阶段进度或虚构已完成事项。

接口流程与证明设置在所属工作面提供当前草稿交接，委派对话框集中展示目标类型、交接对象与接续位置；不在各页复制一套聊天或执行器。任务提供目标补充与自由回答，建议选项只预填回答，统一在右下角提交。任务列表用于查找和切换，目标工作面仍负责处理决定与产物。流程候选使用当前草稿与准确修订的并列表格，带入、保存和采用分别有明确动作；后台读取不自动覆盖本机草稿。既有主题、字体、选中表面与动效继续由公共实现拥有。

操作回执、后台执行结果和发布检查各有含义。工作类别仅汇总真实操作，Agent 的结束消息不等于目标达成，调用成功不等于权限通过。建立目标不启动模型，示例只填入输入。启动前保留源码权限、额度和执行边界；人工批准规则和确定性结论继续由原所有者负责。

## 设置与维护

齿轮进入独立设置页，开发工具、本地存储、运行与维护为一层分类。工具连接与应用授权并列，无第三层客户端导航；具体客户端用选择器。对象与状态就近，接入服务与维护动作组成完整区域，地址和解除配对退到连接管理。

运行诊断与版本更新并列，窄屏依次阅读。版本更新只展示当前操作阶段，已完成回执不与空白更新表单争夺主区。存储清理按相同列比较候选数量、大小及选择，并保留实际保留范围。官方示例围绕当前实例组织进入、停止及工作区链接，归档和实现切换退后。

所有异常状态保留页面标题、当前对象、失败原因与可行恢复；嵌入读取失败留在所属区域，不用重复主标题。空状态将说明与操作组分开，多个操作在组内排列并随宽度换行，不能共占同一网格位置。没有数据不自动视为首次使用，状态未知不自动重放写请求。
