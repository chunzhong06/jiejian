# Agent协作工作面

尚未完成的模型交互受限时，当前工作面直接显示已知原因及接续方式。正常的历史执行说明仍按需阅读，已完成业务不会被旧模型提示遮蔽。产物读取身份包含项目、产物、修订和所指业务，链接改指另一动作时重新核对，不复用上一动作的已读候选。

用于组织当前问题、执行确认、候选审阅、正式产物与原任务接续。模型建议、保存候选、本机采用和确定性检查分开。共同选择、信息归属与返回规则见[工作面模式](../工作面模式.md)，视觉、交互和实现规则各按原所有者维护。

## 任务与资料

任务名称、简明业务目标与单一状态放在页签之前，不单独围合成大卡片。目标与技术执行原文分开，原始委派在资料页保留准确阅读入口。“当前工作”在左侧连续索引列出待办，右侧一次展开一个问题、执行确认、未知回执核对或产物审阅；索引使用共享选择表面，分类使用短文字，不重复为每项加状态徽标。默认先核对未知操作，其次补充业务含义，用户可以自由选择处理顺序。无待办时，主区显示实际执行、继续入口或检查结果。

“产物与相关资料”集中准确产物、交接结构与返回位置，“操作记录”单独查阅操作回执、后台执行和事件，首屏不再重复堆叠目标、待办和时间线。页签和事项切换保留未提交回答；已处理事项消失后选择剩余待办。主操作留在当前详情右下角，暂停、结束与停止归任务操作。尚无产物时准确说明，不画固定阶段进度或虚构已完成事项。

操作记录区分每项操作的结果与按时间排列的任务进展；两者同时存在且容器足够宽时并列，单组直接阅读。面向用户使用“操作结果”，避免将内部“回执”作为标题或完成状态。保存候选明确为“已保存”，发起检查明确为“已提交检查”，通用成功仅表达“已返回结果”；后台执行与正式检查结论由所属任务提供。名称与结果在同一记录内紧邻，名称变长时允许换行，不用伸展列把短状态推到容器另一端。准确操作内容只读取服务已有的summary，按需展开，不从原始参数拼造解释。仅有模型执行说明时仍属于已有记录，不能同时显示“还没有操作记录”。

最近回执可以优先显示，更早的回执必须保留具名展开入口及原顺序，不能在截取最近几项后永久丢掉其余内容。范围和失败诊断从属于各自回执；展开记录只阅读，不附带恢复或重发命令。回执完成、模型回合结束和正式检查结论继续各自表达。

接口流程与证明设置在所属工作面提供当前草稿交接，委派对话框集中展示目标类型、交接对象与接续位置；不在各页复制一套聊天或执行器。任务提供目标补充与自由回答，建议选项只预填回答，统一在右下角提交。任务列表用于查找和切换，目标工作面仍负责处理决定与产物。流程候选使用当前草稿与准确修订的并列表格，带入、保存和采用分别有明确动作；后台读取不自动覆盖本机草稿。既有主题、字体、选中表面与动效继续由公共实现拥有。

操作回执、后台执行结果和发布检查各有含义。工作类别仅汇总真实操作，Agent 的结束消息不等于目标达成，调用成功不等于权限通过。建立目标不启动模型，示例只填入输入。启动前保留源码权限、额度和执行边界；人工批准规则和确定性结论继续由原所有者负责。

协作上下文将任务产物与原交接内容相邻组织，连接管理退后。两组在实际可用宽度充足时并列，不按窗口宽度压成两条窄栏；长请求路径正常换行。

协作任务的“任务产物”只列此次成功操作形成的结果；原报告、原题修复入口与编辑草稿归“交接内容”。报告引用须读取冻结的具体操作、账号、资源与当时结果，直接说明交接对象后再提供阅读入口，不以“原问题报告”替代对象说明。原事项缺失明确反馈并提供重读，不自动改选其他事项。尚无产物时交接依据成为主区，任务产物空态与连接管理退为辅助区。每项依据的账号、操作、状态与资源在同一对象头中；当时要求与实际观察在同一容器内并列，窄区顺序阅读，证据入口在该容器右下收口。返回交接位置属于整页回程，不夹在记录正文中。单一资料链接不绘制假记录边界。

具名报告交接复用共同的要求、实际发生和本次判断组合，避免在对象标题及正文重复声明状态。只有整份报告而没有选定事项时，保留报告级结论及准确操作集合，不擅自挑选一项作为交接对象。

## 当前问题与回答

协作只有一个待答问题时，以问题作为主标题，原任务目标保留为上下文；多事项仍由目录选择当前项。已保存来源与交接草稿分别标明，准确来源链接紧邻回答，任务管理放入原菜单。选择已知选项不自动展开补充表单，“暂不确定”交回原任务在既有授权内查证。

协作任务优先使用明确提供的简明名称；旧长目标按任务用途命名，不截句推断业务含义。明确交付目标与实际保存记录对应展示，保存份数只来自当前目标之后成功的独立对象，不把保存当作采用或检查完成。当前问题直接显示具体业务问题及必要用途，内部诊断和执行指令进入原始问题与补充依据。旧长问题缺少简明说明时明确告知，保留原文和继续查证选项，不生成未经核对的业务摘要。失败后的模型会话选择属于启动确认，先说明保留的业务内容与不会带入的模型历史，默认继续原会话；只有明确选择并提交才另开会话。取消、阅读和勾选均不启动模型。

单一协作事项直接阅读，不继承多事项目录正文的边线与内距；窄窗也不在页签下重复增加目录分界。较长的实际问题标题在既有阅读轴内均衡换行，保留完整题意，不能用截字、孤立短尾行或新增摘要替代原问题。主题切换保留当前展开内容，收起后将焦点交回原实验行。

Agent 问答不预选建议。已保存来源及其修订来自原来源接口，交接草稿单独标明；没有完全对应的来源时明确提示，允许“暂不确定”交回原任务查证。普通文字回答不批准规则或扩大执行授权。

Agent 问题区从原判断方式、准确动作与来源修订提供已有依据，字段存在与业务用途已确认分别说明，缺少依据时明确未知；执行确认同时交代当前任务和实际待执行动作。问题与协作筛选明确已读取集合的范围，当前对象被过滤时保留选择并提示。

协作回答保存、后台执行和产物形成分别反馈，确认执行前常显已知授权对象，完整协议按需展开。

## 候选审阅与准确回程

未知回执将原执行范围与当前核对方式并列；可点击的主要动作只查询同一操作。暂停不遮蔽这个核对入口。模型接续将保留的业务任务与本次启动分开，历史执行说明按需打开；进入会话选择、勾选及取消都不调用模型。已有正式检查结论优先呈现，不因仍可接续模型而退回等待界面。

Agent 审阅围绕产物本身展示准确修订、比较基准、变更内容、影响和后续动作。流程候选在当前事项中读取准确版本并比较，不再次复制编辑器或另造采用逻辑；完整配置与采用仍进入原流程所有者。没有结构化比较合同的其他产物显示真实产物类型、操作回执和原审阅入口，不推测差异、风险或采用状态。待补充的问题、未知回执与候选审阅继续分工。

协作产物较多时，资料页先以完整表格概览保存内容、处理进展与阅读入口；选择待审内容后进入原事项目录与当前正文。目录使用具体业务操作、结果或场景的名称，不能让多份产物都呈现为同一个泛称。流程阅读准确修订与变化，结果判断方式并列说明对应业务结果、资源及准备进展；场景默认用整表比较实验、操作账号、测试资源与预期要求；选择后展开步骤和对应要求，收起恢复原行焦点。预期要求只匹配完整规则引用，当前新修订不替代旧要求。场景原说明按需阅读，额外条件不得靠猜测或截句改写。保存候选、允许读取、可用性核对与正式采用分别表达。

产物入口携带原任务、页签和选中事项；直接打开材料后的返回沿实际发起位置接续，不先进入用户未访问的准备目录。原候选被后续修改替代时，明确原修订与当前修订的区别，另设核对当前配置的入口；不能静默以新配置充当旧候选。多份独立判断方式和已审阅场景继续保留各自入口。

## 完成与继续

准备目标完成后，在当前进展右下继续进入检查准备；规则目标回到权限规则。实际完成依据优先显示，早先模型回合的受限或失败信息保留在操作记录，不能把历史执行提示继续当作当前业务缺口。

## 外部工单

外部工单审阅先说明发送位置与后果，再以完整段落展示将发送的标题和正文；原报告与问题编号收在可展开的检查记录中。按钮写明“创建这张工单”，远端关闭仍不改变本地修复结论。不得把凭据、协议字段或整份参数JSON作为审阅正文。
