# 报告与证据工作面

检查历史的分页与比较选择按项目、归档状态和准确规则修订隔离。显式更换查找条件从第一页开始；从报告或比较返回恢复原页、选择和阅读位置。较早页为空仍保留上一页入口，不能显示为整个应用首次无记录；读取失败原处重读同一游标。

用于阅读正式结果、比较检查、理解业务证明及继续未查范围。结论和记录来自冻结事实，当前配置不补写历史报告。共同选择、信息归属与返回规则见[工作面模式](../工作面模式.md)，视觉、交互和实现规则各按原所有者维护。

## 结果与范围

关键结果使用稳定阅读关系：当时要求、实际发生、本次判断。要求带出主体、操作与资源归属，后果采用已确认的业务事实，判断直接消费正式发布值；正常起点、问题报告和复验共同遵循此语法。接口响应、事后恢复及技术核对作为相邻辅助依据，不与实际后果争夺主视觉，也不参与前端重新判定。

深入依据和证明目录继续采用同一阅读关系。证明配置的名称说明核对什么，本次观察说明发生了什么：例如“内部完整包已被接收”是核对内容，入口主文字应按发布状态显示完整收到、未完整收到或尚未确认。自定义业务名称保留原文，放在明确的核对内容位置。多项证明共用同一封存文件时合并文件入口，逐项观察仍完整保留；辅助记录单独标明，不升级为必要证明或安全结论。

复验完成区直接显示原问题以及实际参与核对的正常操作，账号、动作、资源与结果相邻；同一事项兼有正常对照与回归用途时合并展示并保留用途。缺少结果或对应待核对时明确保留该状态，不用三个抽象分类的“已验证”替代具体成果。完整逐项比较与证据仍可深入阅读。

报告先给本轮判断与范围，再提供结果筛选和连续列表。筛选是定位工具，不做第二组结论卡；改变阅读范围不改变报告结论。选中后目录收窄，证据阅读占主要区域。主区直接比较权限要求与实际结果，再给判断记录；账号、资源、条件和请求/恢复核对在相邻上下文。操作路径与证明记录保留各自页签和准确片段定位。窄屏进入单一阅读面，关闭后恢复选中项、焦点和原滚动位置。

归档属性是报告上下文，放在报告元信息中；返回官方示例与返回该应用检查记录共用顶部操作行。归档目录在标题中说明所属应用，不再用独立横幅重复占据正文高度。只读边界仍由归档查询与实际操作能力负责。

报告先阅读结论和逐项结果，完整适用范围由一个标题统领，以“检查依据”和“业务线索”两项成对字段组织。字段内保留原条件、历史说明、完整清单和记录引用；业务线索组件嵌入时不重复生成同用途标题，独立工作面仍有自身区域名。

单次检查摘要先将结论、所属对象与检查范围成组，阅读依据的操作在摘要右下角。历史列表为区分先后显示时间；当前单份结果的准确时间留在记录依据中。不能把徽标、结论、元信息与主操作全部排成左侧一列，也不通过增加空白高度突出操作。

少量报告结果在原行展开业务依据，要求和观察只说明一次；结果较多或需要持续比较时保留索引。深入操作经过或证明记录使用独立任务，去掉内外重复页签，返回原报告、原事项与原回程。

报告优先展开实际发生变化的项目，共同要求只说一次，观察与解释相邻；通过报告可沿用准确原范围继续预览，Agent 解读保持辅助。

官方示例的起点报告在结果末尾解释已建立的比较起点，并提供查看错误修改的动作。该接续由所属示例读取投影提供，必须与当前项目及本报告Run准确一致；历史报告、外部修改和读取失败时保留通用报告动作。查看下一步不加载源码，实际修改仍需明确确认和正式前置检查。

官方项目的报告补充业务后果概览：当时要求之后，优先呈现被正式确认为违规的实际后果及其权限判断，执行响应和恢复核对在相邻辅助区。窄窗也先读业务后果，再读执行过程。禁止用403或恢复完成遮盖已发生的业务后果。概览直接读取该报告，示例停止、切换版本及查看历史时仍保留；当前演练的下一步入口单独核对旅程与Run。逐项列表与证据仍供深入核对，通用报告通过可选上下文槽接收，不硬写展馆业务或按预设版本推断结论。深入修改是可选链接，点击只导航，不切源码。

## 场景结果的辨识与窄窗阅读

场景结果先说明操作角色、账号与业务动作，资源编号作为相邻事实；同一资源下的正常操作与越权尝试不能仅靠资源名称区分。概览和详情共用封存名称的阅读组合，完全相同或已被完整包含的实验／执行文字只说一次。概览保留实验说明，完整执行安排进入详情按具名字段阅读；选中后的窄目录只保留定位所需的身份、操作、资源、顺序和结论。批量顺序和实际结果继续直接可见，不根据名称推断实验用途或判断。

宽区采用完整比较表；容器变窄后，每项先并列业务实验与正式结论，下方成组阅读资源归属和预期／实际结果。逐项结论不依赖横向滚动；复杂原始数据表继续允许局部滚动。选中后的窄目录将状态放在名称旁，资源与批量事实使用整行，不为状态保留贯穿正文的空列。响应式策略按实际容器宽度生效，保留准确用例与返回焦点。

## 记录查找与比较

归档报告与当前报告分别持有筛选、页码和阅读位置，按项目及Run隔离；片段目录、单条片段和报告逐层返回准确上级。进入归档报告时携带原归档目录及查询，不能套用当前应用的历史位置。归档读取失败仍提供准确回程与重新读取，不用空列表替代错误。归档阅读只提供已有事实，隐藏发起检查、修改与模型解读动作；深读不会改变原发布判断。

键盘Escape与可见返回遵循相同深度：单条片段回到所属片段目录，保留证明和执行节点范围；再回全部记录时清除局部范围，最后回本项结果。片段目录重新读取后按原片段身份恢复焦点，回全部记录时按原封存文件恢复入口，均不依赖已经卸载的DOM；独立任务标题也支持同一层级的键盘返回。读取失败时保留原对象并提供原请求的重读。

报告离开去核对规则、补材料或处理原问题前，保存纯阅读偏好和当前事项；回到同一份报告后恢复分类、页码与阅读位置。表单草稿继续由所属编辑器持有，秘密不进入阅读记忆。失败后重新读取原记录，不重新提交检查或改写旧结果。

历史条目先说明这次核对的修改内容，具体操作作为相邻次级信息；用途、结果与时间保留独立列。工作台近期记录与完整历史共用同一名称投影。名称只来自同项目准确修改声明，官方展馆的业务名另由稳定交付回执核对；不根据当前实现、时间或顺序命名。缺失说明保留原操作名并提示资料缺口。当前单份状态不为辨识历史而增加时间，历史目录继续保留时间。

记录页区分首次无数据、筛选无结果及读取失败：首次无数据集中说明产物和开始动作，不展示无作用的筛选栏；筛选无结果保留查询和清除入口；读取失败保留原因，不宣称没有记录。仅在真实内容需要分组时画分隔线，空列表的筛选与空态不叠加整条边界。

有边框的记录列表将比较操作放在独立底栏：选择状态与命令成组，底栏和记录之间只用一条分区线，左右与底部保留完整内边距。一个选择说明还需补选，两条选择只显示当前数量；原比较对象、时间顺序与返回位置继续由记录工作面持有。

## 逐项比较

跨轮逐项比较使用本节的整表概览与选中后目录详情。说明、比较限制与准确报告入口同属当前项；切换、收起和报告回程保留准确事项与键盘焦点，继续复用共享表格选中底面和内容动效。局部复验的短依据可在所属记录内展开，不将两类任务混成同一种排布。

比较阅读同时统一列关系与纵向节奏。总体说明与限制先成组，与逐项依据保持24px分隔；依据内部的规则要求、实际观察及正常对照分别成段，折叠的测试对象再退后。共同比较模式拥有这些间距，不能只迁移并列布局而遗漏原段落留白。

逐项比较未展开时显示整表，选中一项后切换为左侧事项目录和右侧当前依据，目录保留业务名称、账号及变化状态，右侧解释同一事项的参照结果与本次结果。前后观察在可用宽度足够时并列，窄窗由事项选择器接续当前依据并顺序阅读；收起后恢复原选择焦点。原问题处理、参照报告及本次证据都保留准确记录和上级回程，不因改变排布选择其他检查。

目录项内部使用完整可用宽度：业务名称与短变化状态复用`ObjectIdentity`成组，账号与参照结果在下方按宽度同行或换行。长名称自然换行，状态与名称保持邻近，不给状态单独保留贯穿正文的空白列，也不把每项短信息强制各占一行。

## 证明片段目录

证明片段先按业务事实、结果观察、请求结果与执行过程分组。片段是独立阅读入口，组内按实际容器宽度排列：宽区三列、中区两列、窄区一列；名称、所对应的业务结果和观察阶段在项内成组，阅读动作在本项右下收口。分组保留全部发布索引与准确引用；长名称完整换行，不通过截字或把按钮移到别项下方换取密度。逐记录比较表、连续执行步骤和长篇证明正文继续按自身任务组织，不套用片段网格。

少量片段按实际数量调整轨道，单项使用可用宽度，成对和少量连续阶段优先均衡分组；不为了固定三列留下大片无内容轨道。证明集合服从所属任务的内容轴，不再叠加一套较窄的列表上限。卡片中的业务名称同样标明为核对内容，观察阶段单独保留。索引未提供某阶段的结果时，进入原片段核对，不根据最终判断推断阶段结果。

## 证明记录

单条证明先展示具体业务核对结果，再给必要事实和解释，类别、来源与技术数据退后。前后状态保留各自含义，不用成排勾号暗示权限安全。技术调用、HTTP 成功、业务提交和安全结论分别表达。路径与发布记录不由前端推断或生成。

独立证明记录将当前值与说明作为主阅读区，采集方式、记录关联和检查背景在相邻辅助区核对；原文仍按需展开。按实际容器宽度并列或上下排列，短事实不沿整幅画布连续堆在左侧。独立证据阅读同样只保留当前深度的返回。

证明片段详情先回答业务问题：实际收到的文件是否完整、是否与已采用参照一致；账号、对象或数据变化核对到了什么。直接呈现服务形成的记录摘要与所属检查的已发布判断，解释它们的关系。文件内容一致与符合权限要求是两个不同事实，禁止下载时完整收到文件仍可能构成权限问题。字节数、内容指纹、内部编号与原始片段进入按需展开的核对数据和封存原文；采集方式与检查背景另行深入阅读，不要求用户手工比较技术值后自行得出业务结论。前端不根据哈希、状态码或模型描述重算发布结论。

证明数据已有容器边界时，后续展开项只保留分组间距；采集说明须属于本条事实，身份核对不套用同一证明关联的数据修改方法。
