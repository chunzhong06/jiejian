# 关键设计决策

本文保留仍适用的架构选择、理由和代价。模块入口见[架构](架构.md)，字段与格式见[接口与协议](../参考/接口与协议.md)。具体实现变化应更新所属说明；只有长期取舍改变时才修改这里。

## 人的规则与技术材料分开

业务角色、动作、资源关系和允许或禁止要求由人工审阅形成正式 revision。源码发现、Agent 建议、登录状态和录制用于解释或执行规则，不能自动成为权限事实。

这样允许先讨论权限、后准备环境，也允许替换执行材料而不改变业务要求。代价是候选含义、本轮范围、正式提案和技术采用分别有确认条件。可以合并清晰的同类操作，不能用一次总确认掩盖它们不同的授权范围。

`policy_epoch` 表示正式权限集合的演进。纯实现重绑或重新登录不应伪造权限变化；实际批准事务同时维护 revision、决定、绑定和必要的 epoch 变化。

## 检查冻结输入，历史只读

提交时核对当前规则、来源、源码、材料和完整计划，再冻结 request 与 runtime bundle。Worker 和 Runner 消费冻结输入，不依靠页面缓存或重新解释可变配置。变化影响说明修改涉及哪些规则，不能裁去完整计划中的正常对照和其他必要检查。

快照使结果能对应当时条件，代价是来源漂移后必须重新核对并发起新检查。报告不能补写旧 Evidence，也不能把当前源码或 Git HEAD 当作当时运行版本。

## 执行经过持久任务与隔离进程

HTTP、CLI 和 MCP 共用 ApplicationCore。API 负责输入、授权、用例和回执；目标请求、浏览器及高风险执行由 Worker 和隔离 Runner 承担。

Job 的领取、attempt、租约与 fence 防止失去所有权的进程再次提交。取消请求被接受与实际进程结束分别记录。该结构增加装配、监督和恢复成本，换来可追踪的任务所有权及明确的进程边界；不能把隔离进程等同于任意恶意程序的安全沙箱。

## 业务效果与请求响应分别判断

HTTP 成功只说明请求层观察。权限判断还需要实际身份、资源对应、可信基线、后果证明、关联范围、观察完整性和必要恢复。允许要求验证正常功能；禁止要求验证不应发生的后果，已发生后再撤回不能抵消发生事实。

Verification 仅依据确定事实给出 PASS、BLOCK 或 INCONCLUSIVE。缺少证据时保留具体缺口，不从没有日志推断从未发生，也不扩大为任意历史结论。额外证明与恢复提高准备成本，但阻止状态码或不完整过程造成虚假的安全结论。

## 因果诊断不改变安全结论

Trace 和断裂定位只消费已形成的关联事实。显式父引用表达因果，时间接近、数组顺序和同名节点不能补齐缺边。来源不完整时降低定位精度，仍保留已经确认的业务后果。

诊断有助于解释问题发生在哪里，但它的精度与权限结论分别受证据限制。读取或定位失败不能改写原 Verdict，更不能由模型补出缺失过程。

## 文件发布与数据库完成分别收敛

Runner 写入受限 staging。发布者核验身份、fence、路径、预算、脱敏与 hash，再发布不可变结果；数据库完成事实引用已验证的包。数据库与文件系统无法共享一个普通事务，因此需要明确的发布回执与幂等恢复。

文件已发布但数据库提交失败时，恢复只能基于同一清单、身份和 hash 补齐对应事实。篡改、未知格式或不完整文件不能因为“目录存在”而被接受。索引用于查询，不能成为第二份安全结论。

## 修改围绕规则和原问题关联

源码修改是一次真实变化，可以关联多条规则和多个原问题。登记保存实际差异与明确目标；原问题来源于已发布的 Run 和 Case，不能由修改者重写修复标准。

复验同时核对原问题、正常对照、必要回归、规则与运行对应。无关 PASS 不代表修复完成，运行版本未确认也不能宣布 VERIFIED。代价是关联和标准必须足够精确，收益是修复与正常功能保留可以分别解释。

## 完整基线与明确的格式代际

当前工作区建立完整基线，正常运行不加载旧迁移及旧协议兼容分支。初始化采用当前结构，已有文件先只读核验身份与完整结构。旧数据处置属于明确的维护选择，启动时不猜测转换。后续已发布代际内的结构演进按[迁移规则](数据库与迁移.md)维护。

旧 Contract、Profile、Finding 和 Gate 的独立算法或格式与当前 CHECK 链明确区分。仍有消费者的协议和算法保留针对性测试；已移除产品入口不靠兼容壳复活。未知数据不得猜测转换。

## 一个知识入口，按读者任务展开

人从文档目录进入，开发代理从 `docs/llms.txt` 路由，两者读取同一正文。教程、具体操作、解释、工程契约和生成参考各自承担独立目的。

迁移文档先找有效知识的去向，再移动或合并。历史施工记录和已被取代的具体实现不充当当前指南；仍成立的理由、安全边界和故障恢复必须保留。代价是持续维护链接和事实所有者，不能用链接检查代替内容审阅。
