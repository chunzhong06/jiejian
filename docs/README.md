# 界鉴文档

先完成一个真实任务，再按需要查原理和接口。产品指南面向使用者，工程文档面向维护者；两者使用相同的产品事实，不要求使用者先理解源码层级。

## 选择入口

| 你要完成什么 | 从这里开始 | 完成后应得到什么 |
| --- | --- | --- |

| 使用 Windows 便携版 | [启动、退出与更新](产品/便携版使用.md) | 可独立运行的发行环境与明确的数据支持范围 |

| 检查自己的 Web 应用 | [接入应用](产品/接入应用.md) | 可核对的源码、项目与运行地址 |
