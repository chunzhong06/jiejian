# 界鉴文档导航

本目录提供两条共享真源阅读路径。系统文档解释当前结构和协作边界；ADR 解释形成这些边界的原因。阶段记录、历史基线和竞赛材料保留各自职责，不作为当前系统教程。

## A. 开发者指南：理解、修改、验证

1. [项目总览](项目总览.md)：产品定位、当前能力和受限范围。
2. [架构说明](架构说明.md)：从入口到 Worker、Runner、Verification、Storage 和 Results 的协作。
3. [模块地图](模块地图.md)：按能力定位代码、测试、样例和公共 Schema。
4. [Windows 首次准备](../README.md#环境)：`start.cmd` → `scripts/start.ps1` → `jiejian serve --open`；支持 `PrepareOnly`、`ForcePrepare`、指纹快速路径和 `/ready` 门禁。
5. [开发规范](02_开发规范/开发规范.md)、[代码组织](02_开发规范/代码组织.md)：修改边界和新增文件判断。
6. [测试规范](02_开发规范/测试规范.md)与[测试资产地图](../tests/README.md)：最小验证集合、marker 和共享夹具。
7. [黄金样例](../samples/README.md)：fixed、vulnerable、inconclusive、Recording 和 Contract/Drift 演示。
8. [公共 Schema](../schemas/README.md)：跨进程机器契约及漂移测试定位。
9. [竞赛 Demo 流程](06_竞赛资料/Demo流程.md)：当前可复现的本机演示。

## B. 工程真源：约束、协议、兼容和决策

1. [系统架构](01_架构设计/系统架构.md)与[数据流](01_架构设计/数据流.md)：跨模块职责、进程边界、事务顺序和信任边界。
2. [项目设计规范](02_开发规范/项目设计规范.md)：安全、协议、持久化、状态机、错误和验证硬约束。
3. [数据格式导航](04_协议定义/数据格式.md)与[Runner 执行协议 V1](04_协议定义/Runner执行协议V1.md)：公共数据家族和字段级进程协议。
4. [ADR 索引](03_技术决策/README.md)：ADR-0001～ADR-0020 的状态、关系和当前落实文档。
5. [开发路线图](05_开发记录/开发路线图.md)：阶段历史和当前完成点；不替代当前规范。
6. [重构前行为基线](05_开发记录/重构前行为基线.md)：只用于历史不变量对照，旧路径是证据定位而非当前真源。

## 文档职责

- 根部 [README](../README.md) 是安装、首次准备和产品入口真源；文档只摘要并链接。
- `docs/项目总览.md`、`docs/架构说明.md`、`docs/模块地图.md` 是当前系统的三份短入口。
- `docs/01_架构设计/系统架构.md` 是工程架构真源；`数据流.md` 是跨模块主链真源。
- `docs/02_开发规范` 保存当前项目级约束；不复制模块内部实现说明。
- `docs/03_技术决策` 解释“为什么”，不替代当前系统教程。
- `tests/README.md`、`samples/README.md`、`schemas/README.md` 分别是测试、样例和公共机器契约的资产真源。
- `docs/05_开发记录`、历史 ADR 和重构前基线保留历史事实；扫描当前教程时应明确排除这些目录。
