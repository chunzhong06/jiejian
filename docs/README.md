# 界鉴开发文档

按要解决的问题进入；人类和Codex共用正文。Codex的唯一任务路由是[llms.txt](llms.txt)，行动与安全边界由根[AGENTS](../AGENTS.md)规定。

| 当前需要 | 入口 |
| --- | --- |
| 初次理解项目和有哪些功能 | [系统边界](总览/系统边界.md)、[功能地图](总览/功能地图.md) |
| 理解业务对象、状态和事实所有者 | [概念与事实](总览/概念与事实.md) |
| 看用户、原Agent和界鉴怎样完成一次检查 | [使用流程](总览/使用流程.md)、[产品入口](总览/产品入口.md) |
| 修改某项功能 | 从[功能地图](总览/功能地图.md)直接打开该能力的修改指南；需要时再读相邻协作和协议 |
| 准备开发环境或验证一次修改 | [快速开始](工程/运行与交付/快速开始.md)、[环境与脚本](工程/运行与交付/环境与脚本.md)、[验证](工程/验证.md) |
| 查精确代码、注册、Schema和数据库head | [生成参考](参考/生成/README.md) |
| 理解长期取舍或旧设计为何退役 | [决策索引](决策/README.md) |
| 维护文档与开发规则 | [知识治理](工程/规则/知识与文档治理.md) |

总览负责全局理解；能力按功能保存修改指南、协作与专属契约；工程集中维护前端、数据、环境、验证和规则；参考保存生成事实与独立保留实现；决策保留理由与历史。

路径可达只证明文件存在。生产挂载、严格reader、代码/Schema和真实运行共同决定支持范围；旧方案、代码存在、技术测试和用户实际体验是不同事实。
