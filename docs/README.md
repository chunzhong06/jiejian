## 阅读顺序

默认路径是：

`AGENTS.md → docs/README.md → 1～3 篇相关 Architecture → 必要 ADR/Protocol/Schema/Migration → 相关代码与测试`

根目录 [README.md](../README.md) 是产品使用入口，`AGENTS.md` 是开发行为入口。本目录回答系统当前是什么、为什么这样设计以及机器边界在哪里。

Roadmap 只说明后续方向，不是普通任务的默认必读文档；ADR 解释为什么作出某项长期决策，不能替代当前 Architecture。

## 深入真源

以下目录按需阅读：

- `03_架构决策/`：长期决策及其历史记录。先看索引，再读与任务直接相关的 ADR。
- `04_协议与数据/`：跨进程协议、公共数据和 Schema 版本。协议 Markdown 解释边界，JSON Schema 才是字段约束真源。
- `product/backend/migrations/`：数据库结构和迁移真源。
- `05_路线与研究/`：下一步路线和长期实验结论。路线图不替代当前架构，实验不替代生产代码。

代码与测试是最终运行事实；发现文档和实现不一致时，先按 [技术文档规范](01_技术规范/技术文档规范.md) 记录真源和影响，再同步必要文档。
