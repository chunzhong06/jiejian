## 阅读顺序

默认路径是：

`AGENTS.md → docs/README.md → 1～3 篇相关 Architecture → 必要 ADR/Protocol/Schema/Migration → 相关代码与测试`

根目录 [README.md](../README.md) 是产品使用入口，`AGENTS.md` 是开发行为入口。本目录回答系统当前是什么、为什么这样设计以及机器边界在哪里。

Roadmap 只说明后续方向，不是普通任务的默认必读文档；ADR 解释为什么作出某项长期决策，不能替代当前 Architecture。
