# 界鉴开发文档

> 状态：CURRENT。代码、测试、Schema 与 migration 是实现事实；文档负责解释职责、入口和约束。

第一次开发从[快速开始](开发/快速开始.md)进入。已有具体任务时，直接选[能力指南](开发/能力/)；不知道所有者时查[能力映射](架构/能力映射.md)。Codex 使用同一正文，由 [llms.txt](llms.txt) 选择必要内容。

普通任务通常只需要一篇能力指南和直接代码。跨事务、进程、公共格式或安全语义时，沿指南链接展开相应架构与协议；无需从头读完整文档树。运行证据、设计审阅、临时调查与版本计划放在 `var/` 或用户指定交接包，不作为当前实现说明。

尚未实施的[持续开发工作流与入口重组](决策/ADR-0044-持续开发工作流与入口重组.md)明确标为提议，不作为当前页面合同。未来连接客户端调整也不表示当前适配已完成。

材料准备和修复任务分别从[修改安全准备](开发/能力/修改安全准备.md)、[修改 Agent 变更影响](开发/能力/修改Agent变更影响.md)进入，详细契约按问题跳转；提交检查从[验证入口](开发/验证.md#先选择本次验证入口)进入。

维护人工正文后运行 `dev.ps1 docs`；生成输入变化时先 `dev.ps1 docs -Update` 再只读检查。生成器检查本地链接与章节锚点、路由状态、当前正文中的静态源码路径、数据库 head 和生成漂移，不能替代事实核对。
