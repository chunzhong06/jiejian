## 文档职责

- 根部三份地图是长期入口，保持短、直观、面向所有读者。
- `00_项目介绍` 至 `06_竞赛资料` 保存详细说明，每个事实只保留一个权威真源。
- `03_技术决策` 解释“为什么这样设计”，不替代当前规范。
- `04_协议定义` 描述人和机器共同遵守的数据边界；可执行模型仍位于 `backend/src/jiejian/protocols`。
