# 原Agent协作与旧模型能力退出

> 状态：CURRENT。界鉴已退出内置模型连接。原Agent通过MCP读取事实、保存候选，用户在界鉴确认并执行。

## 当前入口

统一上下文由 `workflows/agent_access/workflow.py` 提供，HTTP为 `/api/projects/{project_id}/agent-context`，MCP为 `jiejian_agent_context`。规则、材料、录制、结果与修复使用精确项目和记录引用；页面复用 `AgentAssistEntry`。复制只表示请求已复制，不表示送达或处理完成。

材料批次由 `workflows/preparation/batches.py` 管理。用户在GUI确认固定清单；MCP只能读取计划、查询批次和在EXECUTE权限下停止批次。后台自动续行已批准步骤，无需Agent反复发送授权或采用命令。重启、撤回读取授权或依据变化后暂停后续步骤，回到GUI重新核对。

开始检查前先调用 `jiejian_check_preview`；`jiejian_check_run` 必须携带读到的 `expected_plan_fingerprint`。改变权限、源码或材料后旧指纹不能提交另一份检查。结果由界鉴形成，Agent只解释；修复仍须用户授权，不降低原规则。

## 已退出

模型API设置、Provider/目录与连接测试、内置短解释和自然语言权限草稿、专属缓存、HTTP路由及前端调用已退出。规则候选、材料候选、确定性源码分析与人工编辑保留。

`llm_profiles` 和 `ai_assistance_settings` 的历史表结构保留用于无损升级，Repository及UoW装配已退出。没有删除用户凭据，也没有清空MCP共享SecretStore。旧模型密钥不再被产品读取。

## 修改边界

协作服务只交接有限事实。录制去除query、fragment、请求正文与资源实际路径值；结果固定到run/case。秘密不进入协作请求、普通数据库或日志。MCP不能代人批准规则、确认读取范围或扩大已确认材料计划。

详细授权见[修改MCP与授权](修改MCP与授权.md)，材料步骤见[修改证明来源](../证明来源/修改证明来源.md)。
