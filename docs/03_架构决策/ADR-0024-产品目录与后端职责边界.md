# ADR-0024：产品目录与后端职责边界

- 取代者：ADR-0027、ADR-0035
- 当前阅读提示：本文保留历史决策；当前边界以 ../README.md 和相关 CURRENT 文档为准。

## 状态

已取代

## 决策

- 产品代码统一位于 `product/`：`backend`、`frontend`、`protocols`、`config` 分别承担后端、前端、版本化机器协议和产品运行时默认配置。
- Python 唯一安装命名空间为 `product`；后端导入使用 `product.backend.*`，协议模型使用 `product.protocols.*`；分发项目名和 console 命令继续为 `jiejian`，入口为 `product.backend.cli:main`。
- `core` 只保存跨目标类型共享的安全领域事实与纯判断；`workflows` 是 API、CLI 和未来入口共享的应用编排；`infra` 保存具体 HTTP 执行、进程、观察器、工件、LLM 和存储适配。
- Runner、Worker、Recording Runner/Observer 的独立进程边界保留。当前目标执行只有 `product.backend.infra.execution.http.HttpExecutionAdapter`；本项不创建 Process/MCP Adapter、target_type 或 Execution Router。
- `product/protocols` 是跨进程协议唯一真源；v1/v2 只表示仍被读取或消费的兼容协议版本。`*_new`、`*_latest` 和无兼容依据的历史实现后缀不保留。
- 内部实现按职责命名：Contract 执行、复杂权限执行、权限关系判定、Job 恢复和工件规则分别使用 `contract_execution.py`、`permission_execution.py`、`permission_evaluation.py`、`recovery.py` 和 `artifact_ruleset.json`；只有协议 wire、签入 Schema、持久 publication 格式和明确兼容适配保留 V1/V2 名称。协议字段、`schema_version`、canonical/hash 与历史读取不因内部改名变化。
- 根 `pyproject.toml` 是唯一 Python project root；`uv.lock`、`environment.yml` 留在根目录。Hatch wheel 只包含后端、协议、迁移、Schema、ruleset 和默认配置，不包含前端开发/生成物。

## 旧路径映射

旧 `backend/src/jiejian` 已移除。`application/domain/execution/runtime/runner/worker/recording_runner/results/storage` 等旧职责分别收敛到 `workflows`、`core`、`infra/runtime`、`infra/runtime/runner`、`infra/runtime/worker_process.py`、`infra/runtime/recording_process.py`、`workflows/results`、`infra/storage`；具体 HTTP 从旧 Verification 位置移动到 `infra/execution/http.py`。

## 不变量

本次重构不改变 Verification、Finding、Gate、Evidence、Report、数据库表语义、Alembic revision identity、Runner/Worker 标准流与退出码、稳定 CLI 命令和历史工件读取。样例边界只将内置 onboarding demo 保留在产品工作流，并将官方 Authorization HTTP Target 放入 `samples/http/target/server.py`；复杂权限 HTTP 测试 Target 属于测试夹具，不是产品或官方 Sample 入口。
