# ADR-0026：单代权限执行链收敛

状态：已接受

## 决策

发布前将 PermissionExecutionProfile、RunnerInput、Evidence、RunnerResult、PersistedExecutionRequest 和 Observer wire DTO 收敛为当前稳定 Python 名称；机器协议的 `schema_version` 继续使用真实值 `"2"`。旧 Runner、旧结果投影、旧 ownership 适配器和 ProjectBundle 到执行请求的构造链不再保留。

CLI、CI、API 和 onboarding 通过同一个 PermissionRunWorkflow 完成当前 Profile 的登记、提交、可选等待和已发布结果读取。Recording replay 只能把已审阅的当前 Flow 作为 Profile 的显式 override，并重新经过 ExecutionProjectSnapshot 的 binding、Contract 和 plan 校验。

## 范围

本决策只覆盖恢复点 1 的单代执行链和直接消费者。Contract/Profile 真源拆分、Core 去 HTTP 化、Storage 垂直聚合、API 路径收敛、ExecutionRouter/ExecutionFact、迁移历史和启动脚本拆分不属于本批。
