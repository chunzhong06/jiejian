# ADR-0021：最小文档真源

- 状态：已接受
- 日期：2026-08-13
- 范围：项目级文档、目录说明
- 取代：旧的面向读者信息架构决策中关于当前入口和文档组织的表述；不改写协议、Schema、迁移、生产代码或仍有效的决策正文

## 背景

仓库同时存在系统短文、架构短文、模块地图、旧阶段记录、目录 README 和竞赛材料。它们大多复制当前设计或记录已经由 Git 历史承担的流水账，导致首次使用、代码审查和协作执行需要在多份文档间反复比对。机器 Schema、公共协议、迁移依据和仍有效的安全/兼容决策具有独立消费价值，不能按人类导航文档处理。

## 决定

1. 根 `README.md` 是唯一面向用户的安装、双击启动、首次使用、黄金样例和必要排错入口。
2. `AGENTS.md` 是协作执行、安全、权限、验证和提交约束入口；项目设计规范、路线图、协议正文和 ADR 索引只保留实际存在的路径。
3. `docs/01_开发规范/项目设计规范.md` 是唯一当前设计真源；它只记录系统边界、核心模型、状态机、安全、公共协议/迁移引用、GUI/CLI/API 共享服务和当前实现边界。
4. `docs/04_开发记录/开发路线图.md` 只记录阶段 0～5.6 摘要、当前里程碑、阶段 6～9 顺序和阶段级验收；逐批流水账由 Git 历史承担。
5. `docs/03_协议定义/`、`schemas/`、`backend/migrations/` 和仍有效的 ADR 保持独立真源。
6. 删除重复的系统导航、旧阶段说明和目录 README；不创建墓碑、wrapper 或删除清单文档。删除前以仓库引用、测试断言、脚本/打包和公共协议消费证据为准。

## 影响与迁移

本决策只改变人类文档路径和导航，不改变生产行为、公共 API、Schema、migration、安全边界、状态机或运行产物。引用统一迁移到根 README、项目设计规范、路线图、协议正文或 ADR 索引；外部使用者应从根 README 进入。

## 验收

- 根 README、AGENTS、项目设计规范、路线图、ADR 索引、协议正文和机器 Schema 存在。
- 仓库内 Markdown 相对链接全部可解析；没有失效的文档活动引用。
- 当前设计文档不再包含阶段流水账、重复目录表或旧教程；阶段 6～9 只作为未实现规划。
- 文档变更不触及生产代码、公共 Schema、迁移和安全测试断言。
