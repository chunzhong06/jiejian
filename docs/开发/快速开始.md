# 开始开发

> 状态：CURRENT。适用于 Windows 源码工作区。

1. 打开仓库根，确认当前任务与已有修改的归属；不要覆盖其他未完成工作。
2. 用户运行从 `start.cmd` 开始。开发准备使用 `scripts/dev.ps1 prepare`，同步依赖使用 `scripts/dev.ps1 sync`。解释器、共享工具链与实例目录见[环境与脚本](环境与脚本.md)。
3. 从[能力映射](../架构/能力映射.md)找到唯一所有者，再读取一个对应指南。通常沿 API/页面、应用服务、领域或适配器找到变更点，不把全仓扫描当作固定前置步骤。
4. 修改后按[验证](验证.md)选择直接测试。前端需核对实际页面和批准设计，测试通过不代表视觉一致。正式验收使用现有 `sample-test`，不要另造第二套产品入口。

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\scripts\dev.ps1 test tests/architecture/test_dependencies.py
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\scripts\dev.ps1 frontend-test
```

以上是入口示例，按本次影响范围选择，不要求每次完整运行。多个 `dev.ps1` 命令串行执行；运行数据和依赖均进入 `var/`。Python 只读语法检查使用 `PYTHONDONTWRITEBYTECODE=1` 与 `python -B`，避免源码缓存。
