# 因果关联实验

> 状态：研究结论。本文只保留可复用证据，不表示新增生产能力。

## 问题

在存在异步任务、审计日志和最终副作用的情况下，能否通过显式关联信息把一个权限用例连接到唯一任务、观察窗口和最终结果，并在证据不足时安全停止。

## 固定条件

实验使用确定性 harness、显式 opaque `case_tag`、有界日志/状态读取、唯一任务终态和资源关联。实验不扫描公网，不把实验数据当作生产结果。

## 观察

- 显式 `case_tag` 可以连接 case、task、sequence/terminal state 和最终 resource effect。
- 缺失、冲突、重复或交错 tag，以及日志轮转、部分尾行和预算不足，都能被识别为证据不完整。
- 观察结果可区分固定、越权和不可确认情形，但实验没有证明生产框架的全部并发、日志轮转或 Schema 漂移行为。

## 结论

显式关联标识、观察窗口、唯一终态、完整性和预算是形成可用因果证据的必要条件；证据不足必须进入 INCONCLUSIVE，而不是推断安全。

## 限制

实验不证明真实目标适配器、Observer、API、GUI、数据库迁移或并发实现已经具备这些能力，也不授权新增公共协议或生产入口。

## 对产品的长期影响

生产 Observer/Runner 需要保留 locator、correlation、causality、completeness、integrity 和 budget 语义，并把结果交给现有 Evidence/Verification 链。实验通过不等于新增 adapter 或 observer。
