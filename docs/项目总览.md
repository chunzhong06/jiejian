# 界鉴项目总览

## 一句话定位

界鉴验证 Vibe Coding Web 应用是否真正满足安全意图：它把显式安全契约转成受授权、可观察、可回溯的运行验证，并将结果作为本地或 CI 门禁。

## 当前产品链

```text
Project → Recording / Contract → Run → Evidence → Result
```

- **Project**：目标范围、身份秘密引用、资源和 Flow 的自包含输入边界。
- **Recording**：通过独立 Recording Runner 采集脱敏事件，形成可审阅 FlowDraft。
- **Contract**：从显式 YAML、Requirement、Flow 和受限候选建立版本化安全规则；ACTIVE 版本可与 Project 绑定。
- **Run**：从不可变执行请求快照创建持久 Job，由 Worker 调度一次或多次隔离 Runner attempt。
- **Evidence**：Verification 结合 HTTP 表象、owner 观察和关系变异生成内容寻址证据。
- **Result**：发布后的 Run、报告和 Evidence 只读读取，结论区分 `PASS`、`BLOCK`、`INCONCLUSIVE` 与基础设施失败。

## 安全边界

- API、CLI 和 GUI 不直接发目标请求；高风险目标流量只能由授权的隔离 Runner 发出。
- Worker 负责租约、fencing、取消、恢复和发布，不决定安全结论。
- Runner 只接收不可变请求和最小秘密环境，只写当前 attempt staging。
- 文件工件先完整校验并原子发布，数据库完成态随后在 UnitOfWork 中提交。
- 日志、错误、事件、请求快照、Evidence 和报告不得泄露真实秘密；未授权公网目标不在产品范围内。
