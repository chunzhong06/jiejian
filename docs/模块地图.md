## Python 包

Python 包根是 [`backend/src/jiejian/`](../backend/src/jiejian/)。

| 模块 | 做什么 |
| --- | --- |
| [`domain/`](../backend/src/jiejian/domain/) | 纯领域模型、公共 ID、生命周期、verdict 和状态转换。 |
| [`runtime/`](../backend/src/jiejian/runtime/) | 配置、doctor 和结构化日志。 |
| [`verification/`](../backend/src/jiejian/verification/) | YAML 输入、目标授权、关系变异、HTTP、多观察者判定和 Evidence。 |
| [`protocols/`](../backend/src/jiejian/protocols/) | RunnerInputV1/RunnerResultV1、规范 JSON 和安全矩阵。 |
| [`storage/`](../backend/src/jiejian/storage/) | SQLite、ORM、Repository、原子 Job 更新和 UnitOfWork。 |
| [`worker/`](../backend/src/jiejian/worker/) | Job 提交、租约、取消、Runner 监督、发布和恢复。 |
| [`runner/`](../backend/src/jiejian/runner/) | 隔离进程入口；唯一能连接 Runner 协议与目标执行的包。 |
| [`cli.py`](../backend/src/jiejian/cli.py) | 唯一安装的 `jiejian` 产品命令入口。 |
| [`errors.py`](../backend/src/jiejian/errors.py) | 稳定错误码和脱敏错误。 |
| [`redaction.py`](../backend/src/jiejian/redaction.py) | 日志、错误、Evidence 和展示脱敏。 |
| [`sample_app.py`](../backend/src/jiejian/sample_app.py) | 本机 safe/vulnerable 黄金样例服务。 |
