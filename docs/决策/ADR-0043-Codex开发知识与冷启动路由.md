# ADR-0043：按任务加载开发知识

- 状态：已接受
- 适用范围：开发知识入口、渐进阅读、生成参考与路由验收

## 决策与理由

根 AGENTS.md 只保留授权、硬边界和停止条件。`docs/llms.txt` 按任务指向一篇能力指南；未知所有者时查能力映射。只有受影响的事实、进程、事务、协议或安全语义需要进一步阅读时才展开链接。取消固定“任务指南加模块指南加架构”的重复堆叠，已有有效上下文不重复加载。

人类与 Codex 共用产品、架构、开发、参考、约束和决策正文。产品流程与视觉规范、修改步骤、精确协议和长期理由分开维护；一个详细事实只有一个位置。函数签名和 Schema 索引由确定性工具从文本或 AST 生成，不 import 生产代码，生成参考不默认整份读取。

任务指南应让读者找到当前所有者、关键消费者和直接验证，不能只写抽象原则。以受影响的真实任务检查路由可达性及事实准确性；独立执行线程探针需要用户授权，不能自动创建聊天。链接通过不等于知识可用。

## 取舍与同步

精简默认上下文会使深层知识按需展开，因此入口必须准确，不能通过删掉安全边界来缩短文档。职责迁移时同步能力表、指南、协议引用和生成器；旧路径在内容与消费者迁移后删除，不留永久转发层。版本计划、账本、截图与临时审阅不进入当前实现文档。

详细职责与验收规则见[知识与文档治理](../工程/规则/知识与文档治理.md)，正式验证入口见[验证](../工程/验证.md)。
